## 排烟窗水平距离答疑：净高5m工业建筑=14m（WorkBuddy）

- 用户问"造纸厂房，室内净空高度5m，采用自然排烟，该车间防烟分区内任一点与最近自然排烟窗之间水平距离最大为"。
- 选项 A30 / B37.5 / C14 / D20。
- **答案 C、14m**。
- 依据：GB 51251-2017 第4.3.2条 + 讲义P392（3号书设施篇视觉版OCR L12861-12862）。
- 三个限值：一般≤30m；工业自然排烟≤净高×2.8=5×2.8=14m；公建净高≥6m有对流≤37.5m。**取更严格者（最小值）**。
- 讲义P396原题示例（OCR L13277）："某厂房采用自然排烟，室内净高5m，防烟分区内任一点距离自然排烟窗不应大于（14）m"——几乎原题复刻。
- 知识库 smoke-control.md 已完整覆盖，无盲区，未提交 wb-suggestions。
- 易混点提醒：37.5m 是公建专属、不能用于工业；30m 是公建/工业通用上限、但工业还受2.8倍净高约束。
