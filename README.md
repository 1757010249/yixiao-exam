# 一级消防工程师备考知识库

一个面向一级消防工程师考试的结构化备考知识库，覆盖《消防安全技术实务》《消防安全综合能力》《消防安全案例分析》三科。知识库围绕教材讲义、奇门遁甲口诀、历年真题、错题本四类资源构建，目标是让每一次答题、每一道错题都有可追溯的知识依据。

## 一、内容组成

```
knowledge-base/     # 结构化知识库（唯一权威内容源，40个条目 + 索引）
  building-fire-protection/   # 建筑防火
  fire-facilities/            # 消防设施（water/electrical/hvac）
  safety-management/          # 安全管理
  laws-regulations/           # 法律法规
materials/          # 原始资料归档（讲义/习题/真题/思维导图/奇门遁甲）
errors/             # 错题本
diagrams/           # 独立 Mermaid 流程图
templates/          # 条目模板
wb-suggestions/     # WorkBuddy 建议回流（wb 只写 pending/，Claude 校验后入库）
SC-输出成果/        # 笔记校验、知识汇总、分析报告等输出
```

### 知识库主体（knowledge-base/）

按考试科目组织为四大模块，40 个知识条目，每个条目含完整 YAML 元数据（module、tags、regulation_refs、related）：

| 模块 | 覆盖内容 | 典型条目 |
|---|---|---|
| 建筑防火 | 建筑分类、火灾危险性分类、耐火等级、总平面布局、平面布置、安全疏散、装修防火、防排烟、防火分区、防爆、电气防火等 | fire-resistance.md、evacuation.md、site-layout.md |
| 消防设施 | 消火栓、自动喷水、水喷雾/细水雾、气体灭火、干粉、灭火器、火灾自动报警、应急照明、防排烟、自动消防炮 | automatic-sprinkler.md、gas-extinguishing.md、water-supply.md |
| 安全管理 | 消防安全责任制、检查维护、大型商业综合体 | responsibility.md、inspection.md |
| 法律法规 | 法律法规概览、法律责任与处罚 | overview.md、penalties.md |

### 原始资料（materials/）

- **讲义**。1号书防火篇、3号书设施篇、5号书综合能力（均已 OCR 全文入库 `tools/extracted/`）
- **习题**。2号书防火习题集、4号书题眼、6号综合习题
- **真题**。2015-2023 历年实务/综合真题
- **思维导图**。建筑防火、消防给水、设施、综合能力
- **奇门遁甲**。横向/竖向 PDF、总结版、卡牌大师，口诀已拆分为 10 个分组文件（75条）

### 错题本（errors/）

- `items/` 逐条错题（知识点、科目、难度、答案）
- `index.md` 按知识点和模块双维度统计
- `weak-points-analysis.md` 薄弱点分析
- `versions/` 错题本版本对比报告

## 二、功能

### 1. 规范条文溯源

每条知识都标注来源（知识库文件 + 规范条文编号 + 讲义页码 + OCR文本行号）。引用口诀后强制附规范条文编号（如"依据：GB 50016-2014 第X.X.X条"），口诀只是记忆辅助，规范才是考试依据。

### 2. 奇门遁甲口诀

横版（章节浓缩）+ 竖版（跨知识点辨析）双维度记忆体系，搭配 75 条拆分组装口诀，用于速记易混淆数字（火灾危险性分类、耐火等级、防火间距等）。

### 3. 答题判定协议

- 所有提问逐条与知识库核对，给出"一致 / 不一致 / 存疑"判定
- 知识库无法判定的明确标注"知识库未收录，无法核实"，不凭空判断
- 知识库与规范冲突时明确标注冲突，由用户判断

### 4. 错题全流程管理

- 错题四要素解析。核心考点 + 概念混淆 + 规范条文依据 + 举一反三模拟题
- 每周真题错题更新。逐条录入 errors/items/，同步更新统计与薄弱分析
- 错题本版本对比。新旧 PDF 全文比对，识别新增/删除错题，生成对比报告

### 5. 主动学习建议

- 根据错题知识点分布，主动指出薄弱模块
- 定期生成针对性练习建议和"举一反三"模拟题

### 6. 全量检验保障

对知识库的任何补录、修改、核对，必须逐条全部检验并回查讲义/规范原文，禁止抽样抽查，确保每个条目都有真实来源。

## 三、使用方式

| 场景 | 操作 |
|---|---|
| 知识问答 | 直接提问，Claude 按知识库 + 规范条文作答 |
| 笔记校验 | 提交笔记/讲义，Claude 逐条与知识库核对 |
| 错题录入 | 完成真题后提交错题，录入 errors/items/ |
| 错题本更新 | 提供新版错题本 PDF，生成版本对比报告 |
| 模拟题评分 | 提交作答，对照标准答案评分并分析丢分点 |

## 四、双 Agent 协作分工

本项目由 **WorkBuddy（wb）** 与 **Claude Code** 协作维护：

| 事项 | WorkBuddy | Claude Code |
|---|---|---|
| 日常问答 | 负责（读知识库作答） | — |
| 知识库写入 / 索引更新 | 禁止（只读） | 负责 |
| 新内容开发（补录/校验/错题/真题） | — | 负责 |
| 盲区建议回流 | 写 wb-suggestions/pending/ | 校验后写入 knowledge-base/ |
| git 提交 | 禁止 | 唯一执行者 |

- wb 的项目规则见根目录 `AGENTS.md`（只读边界 + 回答协议 + 建议流）
- 建议回流协议见 `wb-suggestions/README.md`，建议台账见 `wb-suggestions/待处理清单.md`（定期与用户一起处理），Claude Code 处理规则见 `.claude/rules/wb-suggestion-processing.md`
