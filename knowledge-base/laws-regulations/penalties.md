# 法律法规与处罚

## 消防法处罚规定（核心记忆）

### 建设工程相关（第58条，3万-30万档）

| 违法行为 | 处罚 |
|---|---|
| 未经消防设计审查擅自施工（或审查不合格） | 责令停止施工/使用/停产停业，处**3万-30万元**罚款 |
| 未经消防验收擅自投入使用（或验收不合格） | 责令停止施工/使用/停产停业，处**3万-30万元**罚款 |
| 验收后经依法抽查不合格，不停止使用 | 责令停止施工/使用/停产停业，处**3万-30万元**罚款 |
| 公众聚集场所未经许可擅自投入使用、营业 | 责令停止施工/使用/停产停业，处**3万-30万元**罚款 |
| 验收后未报备案 | 责令改正，处**5000元以下**罚款 |

### 建设工程相关（第59条，1万-10万档）

| 违法行为 | 处罚 |
|---|---|
| 建设单位要求建筑设计单位或施工企业降低消防技术标准设计、施工 | 责令改正或停止施工，处**1万-10万元**罚款 |
| 建筑设计单位不按消防技术标准强制性要求进行消防设计 | 责令改正或停止施工，处**1万-10万元**罚款 |
| 施工企业不按消防设计文件和消防技术标准施工，降低消防施工质量 | 责令改正或停止施工，处**1万-10万元**罚款 |
| 工程监理单位与建设单位或施工企业串通，弄虚作假，降低消防施工质量 | 责令改正或停止施工，处**1万-10万元**罚款 |

### 消防技术服务机构（第69条，易错点）

| 违法行为 | 处罚 |
|---|---|
| 不具备从业条件从事活动 或 出具虚假文件 | 处**5万-10万元**罚款；主管人员处**1万-5万元** |
| 不按国标行标开展技术服务 | 处**5万元以下**罚款；主管人员处**1万元以下** |
| 有违法所得 | 并处没收违法所得 |
| 情节严重 | 责令停止执业或吊销资格 |
| 造成重大损失 | 吊销营业执照，责任人员终身市场禁入 |

## 消防技术服务机构规定（社会消防技术服务管理规定）

| 违规情形 | 处罚 |
|---|---|
| 冒用其他机构名义 | 处**2万-3万元**罚款（口诀：23盖帽） |
| 注册消防工程师同时两处执业；指派无资格人员；转包分包 | 处**1万-2万元**罚款（口诀：12人转） |
| 未设技术负责人、结论未签名盖章、未签合同、未建档案等 | 处**1万元以下**罚款 |
| 未公示服务信息 | 处**5000元以下**罚款 |

**档案保管**。消防技术服务档案保管期限为**6年**

## 其他处罚要点

### 注册消防工程师处罚（讲义314、321页）

| 违规情形 | 处罚 |
|---|---|
| 注册消防工程师**同时两处执业**（个人） | 处**5000元-1万元**罚款（机构层面为1万-2万元） |
| 隐瞒有关情况或提供虚假材料申请注册 | 不予受理/不予许可，**1年内**不得再次申请 |
| 聘用单位为不符合条件人员提供便利 | 处**1万-3万元**罚款 |
| 未经注册以注册消防工程师名义执业 | 处**1万-3万元**罚款 |

### 不合格消防产品处罚（讲义320页）

- 人员密集场所使用不合格或国家明令淘汰的消防产品 → 责令**限期改正**，逾期不改正处**5000元-5万元**罚款，直接负责的主管人员处**500-2000元**罚款
- 情节严重的 → 责令**停产停业**
- 生产者、销售者生产销售不合格消防产品 → 依《产品质量法》**从重处罚**

### 单位违反消防法7项行为处5000元-5万元（讲义320页）

| 序号 | 行为 |
|---|---|
| 1 | 消防设施、器材配置不符合标准或未保持完好有效 |
| 2 | 损坏、挪用、擅自拆除/停用消防设施器材 |
| 3 | 占用、堵塞、封闭疏散通道、安全出口 |
| 4 | 埋压、圈占、遮挡消火栓，占用防火间距 |
| 5 | 占用、堵塞、封闭消防车通道 |
| 6 | 门窗设置影响逃生和灭火救援的障碍物 |
| 7 | 火灾隐患不及时消除 |

- 单位有上述行为。处**5000元-5万元**罚款
- 个人有第**2/3/4/5**项行为。处警告或**500元以下**罚款
- 拒不改正的。可以强制拆除/清除，所需费用由行为人承担

### 警告或500元以下、情节严重5日以下拘留（讲义320-321页）

- 违规进入生产、储存易燃易爆危险品场所
- 违规使用明火作业、或在具有火灾爆炸危险场所吸烟、使用明火
- 处罚。警告或**500元以下**罚款；情节严重的处**5日以下**拘留

### 10-15日拘留可并处500元以下罚款（讲义321页，口诀"强拆阻乱伪过失"）

| 序号 | 行为 |
|---|---|
| 1 | 指使或强令他人冒险作业 |
| 2 | 过失引起火灾 |
| 3 | 阻拦报警，或负有报告职责的人员不及时报警 |
| 4 | 扰乱火灾现场秩序，或拒不执行火灾现场指挥员指挥 |
| 5 | 故意破坏或伪造火灾现场 |
| 6 | 擅自拆封或者使用被查封的场所、部位 |

处罚。处**10-15日拘留**，可以并处**500元以下**罚款

> 口诀"强拆阻乱伪过失"为助记，逐字对应以讲义原文为准。

### 电器产品、燃气用具违规（讲义321页）

- 电器产品、燃气用具的安装使用及线路管路的敷设维护保养不符合规定 → 责令**限期改正**，逾期责令**停止使用**，可以并处**1000-5000元**罚款

### 拒绝执行紧急命令、阻碍公务、阻碍消防车通行（讲义321页）

- 警告或**500元以下**罚款
- 情节严重的处**5-10日拘留**，可以并处**1000元以下**罚款

### 高层民用建筑消防安全管理规定（应急管理部令第5号）7种处罚情形（讲义315页，口诀"排队充值抢汉庭"）

| 序号 | 违规情形 |
|---|---|
| 1 | 电焊、气焊等动火作业未履行动火审批手续 |
| 2 | 户外广告牌、装饰物妨碍防烟排烟、逃生和灭火救援 |
| 3 | 未设置外墙外保温材料提示性/警示性标识 |
| 4 | 消防控制室值班制度不落实 |
| 5 | 未建立专职消防队、志愿消防队 |
| 6 | 停用消防设施未公告、未制定并演练应急预案 |
| 7 | 公共门厅、楼梯间停放/充电电动自行车拒不改正 |

- 经营性单位和个人。处**2000-10000元**罚款
- 非经营性单位和个人。处**500-1000元**罚款

> 口诀"排队充值抢汉庭"为助记，逐字对应以讲义原文为准。

### 高层建筑维护管理周期表（讲义318页）

| 项目 | 周期 |
|---|---|
| 高层公共建筑防火检查 | 每**半月**1次 |
| 分预案演练 | 每**半年**1次 |
| >100m超高层全要素演练 | 每**半年**1次 |
| ≤100m高层全要素演练 | 每**年**1次 |
| 消防安全评估 | 每**年**1次 |
| 消防安全培训 | 每**半年**1次 |

### 大型群众性活动（讲义282页）

- 未经公安机关安全许可举办大型群众性活动 → 予以**取缔**，对承办者处**10万-30万元**罚款

### 消防技术服务机构处罚补充（讲义313-314页）

- 实行积分信用管理
- 行政处罚由违法行为发生地**设区的市级、县级**消防救援机构决定
- 违反规定造成损失的，**从重处罚**
- 书面结论文件须由**技术负责人、项目负责人**签名盖章，并加盖**机构印章**；技术负责人须具备**一级注册消防工程师**资格

- 消防技术服务机构出具虚假文件的直接主管人员罚款。1万-5万元（真题高频）
- 到期不缴纳罚款。每日按罚款数额的3%加处罚款
- 人员密集场所工作人员不履行疏散义务，情节严重**尚不构成犯罪** → 拘留（5-10日）

## 与错题关联

以下错题涉及法规处罚（见 errors/items/ 中对应文件）：
- "消防技术服务机构出具虚假文件，对直接负责的主管人员应处（）罚款" → 1万-5万元
- "到期不缴纳罚款每日加处（）" → 按3%加罚

## 规范依据

- 消防法第58条。建设工程处罚（3万-30万档）。未经消防设计审查擅自施工、未经验收擅自投入使用、抽查不合格不停用、公众聚集场所未经许可擅自营业
- 消防法第59条。建设工程处罚（1万-10万档）。建设单位要求降低标准、设计单位不按强制性标准设计、施工企业降低施工质量、监理单位串通弄虚作假
- 消防法第69条。技术服务机构处罚
- 社会消防技术服务管理规定

## 考试出题角度

- 罚款金额区间判断（5-10万/1-5万/1-2万等）
- 责任主体（服务机构 vs 主管人员）
- 注销资格/终身禁入等严重处罚情形
