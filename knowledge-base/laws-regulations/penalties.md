# 法律法规与处罚

## 消防法处罚规定（核心记忆）

### 建设工程相关（第58条）

| 违法行为 | 处罚 |
|---|---|
| 未经消防验收擅自投入使用 | 责令改正/停止使用，处**1万-10万元**罚款 |
| 建设单位要求降低消防技术标准设计施工 | 责令改正或停止施工，处**1万-10万元**罚款 |
| 验收后未报备案 | 责令改正，处**5000元以下**罚款 |
| 公众聚集场所未经许可擅自营业 | 责令改正，处1万-10万元罚款 |

### 消防技术服务机构（第69条，易错点）

| 违法行为 | 处罚 |
|---|---|
| 不具备从业条件从事活动 或 出具虚假文件 | 处**5万-10万元**罚款；主管人员处**1万-5万元** |
| 不按国标行标开展技术服务 | 处**5万元以下**罚款；主管人员处**1万元以下** |
| 有违法所得 | 并处没收违法所得 |
| 情节严重 | 责令停止执业或吊销资格 |
| 造成重大损失 | 吊销营业执照，责任人员终身市场禁入 |

## 消防技术服务机构规定（社会消防技术服务管理规定）

| 违规情形 | 处罚 |
|---|---|
| 冒用其他机构名义 | 处**2万-3万元**罚款（口诀：23盖帽） |
| 注册消防工程师同时两处执业；指派无资格人员；转包分包 | 处**1万-2万元**罚款（口诀：12人转） |
| 未设技术负责人、结论未签名盖章、未签合同、未建档案等 | 处**1万元以下**罚款 |
| 未公示服务信息 | 处**5000元以下**罚款 |

**档案保管**。消防技术服务档案保管期限为**6年**

## 其他处罚要点

- 消防技术服务机构出具虚假文件的直接主管人员罚款。1万-5万元（真题高频）
- 到期不缴纳罚款。每日按罚款数额的3%加处罚款
- 人员密集场所工作人员不履行疏散义务，情节严重 → 拘留（5-10日）

## 与错题关联

以下错题涉及法规处罚（见 errors/items/ 中对应文件）：
- "消防技术服务机构出具虚假文件，对直接负责的主管人员应处（）罚款" → 1万-5万元
- "到期不缴纳罚款每日加处（）" → 按3%加罚

## 规范依据

- 消防法第58条。建设工程处罚
- 消防法第69条。技术服务机构处罚
- 社会消防技术服务管理规定

## 考试出题角度

- 罚款金额区间判断（5-10万/1-5万/1-2万等）
- 责任主体（服务机构 vs 主管人员）
- 注销资格/终身禁入等严重处罚情形
