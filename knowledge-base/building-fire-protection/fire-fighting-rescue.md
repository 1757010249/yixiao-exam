# 灭火救援设施

## 消防救援口（GB 50016-2014 第7.2.4、7.2.5条）

| 项目 | 要求 |
|---|---|
| 数量 | 每个**防火分区**不应少于 **2 个** |
| 设置位置 | 厂房、仓库、公共建筑的外墙应每层设置；无外窗时应每层设置 |
| 层数 | 有外窗的建筑，消防救援口自**第三层**起设置（一层、二层可利用外窗/门） |
| 净高、净宽 | 窗口净高和净宽均 ≥**1.0m**；采用门的净宽度 ≥**0.8m** |
| 下沿高度 | 窗口下沿距室内地坪 ≤**1.2m** |
| 间距 | 消防救援口沿外墙的间距 ≤**20m** |
| 开启 | 应易于从室内和室外开启（从室外易于击碎玻璃/开启） |

## 消防电梯设置条件（GB 50016-2014 第7.3.1条）

口诀"**铁道城管无人机，不设消防电梯**"。下列建筑应设置消防电梯：

1. **住宅建筑**。建筑高度 >**33m** 的住宅建筑
2. **老年人照料设施**。**5 层及以上且总建筑面积 >3000㎡** 的老年人照料设施
3. **一类高层公共建筑**及建筑高度 >**32m** 的二类高层公共建筑
4. **丙类高层厂房**。建筑高度 >**32m** 且设置电梯的**丙类高层厂房**（仓库）
5. **汽车库**。设置消防电梯的建筑的地下、半地下室（**封闭或半封闭汽车库** >32m 时）
6. **地下/半地下**。埋深 >**10m** 且总建筑面积 >**3000㎡** 的地下或半地下建筑（室）

## 消防电梯前室（GB 50016-2014 第7.3.5条）

| 项目 | 要求 |
|---|---|
| 前室面积 | 单独设置时 ≥**6.0㎡**；短边净长 ≥**2.4m** |
| 前室门 | 采用**乙级**防火门（前室或合用前室不应设置防火卷帘） |
| 直通室外 | 首层前室直通室外，或经长度 ≤**30m** 的通道直通室外 |
| 隔墙 | 前室与走道之间采用耐火极限 ≥**2.00h** 的防火隔墙分隔 |
| 合用前室 | 与防烟楼梯间前室合用时的面积要求按疏散规范执行（住宅合用 ≥6.0㎡、公共 ≥10㎡等） |

## 消防电梯井底排水（GB 50016-2014 第7.3.7条）

- 消防电梯的井底应设置排水设施
- 排水井容量不应小于 **2m³**
- 排水泵的排水量不应小于 **10L/s**

## 消防电梯技术参数

| 项目 | 要求 |
|---|---|
| 载重量 | ≥**800kg**（满足消防队员及器材运输） |
| 运行时间 | 从**首层到顶层**的运行时间 ≤**60s** |
| 防水等级 | 电机防护等级不低于 **IPX5**（耐水冲洗） |
| 轿厢尺寸 | 轿厢内长、宽 ≥**1.5m × 2m**（便于担架、器材进入） |
| 通讯 | 轿厢内设置专用消防电话，与消防控制室、值班室通讯 |
| 供电 | 消防电梯的供电应满足消防供电要求，双回路电源 |
| 梯井 | 消防电梯井底排水、井道防火分隔按规范执行 |

## 直升机停机坪（GB 50016-2014 第7.4.1、7.4.2条）

- 建筑高度 **>250m** 的公共建筑宜设置直升机停机坪（或供直升机救助的设施）
- **平面尺寸**（按直升机旋翼直径 D 确定）：
  - 圆形或方形平面。直径（边长）不应小于直升机旋翼直径的 **1.5 倍**（D×1.5）
  - 矩形平面。短边不应小于直升机旋翼（机翼）的长度（机轮尺寸）
- **出口**。每个停机坪设置出口不少于 **2 个**，每个出口宽度 ≥**0.90m**，且不应小于直升机停机坪的1/4周长均匀布置（口。不少于2个，每个≥0.90m）
- **净空**。停机坪外 **5m** 范围内不应设置凸出物（天线、广告牌等）
- **标志与照明**。四周设置**航空障碍灯**和应急照明（地面设置应急照明，灯光标志保证夜间救助）
- **消防设施**。停机坪设置**消火栓**（航空煤油火灾扑救），并设应急灭火设施
- 停机坪应设置安全出口与疏散楼梯直接连通

## 规范依据

- GB 50016-2014 第7.2.4、7.2.5条。消防救援口
- GB 50016-2014 第7.3.1条。消防电梯设置范围
- GB 50016-2014 第7.3.3条。消防电梯前室
- GB 50016-2014 第7.3.4条。消防电梯轿厢与排水
- GB 50016-2014 第7.3.5条。前室面积与门
- GB 50016-2014 第7.3.6条。消防电梯井底排水
- GB 50016-2014 第7.3.7条。消防电梯排水泵
- GB 50016-2014 第7.4.1、7.4.2条。直升机停机坪

## 易错点 / 陷阱

- 消防救援口净高宽 ≥1.0m、门净宽 ≥0.8m；下沿 ≤1.2m；间距 ≤20m
- 消防电梯口诀"铁道城管无人机"。>33m 住宅、5 层且 >3000㎡ 老照、一类高层及 >32m 二类高层公共、>32m 丙类高层厂房、>32m 汽车库、埋深 >10m 且 >3000㎡ 地下
- 前室短边 ≥2.4m 常考；前室不能用防火卷帘
- 排水井 ≥2m³、排水泵 ≥10L/s
- 消防电梯载重 ≥800kg、首层至顶层 ≤60s、IPX5、轿厢 ≥1.5m×2m
- 停机坪圆形 1.5 倍旋翼直径、出口 ≥2 个每个 ≥0.90m、外 5m 无凸出物

## 考试出题角度

- 实务。消防电梯设置条件、消防救援口尺寸、停机坪尺寸
- 综合。消防电梯检查（载重、前室、排水）、救援窗检查
- 案例。高层建筑灭火救援设施是否齐全
