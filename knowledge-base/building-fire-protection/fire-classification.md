# 火灾危险性分类

## 核心判定标准（记忆起点）

| 类别 | 液体（闪点） | 气体（爆炸下限） | 固体 |
|---|---|---|---|
| 甲 | 闪点 < 28℃ | 爆炸下限 < 10% | 遇水/氧化剂反应剧烈等 |
| 乙 | 28℃ ≤ 闪点 < 60℃ | 爆炸下限 ≥ 10% | 可燃固体中的危险品 |
| 丙 | 闪点 ≥ 60℃ | - | 可燃固体 |
| 丁 | - | - | 难燃物质；高温熔融产生辐射热 |
| 戊 | - | - | 不燃物质 |

## 厂房分类口诀（奇门遁甲）

**甲类口诀**：缺心眼琳姐拿次假酒进出车间，过来将要亲甲乙丙丁被削死
- 缺=乙炔站；心=乙烯、氯乙烯、苯乙烯、丁二烯、醋酸乙烯；眼=液化石油气罐瓶间、**天然气**
- 琳=赤磷制备；**五硫化二磷厂房及其应用部位、三氧化磷厂房、五氧化二磷厂房**
- 姐=洗涤剂石蜡裂解、冰醋酸裂解、**电解水或**电解食盐厂房
- 拿次=金属钠钾、次氯酸钙
- 酒=白酒**液态法**酿酒车间、酒精蒸馏塔、酒精度38度及以上**勾兑/灌装车间、酒泵房**；白兰地蒸馏/勾兑/灌装车间、酒泵房
- 进出=植物油浸出车间；过来=**过氧化氢厂房，过氧化钠、过氧化钾厂房**；来（所）=**氯酸钠、氯酸钾、氯乙醇**；将=橡胶涂胶胶浆
- 要=农药乐果敌敌畏、**青霉素提炼部位，原料药厂的非纳西丁车间的烃化**
- 亲=氢气；甲乙丙丁=甲醇乙醇丙酮丁酮异丙醇
- 被=苯合成；削=硝化棉；死=赛璐珞

**乙类口诀**：张老炮养一金发高个面瘫美女没有空回家过除夕，送俺
- 张老=樟脑/松香提炼、**樟脑油提取部位**；炮养=金属抛光/氧气站
- 一=一氧化碳压缩机及净化；金发=发生炉煤气净化、**鼓风炉煤气净化部位**
- 高个=高锰酸钾/重铬酸钠；面瘫=面粉研磨/活性炭
- 美女=铝粉镁粉；没有空=煤油煤粉/空分厂房
- 回=硫黄回收；送俺=松节油松香蒸馏、氨压缩机房

**丙类口诀**：经历同干变压器，笨甲陪笨乙吃煤炭鸡鸭滑
- 经历=植物油精炼/沥青加工；同干=桐油甘油；变压器=油浸变压器室
- 笨甲=苯甲酸；陪=配电室(油>60kg)；笨乙=苯乙酮
- 吃=鱼加工/食品加工；煤炭=煤碳；鸡=机器油；鸭=橡胶压延硫化；滑=润滑油

**丁类口诀**：全保温电石炉热蒸锅失恋
- 全=酚醛泡沫塑料加工；保温=保温瓶胆；电石炉=电石炉转炉
- 热=金属热处理冶炼锻造；蒸=蒸汽机车库；锅=锅炉房；恋=印刷厂漂炼

**戊类口诀**：捐助专车盖一栋水泥石佛
- 捐=卷扬机室；助=造纸浆粕蒸煮；专车=制砖/车辆装配
- 盖=钙镁磷肥车间；一=仪器仪表装配；栋=电动车库
- 水泥=水泥厂；石=石棉加工；佛=氟利昂

## 判定规则

- **基本规则**：同一厂房有多种火灾危险性生产时，按火灾危险性较大的确定
- **特殊情况1**：较大危险性部分占本层/防火分区面积 <5%（或丁戊类厂房油漆工段 <10%），且不蔓延、有防火措施时，可按较小的确定
- **特殊情况2**：丁戊类厂房油漆工段采用封闭喷漆+负压+探测报警/抑爆系统（自可负闭），且 ≤20% 时，可按较小的确定

## 仓库分类要点

- 储存物品分类与生产分类不同，**储存按物品储存时的危险性**
- 漂白粉仓库=乙类（判断时注意与厂房区别）
- 白兰地成品库=丙类、赛璐珞板仓库=乙类
- 硝酸铜=乙类、赤磷=甲类（储存）
- **高架仓库**。货架高度>7m，且机械化操作或自动化控制的货架仓库
- **同一座仓库多物品**。按火灾危险性最大的物品确定

### 仓库易混淆点（高频陷阱）

| 物品 | 类别 | 对比说明 |
|---|---|---|
| 硝化纤维胶片 | 甲 | 与色片/漆布对比 |
| 硝化纤维色片 | 乙 | 胶片为甲 |
| 硝化纤维漆布 | 乙 | 胶片为甲 |
| 硫磺 | 乙 | - |
| 粒径≥2mm 工业成型硫磺 | 丙 | 颗粒状降低危险性 |
| 醋酸甲酯 | 甲 | - |
| 醋酸丁酯 | 乙 | - |
| 硝酸乙酯 | 甲 | - |
| 硝酸戊酯 | 乙 | - |
| 漆布/油布/油纸/油绸及制品 | 乙（储存） | 甘油桐油生产场所为丙 |
| 糖醛 | 丙（仓库） | - |
| 石脑油 | 甲（仓库） | - |
| 陶瓷制品 | 戊（仓库） | 陶瓷烘干厂房为丁类 |

### 生产 vs 储存（分类不同，易错）

| 物品 | 生产（厂房） | 储存（仓库） |
|---|---|---|
| 次氯酸钙 | 甲 | 漂白粉=乙 |
| 面粉 | 面粉研磨=乙 | 面粉=丙 |
| 白兰地 | 灌装=甲 | 成品库=丙 |
| 冰醋酸 | 裂解=甲 | 储存=乙 |

### 丁戊类储存包装规则（口诀：重4体2）

可燃包装重量>物品本身重量 **1/4** 或体积> **1/2** 时，按丙类确定

### 甲类仓库 3、4 项口诀：青金荒郊三七火化

- 青=氢化锂、氢化钠；金=金属钾、钠、锂、钙、锶
- 荒=黄磷；郊=硝化纤维胶片
- 三=赛璐珞棉；七=喷漆棉；火=火胶棉；化=硝化棉

### 乙类仓库 2、5、6 项口诀：潜（气）布油纸绸

- 漆布、油布、油纸、油绸

### 各仓库分类明细（P55-57）

- **甲类**（1-6项）。详见口诀"青金荒郊三七火化"及 3.1.3 条规定
- **乙类**。乙炔、氢气、发烟硫酸、硝酸等；**漆布/油布/油纸/油绸及制品**
- **丙类**。动物油、植物油、沥青、蜡、润滑油、机油、重油、闪点≥60℃柴油、糖醛、白兰地成品库等
- **丁类**。自熄性塑料、酚醛泡沫塑料、水泥刨花板
- **戊类**。钢材、铝材、玻璃、陶瓷、不燃气体、玻璃棉、岩棉、矿棉、水泥、石等

## 考试出题角度

- 给具体厂房名称判断火灾危险性类别（甲/乙/丙/丁/戊）
- 给闪点/爆炸下限判断类别
- 混合生产车间的类别判定（面积百分比规则）
- 生产 vs 储存分类差异对比
