# 汽车库、修车库、停车场防火

## 一、防火分类

| 名称 | Ⅰ类 | Ⅱ类 | Ⅲ类 | Ⅳ类 |
|---|---|---|---|---|
| 汽车库（车位数） | >300 | 151~300 | 51~150 | ≤50 |
| 汽车库（总面积S m²） | S>10000 | 5000<S≤10000 | 2000<S≤5000 | S≤2000 |
| 修车库（车位数） | >15 | 6~15 | 3~5 | ≤2 |
| 修车库（总面积S m²） | S>3000 | 1000<S≤3000 | 500<S≤1000 | S≤500 |
| 停车场（车辆数） | >400 | 251~400 | 101~250 | ≤100 |

注：①屋面露天停车场与下部汽车库共用坡道时车位数计入总数 ②室外坡道、屋面露天停车场面积不计入建筑面积 ③**公交汽车库建筑面积可增加2.0倍**

## 二、按建筑高度等方式分类

- **地下汽车库**：室内地坪与室外地坪高差>该层净高1/2
- **高层汽车库**：建筑高度>24m，或设在高层建筑内地面层以上楼层
- **机械式立体汽车库**：室内无车道且无人员停留，机械设备垂直/水平移动停放
- **复式汽车库**：室内有车道有人员停留，机械设备叠放2~3层
- 敞开式 / 封闭式（按围封形式）

## 三、耐火等级

| 类型 | 耐火等级 |
|---|---|
| 地下/半地下/高层汽车库；甲乙类物品运输车的汽车库修车库；Ⅰ类汽车库修车库 | **一级** |
| Ⅱ、Ⅲ类汽车库修车库 | 不低于二级 |
| Ⅳ类汽车库修车库 | 不低于三级 |

## 四、平面布置

### 禁止与限制

- 不应布置在易燃可燃液体/气体生产装置区和贮存区内
- 不应与甲乙类厂房仓库贴邻或组合建造
- 不应与托儿所幼儿园、老年人建筑、中小学校教学楼、病房楼组合建造；设在上述建筑地下部分时：≥2.00h楼板完全分隔+安全出口和疏散楼梯分别独立设置
- **地下/半地下汽车库内不应设**修理车位、喷漆间、充电间、乙炔间和甲乙类物品库房（口诀：**甲乙一休喷电**的地下禁令）
- 库内不应设汽油罐、加油机、LPG/LNG储罐、加气机（油气不进汽车库修车库）
- 停放易燃液体/LPG罐车的汽车库内不得设地下室和地沟
- 燃油燃气锅炉、油浸变压器等不应设在库内

### 可贴邻的附属建筑（口诀155122）

用防火墙隔开+直通室外安全出口：
1. 贮存量≤**1.0t** 的甲类物品库房
2. 总安装容量≤5.0m³/h 的乙炔发生器间和≤5个标准钢瓶的乙炔气瓶库
3. 1车位非封闭喷漆间或≤2车位封闭喷漆间
4. ≤200m² 充电间和其他甲类生产场所

## 五、防火分区

| 类型 | 最大允许建筑面积(m²) |
|---|---|
| 一二级耐火·单层 | 3000 |
| 一二级耐火·多层/半地下 | 2500 |
| 一二级耐火·地下/高层 | 2000 |
| 三级耐火·单层 | 1000（多层/地下不允许） |
| 甲乙类物品运输车汽车库修车库 | ≤500 |
| 修车库 | ≤2000（修车部位与喷漆工段防火墙分隔时≤4000） |

- 敞开式/错层式/斜楼板式上下连通层面积叠加计算，每个防火分区可为表值**2.0倍**
- 复式汽车库按表值**减少35%**
- 设自动灭火系统时可为表值2.0倍

## 六、安全疏散

- 人员安全出口与汽车疏散出口**分开设置**
- 每个防火分区人员安全出口≥2个（Ⅳ类汽车库和Ⅲ、Ⅳ类修车库可1个）
- 疏散楼梯：>32m高层汽车库、地坪高差>10m地下汽车库→防烟楼梯间；其他→封闭楼梯间；楼梯间前室门甲级并向疏散方向开启；梯宽≥1.1m
- 与住宅地下室连通的地下车库可借用住宅疏散楼梯（不能直接进入时设连通走道：防火隔墙+甲级门）
- 疏散距离：室内任一点至最近人员安全出口≤45m（设自喷≤60m）；单层或首层≤60m
- 汽车疏散出口总数≥2个分散布置；可设1个的条件：①Ⅳ类汽车库 ②双车道Ⅲ类地上汽车库 ③双车道+停车≤100辆+面积<4000m²的地下半地下汽车库 ④Ⅱ/Ⅲ/Ⅳ类修车库
- 汽车疏散坡道：单车道≥3.0m、双车道≥5.5m
- Ⅳ类汽车库可用汽车专用升降机代替坡道：≥2台（停车<25辆可1台）
- 室内无车道无人员停留的机械式汽车库可不设人员安全出口，但每个停车区域>100辆应设1个灭火救援楼梯间（防火隔墙+甲级门、净宽≥0.9m）
- >32m汽车库应设消防电梯（机械式除外）

## 七、消防设施

| 设施 | 设置场所 |
|---|---|
| 自动灭火系统（除敞开式/屋面停车场外应设） | Ⅰ/Ⅱ/Ⅲ类地上汽车库；停车>10辆的地下半地下汽车库；机械式汽车库；专用升降机作出口的汽车库；Ⅰ类修车库（口诀：**1231吓死两个鸡**） |
| 泡沫-水喷淋系统（宜采用） | Ⅰ类地下半地下汽车库；Ⅰ类修车库；停车>100辆的无车道无人停留机械式汽车库（口诀：**1下1修100无人机**） |
| 其他系统 | 地下半地下汽车库可采用高倍数泡沫；停车≤50辆机械式可用CO₂等气体灭火 |
| 火灾自动报警系统 | Ⅰ类汽车库修车库；Ⅱ类地下半地下汽车库修车库；Ⅱ类高层汽车库修车库；机械式汽车库；专用升降机作出口的汽车库（口诀：**1全2高下2个鸡**） |
| 排烟系统 | 除敞开式和<1000m²地下一层外均应设；防烟分区≤2000m²不跨越防火分区（挡烟垂壁/隔墙/梁≥0.5m）；排烟量按净高查表30000~40500m³/h（净高3m以下30000起） |
| 应急照明 | 除停车≤50辆和机械式外均应设；地面最低照度≥1.0lx；蓄电池连续供电≥30min；指示标志间距≤20m、距地1m以下墙面 |
| 灭火器 | 除机械式外均应配置（GB 50140） |

- 火灾延续时间：**2.00h**（自喷1.00h、泡沫0.50h）
- 临时高压给水系统的屋顶消防水箱≥12m³
- 无车道无人停留机械式汽车库：>100辆用无门窗洞口防火墙分隔为≤100辆区域（防火隔墙+≥1.00h楼板分成≤3辆单元时可放宽至≤300辆区域）；应设火灾自动报警+自动喷水（快速响应喷头）；楼梯间及检修通道设消火栓；排烟口在通道顶部
- 合建分隔：贴邻建造用防火墙；设在建筑物内用防火墙+≥2.00h不燃楼板；外墙门窗洞口上方≥1.00h宽≥1.0m防火挑檐；上下层开口间墙高≥1.2m或1.00h宽≥1.0m挑檐

### 电动汽车充电站补充

- 充电站独立防火分区：一二级耐火 单层1500 / 多层1250 / 地下高层1000（约为汽车库一半；设自喷增1.0倍）
- 充电区消火栓沿周边设置，距最近一排充电位不宜小于7m
- 室外无人值守充电站应设火灾报警装置（可采用图像火灾报警）；灭火器严重等级 ABC5/6 干粉
- 一二三级充电站与重要公共建筑物主要出入口安全间距≥50m

## 易错点 / 陷阱

- 复式汽车库减35% vs 敞开式/错层式/斜楼板式加到2倍——方向相反
- 自动灭火"应设"口诀1231吓死两个鸡 vs 报警"应设""1全2高下"，两组场所不同
- 疏散距离45/60 与地铁车库45/60 数字巧合但规范不同
- 汽车疏散出口4种"可设1个"情形常考多选

## 记忆方法

- 分类数字链：汽车库 50/150/300 辆、2000/5000/10000 m²；修车库 2/5/15 位
- 口诀：**甲乙一休喷电**（可贴邻附属建筑：甲类1t、乙炔5瓶、喷漆间、充电间200m²）
- 口诀：**1下1修100无人机**（泡沫水喷淋）；**1231吓死两个鸡**（自动灭火）；**1全2高下**（火灾报警）

## 规范依据

- GB 50067-2014《汽车车库、修车库、停车场设计防火规范》第3章（防火分类和耐火等级）、第4章（总平面布局和平面布置）、第5章（防火分隔和建筑构造）、第6章（安全疏散和救援设施）、第7章（消防给水和灭火设施）、第8章（供暖通风和排烟）、第9章（电气）

## 考试出题角度

- **实务**。防火分类判定（给车位/面积定Ⅰ~Ⅳ类）、耐火等级对应、消防设施设置场所判断
- **案例**。地下汽车库防火分区叠加计算、疏散出口数量判断
