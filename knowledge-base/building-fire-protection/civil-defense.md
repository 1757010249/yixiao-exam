# 人防工程防火

## 一、平面布置限制

| 场所 | 要求 |
|---|---|
| 燃料使用 | **不得使用和储存**液化石油气、相对密度≥0.75 的可燃气体和闪点<60℃的液体燃料 |
| 儿童及残疾场所 | 不应设置哺乳室、托儿所、幼儿园、游乐厅等儿童活动场所和残疾人员活动场所 |
| 医院病房 | 不应设在地下二层及以下；设在地下一层时室内地面与室外出入口地坪高差≤**10m** |
| 歌舞娱乐放映游艺 | 不应设在地下二层及以下；地下一层时高差≤10m；一个厅室建筑面积≤200m² |
| 油浸设备 | 不得设置油浸电力变压器和其他油浸电气设备 |
| 旅店/病房/员工宿舍 | 不得设在地下二层及以下；独立防火分区；疏散楼梯不得与其他防火分区共用 |
| 消防控制室 | 应设地下一层并邻近直通地面安全出口；可与值班室、变配电室合用；可与地面建筑消防控制室合用 |

## 二、地下商店

1. 不应经营和储存甲、乙类储存物品属性的商品
2. 营业厅不应设置在地下三层及以下
3. 总建筑面积 >**20000m²** 时应采用防火墙分隔（墙上不开门窗洞口）；需局部连通时选择：①下沉式广场等室外开敞空间 ②防火隔间（墙为实体防火墙）③避难走道 ④防烟楼梯间（前室门为火灾时自动关闭的常开甲级防火门）

## 三、防火分区

- 应采用防火墙划分；确有困难可用防火卷帘等分隔
- 无可燃物房间（水泵房、污水泵房、水池、厕所、盥洗间）面积不计入
- 柴油发电机房/锅炉房配套的水泵间、风机房、储油间与其划为同一防火分区
- 防火分区划分宜与防护单元相结合

| 场所 | 防火分区最大面积 |
|---|---|
| 一般 | ≤**500m²**；设自动灭火系统时增加1倍（局部设置按局部面积1倍） |
| 商业营业厅/展览厅（有报警+自喷+A级装修） | ≤**2000m²** |
| 电影院/礼堂观众厅 | ≤**1000m²**，**设有报警+自喷也不得增加** |
| 冰场/游泳池/靶道区/球道区 | 面积不计入防火分区；装修A级 |

## 四、防火分隔构造

| 部位 | 要求 |
|---|---|
| 观众厅与舞台之间墙 | ≥**2.5h**；放映室隔墙≥1h，观察窗放映孔设阻火闸门 |
| 设备用房（消控室/水泵房/排烟机房/灭火剂储瓶室/变配电室/通信机房/通风空调机房/火灾荷载>30kg/m²房间） | ≥2h 隔墙 + ≥1.5h 楼板 + 常闭甲级防火门 |
| 柴油机房储油间 | 同上 + 高**150mm**不燃不渗漏门槛 + 地面不得设地漏 |
| 同一分区厨房食品加工 | ≥2h 隔墙 + ≥1.5h 楼板 + ≥乙级门；频繁出入设常开式防火门 |
| 歌舞娱乐厅室 | ≥2h 隔墙 + ≥1.5h 楼板 + ≥乙级门；厅室≤200m² |
| 管道穿越 | 可燃气体和丙类液体管道严禁穿过防火分区之间防火墙（柴油机房/燃油锅炉房储油间与机房间的除外） |

## 五、避难走道与下沉式广场

### 避难走道

- 两侧为实体防火墙，仅用于人员安全通行至室外
- 直通地面出口≥2个且不同方向；只与一个防火分区相通时可设1个（该分区至少有1个不通向避难走道的出口）
- 净宽≥容纳人数最多一个防火分区通向避难走道各安全出口最小净宽之和
- 装修 A 级；设消火栓、应急照明、应急广播、消防专线电话
- 入口前室面积≥**6m²**，前室门为甲级防火门

### 下沉式广场

- 不同防火分区通向下沉广场安全出口最近边缘水平距离≥**13m**；疏散区域净面积≥**169m²**
- ≥1个直通地坪疏散楼梯，总宽度≥相邻最大防火分区计算疏散总宽度
- 防风雨棚不得封闭：四周敞开面积>投影面积25%（计算值>40m² 可取40m²）；敞开高度≥1m；百叶有效通风排烟面积按洞口面积60%计

## 六、安全疏散

- 房间内最远点至房间门≤**15m**
- 房间门至最近安全出口：医院 **24m**、旅馆 **30m**、其他工程 **40m**；袋形走道两侧或尽端为上述一半
- 大空间（观众厅/展览厅/多功能厅/餐厅/营业厅/阅览室）：室内任一点至最近安全出口≤30m，设自喷可增加25%
- 安全出口同方向设置时最近边缘水平距离≥5m
- 歌舞娱乐：不宜布置在袋形走道两侧或尽端；必须时最远房间疏散门到安全出口≤9m；>50m²厅室疏散出口≥2个

## 七、消防设施

| 项目 | 要求 |
|---|---|
| 消防供电 | >5000m² 一级负荷；≤5000m² 可二级负荷 |
| 疏散照明 | 地面最低照度≥5lx；蓄电池连续供电≥30min |
| 备用照明 | >5000m² 宜保持正常照度；≤5000m² 不低于正常照度50% |
| 疏散标志 | 沿墙面距地≤1m、间距≤15m；走道上方下边缘距地≤2.5m；地面灯光型间距≤3m、蓄光型≤2m |
| 火灾自动报警 | >500m² 地下商店/展览厅/健身体育场所；>1000m² 丙丁类生产车间和库房；重要通信机房/电子计算机房/柴油发电机房/变配电室/重要实验室/图书资料档案库；歌舞娱乐放映游艺场所 |
| 防烟分区 | ≤500m²（室内净高>6m不受限）；不得跨越防火分区；挡烟垂壁/隔墙/突出顶棚≥0.5m的梁划分 |

## 易错点 / 陷阱

- 电影院观众厅 1000m² **任何情况下不得增加** vs 商业营业厅 2000m²（条件满足才可）
- 观众厅与舞台隔墙 **2.5h**（高于一般设备用房2h）
- 医院病房与歌舞娱乐都是"地下二层以下禁+地下一层高差≤10m"，但医院是"不应"、歌舞娱乐也是"不应"
- 下沉广场：13m / 169m² / 敞开25%（>40m²取40）/ 高度1m / 百叶60%

## 记忆方法

- 疏散距离"医24旅30其他40"，袋形减半
- 报警设置面积线：商店500、车间库房1000

## 规范依据

- GB 50098-2009《人民防空工程设计防火规范》第3章（总平面布局和平面布置）、第4章（防火防烟分区）、第5章（安全疏散）、第6章（防排烟）、第7章（消防给水排水灭火设施）、第8章（电气）

- **实务**。防火分区面积（500/2000/1000）、疏散距离数字、下沉式广场参数
