# 安全疏散

## 人员密度（计算疏散人数的起点）

**口诀：录像1、展览0.75、歌0.5**（录像厅/歌舞展览是面积×密度，办公室是面积÷密度）

| 场所 | 人员密度 |
|---|---|
| 录像厅 | 1.0 人/㎡ |
| 展览馆 | 0.75 人/㎡ |
| 歌舞娱乐 | 0.5 人/㎡ |
| 商店-地下二层 | 0.56 人/㎡ |
| 商店-地下一层 | 0.60 人/㎡ |
| 商店-地上一二层 | 0.43-0.60 人/㎡ |
| 商店-三层 | 0.39-0.54 人/㎡ |
| 商店-四层及以上 | 0.30-0.42 人/㎡ |

**调整系数**：建材灯饰家具商店 ×0.3；餐饮座位 ×1.1

**密度取大小（按建筑面积对比3000㎡）**：商店人员密度区间取值的分界依据是建筑面积——大于3000㎡取区间小值，小于3000㎡取区间大值（讲义 1号书 P6042"建筑规模较小（营业厅总建筑面积<3000㎡）时宜取上限值，规模较大时可取下限值"）

**办公室计算示例**（面积÷密度）
- 普通办公室 6㎡/人、研究工作室 7㎡/人、手工绘图室 6㎡/人
- 会议室有桌 2㎡/人、无桌 1㎡/人

## 疏散宽度计算（4步法）

计算四步骤。查人数 → 查百人指标 → 算宽度 → 校验部位

### 百人疏散宽度指标

| 楼层 | 一二级 | 三级 | 四级 |
|---|---|---|---|
| 1-2层 | 0.65 | 0.75 | 1.00 |
| 3层 | 0.75 | 1.00 | - |
| ≥4层 | 1.00 | 1.25 | - |

**地下商店百人指标 1.0**

**地下部分百人指标**
- 地下非人员密集场所且高差≤**10m** → 取 **0.75**；高差>**10m** → 取 **1.00**
- 地下**人员密集场所**无论高差多少 → 取 **1**
- **一个建筑的百人指标只有一个**，地上地下可不同（P172、P175）

**厂房百人疏散宽度指标（每100人，m）**

| 楼层 | 指标 |
|---|---|
| 1-2层 | 0.6 |
| 3层 | 0.8 |
| 4层及以上 | 1.0 |

**厂房疏散宽度底线（口诀：8111）**
- 厂房出口 **0.8m**、走道 **1.1m**、楼梯 **1.1m**、首层外门 **1.1m**

### 疏散走道/楼梯最小净宽（高层其他公共建筑）

| 部位 | 最小净宽 |
|---|---|
| 外门 | ≥1.2m |
| 单面布房走道 | ≥1.3m |
| 双面布房走道 | ≥1.4m |
| 楼梯 | ≥1.2m |

**完整民用最小净宽表（P163-165）**

| 建筑类型 | 外门 | 安全出口 | 单面走道 | 双面走道 | 楼梯 |
|---|---|---|---|---|---|
| 单多层公共建筑 | 1.1 | 0.8 | 1.1 | 1.1 | 1.1（口诀：8111） |
| 住宅 | 1.1 | 0.8 | 1.1 | 1.1 | 1.1（≤18m 且一边有栏杆的楼梯可放宽至 1.0m） |
| 高层公共（其他） | 1.2 | 0.8 | 1.3 | 1.4 | 1.2 |
| 高层医疗 | 1.3 | 0.8 | 1.4 | 1.5 | 1.3（除出口外，其他在高层其他公共基础上 +0.1） |

> 说明。单多层公共/住宅的"8111"口诀对应：出口0.8、外门/走道/楼梯1.1。高层其他公共与高层医疗为主要考点

### 人员密集场所疏散宽度（P164）

- 人员密集公共场所的疏散门净宽≥**1.4m**，紧靠门口内外各 **1.4m** 范围内不应设踏步
- 室外疏散通道净宽≥**3.00m**，并应直通宽敞地带
- 疏散楼梯、台阶、坡道净宽>**4.0m** 时，应设扶手栏杆分隔为≤**2.0m** 的区段

## 疏散距离

### 电影院、剧场百人指标与座位布置（P173）

**观众厅内疏散走道**。每 100 人不小于 **0.60m** 且不应小于 **1.00m**；边走道≥**0.80m**

**剧场、电影院、礼堂每100人最小疏散净宽（m）**

| 座位数/耐火等级 | 门和疏散走道（平坡地面） | 门和疏散走道（阶梯地面） | 疏散楼梯 |
|---|---|---|---|
| ≤2500座（一二级） | 0.65 | 0.75 | 0.75 |
| 1200座（三级） | 0.85 | 1.00 | 1.00 |

**观众厅座位布置**
- 横走道之间的座位排数 ≤**20排**
- 纵走道之间的座位数。剧场、电影院、礼堂等 ≤**22个**；体育馆 ≤**26个**
- 排距≥**0.90m** 时可增加 1.0 倍，但不超过 **50个**
- 仅一侧有纵走道时，座位数减半

### 厂房疏散距离（设置自喷不增加）

|---|---|---|---|---|---|
| 甲类 | 一二级 | 30m | 25m | - | - |
| 乙类 | 一二级 | 75m | 50m | 30m | - |
| 丙类 | 一二级 | 80m | 60m | 40m | 30m |
| 丙类 | 三级 | 60m | 40m | - | - |

### 民用建筑疏散距离（带自喷×1.25）

### 疏散距离加减规则（P178-181）

- **加5m情形**。**敞开式外廊**直接相连的房间，疏散距离可**+5m**（68题考点：三级耐火多层办公，袋形走道两侧房间，房间内20m+袋形走道20m+外廊加成5m=45m）
- **减5m情形**。直通疏散走道的房间疏散门至最近**敞开楼梯间**的直线距离，当房间位于**两个楼梯间之间**时减少 5m
- **减2m情形**。当房间位于**袋形走道两侧或尽端**时减少 2m
- **内疏散距离**。房间内任一点至疏散门的距离 = 袋形走道距离，**没有加减，只有 ×1.25**
- **运算顺序**。先乘（×1.25）再加减

### 商展多功能厅 30/10（P182-183）

- 一、二级耐火等级、疏散门或安全出口≥2个的**观众厅、展览厅、多功能厅、餐厅、营业厅等**（商展多功能厅），室内任一点至最近疏散门≤**30m**
- 疏散门不能直通室外地面或楼梯间时，应采用长度≤**10m** 的疏散走道通至最近的安全出口
- 设置自动喷水灭火系统时，分别 ×1.25（30×1.25、10×1.25）

## 住宅安全出口设置

| 建筑高度 | 1个安全出口条件 |
|---|---|
| H≤27m | 每单元每层建筑面积≤650㎡，且任一户门至最近安全出口≤15m |
| 27<H≤54m | 每单元每层建筑面积≤650㎡，且任一户门至最近安全出口≤10m；1个疏散楼梯应通至屋面且单元间楼梯可经屋面连通；户门耐火完整性≥1h |
| H>54m | 不可设置1个安全出口（必须设2个） |

## 厂房 1 个安全出口条件（P190-191）

| 厂房类别 | 条件 |
|---|---|
| 甲类 | 每层建筑面积≤100㎡，且同一时间作业人数≤**5人** |
| 乙类 | 每层≤150㎡，且作业人数≤**10人** |
| 丙类 | 每层≤250㎡，且作业人数≤**20人** |
| 丁戊类 | 每层≤400㎡，且作业人数≤**30人** |
| 丙类（地下/半地下） | ≤50㎡，且人数≤**15人** |
| 丁戊类（地下/半地下） | ≤200㎡，且人数≤**15人** |

## 仓库安全出口（P191-192）

- 每座仓库安全出口≥**2个**；占地面积≤**300㎡** 时可设 1 个
- 每个防火分区通向疏散走道、楼梯、室外的出口≥**2个**；建筑面积≤**100㎡** 的房间可设 1 个
- 地下、半地下仓库出口≥**2个**；建筑面积≤100㎡ 可设 1 个
- 地下仓库采用防火墙分隔多个防火分区时，疏散楼梯通向各分区时，可用**甲级防火门**作第二安全出口，但**每个防火分区必须有 1 个直通室外的出口**

## 公共建筑 1 个安全出口条件（P188）

- **单层公共建筑或多层公共建筑首层**。除托儿所、幼儿园外，建筑面积≤**200㎡** 且人数≤**50人**时，可设 1 个安全出口
- 歌舞娱乐放映游艺场所、医疗建筑、老年人照料设施、托儿所幼儿园**不能设1部疏散楼梯**
- 地下。地下建筑面积≤200㎡ 的设备间；地下建筑面积≤50㎡ 且人数≤15人 的其他房间，可设 1 个
- **设1部疏散楼梯的公共建筑**（全部楼层仅1部疏散楼梯）

| 耐火等级 | 允许层数 | 每层最大建筑面积 | 人数 |
|---|---|---|---|
| 一、二级 | 3层 | 200㎡ | 第二层、第三层人数之和≤50人 |
| 三级 | 3层 | 200㎡ | 第二层、第三层人数之和≤25人 |
| 四级 | 2层 | 200㎡ | 第二层人数≤15人 |

## 房间疏散门数量（P192-196）

- **人数不超过60人且每樘门平均疏散人数不超过30人的房间，疏散门开启方向不限**；人数超30人时疏散门必须向外开启（或设2个疏散门），48题考点
- **两出口间或袋形走道两侧房间**可设 1 个疏散门。托幼老照≤**50㎡**、医疗教学≤**75㎡**、其他≤**120㎡**
- **袋形走道尽端房间**（除托幼老照、医疗教学外）≤**50㎡** 可设 1 个；或建筑面积≤200㎡ + 门至最近安全出口距离≤**15m** + 门净宽≥**1.4m** 可设 1 个
- **歌舞娱乐放映游艺场所**。建筑面积≤50㎡ 且人数≤**15人** 的厅、室
- **地下**。≤200㎡ 设备间；≤50㎡ 且人数≤15人 的其他房间
- **电影院、剧场、礼堂**。≤2000人 时，每个疏散门≤**250人**；>2000人 时，超过部分每扇门≤**400人**

## 剪刀楼梯间（P209-210）

**高层公共建筑**
- 任一疏散门至最近疏散楼梯间入口距离≤**10m** 时可采用剪刀楼梯间
- 应为**防烟楼梯间**
- 梯段之间设**1.00h 防火隔墙**
- 前室应**分别设置**

**住宅建筑**
- 任一户门至最近楼梯间入口距离≤10m 时可采用
- 应为防烟楼梯间
- 梯段之间设 1.00h 防火隔墙
- 前室**不宜共用**（必须共用时≥**6.0㎡**）
- 不宜与消防电梯前室合用；必须合用时，合用前室≥**12.0㎡** 且短边≥**2.4m**

## 室外疏散楼梯（P210-211）

- 栏杆扶手高度≥**1.10m**
- 净宽度≥**0.80m**
- 倾斜角度≤**45°**
- 平台耐火极限≥**1.00h**、梯段≥**0.25h**
- 门采用**乙级防火门**，向外开启
- 周围 **2m** 范围内墙面不应设门窗洞口，疏散门不正对梯段
- 3层及以下建筑可采用难燃材料或木结构

## 疏散楼梯间布置原则（P185-186）

- 疏散楼梯宜设置在标准层或防火分区的**两端**
- 宜**靠近电梯**设置
- 宜**靠外墙**设置
- 疏散楼梯应**上下畅通**
- 高层建筑的疏散楼梯不应与裙房内的交通大厅、楼梯间、自动扶梯**混杂交叉**

## 疏散门开启方向（P186）

- 民用建筑和厂房的疏散门，应采用向疏散方向开启的**平开门**，不应采用推拉门、卷帘门、吊门、转门和折叠门
- **开启方向不限**。甲、乙类生产车间；人防公共场所；楼梯间门；≤60人 且每楼门≤30人 的房间
- 丙、丁、戊类仓库首层靠墙的外侧可采用**推拉门或卷帘门**
- 楼梯门完全开启时，不应减少楼梯平台的**有效宽度**

## 门禁/5m/防护挑檐（P185-190）

- **门禁系统**。住宅、宿舍、公寓建筑的外门采用门禁系统时，火灾时不需使用钥匙等从内部易于打开
- **5m 分散**。相邻两个安全出口及相邻两个疏散门最近边缘之间的水平距离≥**5m**
- **自动扶梯和电梯**不计作安全疏散设施
- **防护挑檐**。高层建筑直通室外的安全出口上方，应设挑出宽度≥**1.0m** 的防护挑檐
- **汽车库电梯**。直通附设汽车库的电梯，应设候梯厅，用 **2.00h 防火隔墙 + 甲级防火门** 分隔（住宅建筑内汽车库用 2.00h 隔墙 + 乙级门 + 1.00h 楼板）

## 疏散楼梯间分类（高频考点）

### 三种类型
- **封闭楼梯间**。入口处设门，1道门
- **防烟楼梯间**。设防烟前室、开敞阳台或凹廊，2道门
- **室外楼梯**。最安全但受环境影响

### 住宅楼梯间选择

| 建筑高度 | 楼梯间类型 |
|---|---|
| H≤21m | 敞开楼梯间；与电梯井相邻时用封闭楼梯间（户门完整性≥1h仍可敞开） |
| 21<H≤33m | 封闭楼梯间；户门完整性≥1h可采用敞开楼梯间 |
| H>33m | 防烟楼梯间；户门不宜直接开向前室，确需时每层开向同一前室≤3樘且用乙级防火门 |

### 多层公共建筑需设封闭楼梯间（口诀：老叔伤心无聊溜懒驴）
医疗建筑、旅馆；歌舞娱乐放映游艺场所；商店、图书馆、展览建筑、会议中心；6层及以上其他建筑；老年人照料设施
- 例外。与敞开式外廊直接相连的楼梯间可不封闭

### 高层公共建筑
| 情况 | 楼梯间类型 |
|---|---|
| 一类高层 | 防烟楼梯间 |
| H>32m 的二类高层 | 防烟楼梯间 |
| H≤32m 的二类高层 | 封闭楼梯间 |
| 裙房 | 封闭楼梯间；与高层主体设防火墙时按单多层 |

### 厂房仓库
| 情况 | 楼梯间类型 |
|---|---|
| 高层厂房 | 封闭楼梯间或室外楼梯 |
| 甲乙丙类多层厂房 | 封闭楼梯间或室外楼梯 |
| H>32m 且任一层人数>10人厂房 | 防烟楼梯间或室外楼梯 |
| 高层仓库 | 封闭楼梯间（最高封闭，无防烟） |

### 地下建筑
- 室内地面与室外出入口高差>10m 或 3层及以上地下/半地下 → 防烟楼梯间
- 其他地下/半地下 → 封闭楼梯间

## 楼梯间通用要求

- 不应设置烧水间、可燃材料储藏室、垃圾道；不应有凸出物
- **地上地下分隔**。地下楼层与地上楼层的疏散楼梯间，应在直通室外地面的楼层采用**耐火极限≥2.00h 且无开口的防火隔墙**分隔（讲义P204；GB 50016-2014 第6.4.4条；口诀。地上地下防火分隔=2h隔墙无洞口）
- 封闭/防烟楼梯间及其前室不应设置卷帘
- 不应设置甲乙丙类液体管道；封闭/防烟楼梯间及前室禁止可燃气体管道（住宅敞开楼梯间可用金属管道+切断气源阀门）
- 封闭楼梯间门。高层、人员密集公共建筑、多层丙类厂房、甲乙类厂房用乙级防火门；其他用弹簧门

## 防烟楼梯间前室面积

| 类型 | 公共建筑/高层厂房仓库 | 住宅建筑 |
|---|---|---|
| 独立前室 | ≥6.0㎡ | ≥4.5㎡ |
| 合用前室 | ≥10㎡ | ≥6.0㎡ |

门等级。超高层、地下>20000㎡商场用甲级防火门；其他建筑乙级防火门

## 疏散门特殊要求

- 宿舍居室、老年人照料设施居室、旅馆客房疏散门应具有烟密闭功能（老客居）
- 宿舍居室、旅馆客房疏散门应具有自动关闭功能
- 防火隔间。建筑面积≥6.0㎡，隔墙3h防火隔墙，门用甲级防火门（346甲A：3h墙、4m间距、6㎡、甲级门、A级装修）

## 避难走道（口诀：甲乙66315A）

- 防火分区至避难走道入口设防烟前室，前室面积≥6.0㎡，开向前室门甲级防火门，前室开向避难走道门乙级防火门
- 避难走道内设消火栓、消防应急照明、应急广播、消防专线电话（口诀：笑话照播）
- 防火分区通向避难走道的门至最近直通地面出口距离≤60m
- 避难走道净宽度≥任一防火分区通向该走道的设计疏散总净宽度
- 避难走道内部装修材料燃烧性能A级
- 避难走道防火隔墙耐火极限≥3.00h

**出口数量（P211）**
- 直通地面出口≥**2个**，且应在不同方向
- 避难走道仅与**一个防火分区**相通，且该防火分区有 1 个直通室外出口时，可设 **1个**

**口诀"甲乙66315A"拆解**。甲=开向前室甲级门、乙=前室开向走道乙级门、6=前室面积6㎡、3=隔墙3h、1=（距出口≤60m的百位）、5=设5类设施、A=装修A级

## 避难间（口诀：2+甲门+乙窗、发囊变库）

- 分隔。2.00h防火隔墙+甲级防火门+乙级防火窗
- **贴临限制（口诀：发囊变库）**。避难间不允许和可燃物库房、锅炉房、发电机房、变配电站等火灾危险性大的场所正下方、正上方或贴邻
- 避难间内设施。消火栓、电话、广播、卷盘、标志
- 设置条件。老年人照料设施三层及以上且总面积>3000㎡；医疗建筑高层住院部二层及以上

**高层病房楼避难间细节（P218-219）**
- 二层及以上病房楼层和**洁净手术部**应设避难间
- 服务的护理单元≤**2个**，净面积按每个护理单元≥**25.0㎡**
- 建筑层数>**24m** 的洁净手术部及重症监护区，每个防火分区应设置≥**1间**避难间

**老年人照料设施避难间细节（P219-220）**
- 3层及以上且总建筑面积>**3000㎡** 的老年人照料设施
- 二层及以上每座疏散楼梯间**相邻部位**设 1 间避难间
- 净面积≥**12㎡**
- 可利用楼梯间前室或消防电梯前室（**不能利用合用前室**）
- 失能老年人且层数>**2层**时，应按核定人数配备简易防毒面具

## 应急照明备用电源时间（P221-223）

| 情形 | 持续供电时间 |
|---|---|
| 建筑高度>100m | ≥**1.5h** |
| 医疗建筑、老年人照料设施、总建筑面积>100000㎡ 公共建筑、>20000㎡ 地下半地下建筑 | ≥**1.0h**（口诀：一老公十万买两万平地下室） |
| 其他建筑 | ≥**0.5h** |

**增设视觉连续疏散指示标志的场所（口诀：懒爸上午下午跳舞要我去电影院看三体）**
- 总建筑面积>**8000㎡** 的展览建筑
- 总建筑面积>**5000㎡** 的地上商店
- 总建筑面积>**500㎡** 的地下商店
- 歌舞娱乐放映游艺场所
- 座位数>**1500座** 的电影院、剧场
- 座位数>**3000座** 的体育馆、会堂、礼堂
- 总建筑面积>**3000㎡** 的候车厅、候船厅

## 下沉式广场（P221、P224）

- 用于防火分隔的开口，其最近边缘之间的水平距离≥**13m**
- 直通地面的疏散楼梯≥**1部**，疏散净面积≥**169㎡**
- 疏散楼梯的总净宽度≥任一防火分区设计疏散总净宽度
- 防风雨篷开口面积≥地面面积的 **25%**、高度≥**1.0m**；百叶有效排烟面积按开口面积的 **60%** 计

## 避难层（超高层，>100m）

> 来源：1号书防火篇 P217 安全疏散·避难层；依据 GB 50016-2014 第5.5.23条（设置条件）、第5.5.24条（间距与构造要求）

### 设置条件与位置

- 建筑高度大于 **100m** 的建筑，应设置避难层（间）
- 第一个避难层（间）的楼地面至灭火救援场地地面高度**不应大于 50m**
- 两个避难层（间）之间的高度**不宜大于 50m**

### 楼梯与避难层关系

- 通向避难层（间）的疏散楼梯应在避难层**分隔、同层错位或上下层断开**

### 净面积

- 应满足该避难层与上一避难层之间所有楼层全部使用人数避难的要求
- 宜按 **5.0 人/㎡** 计算

### 分隔与设备管道（详见 building-plane.md 避难区井道分隔）

- 避难层可兼作设备层，设备管道宜集中布置；易燃、可燃液体或气体管道应集中布置
- 设备管道区与避难区。**3.00h** 防火隔墙
- 管道井、设备间与避难区。**2.00h** 防火隔墙
- 管道井和设备间的门不应直接开向避难区；连通时设防火隔间，防火隔间门为甲级防火门
- 避难间内不应设置易燃、可燃液体或气体管道，不应开设除外窗、疏散门之外的其他开口
- **5m 间距（非面积）**。管道井/设备间的门确需直接开向避难区时，与避难区出入口的距离不应小于 **5m**，且应采用甲级防火门（offcn 规范源印证；讲义标注"5M"）

### 设施配置

- 消防电梯出口
- 消火栓和消防软管卷盘
- 消防专线电话和应急广播
- 避难层进入楼梯间入口处、疏散楼梯通向避难层出口处设明显指示标志

### 防烟与外窗

- 应设直接对外的可开启窗口或独立的机械防烟设施
- 外窗采用乙级防火窗
- 避难区应至少有一边水平投影位于同一侧的消防车登高操作场地范围内

### 大于 250m 建筑附加要求

- 避难层设置区域不应设置玻璃幕墙
- 按 **4 人/㎡** 计算（注意：与 ≤250m 的 5.0 人/㎡ 不同）

## 借道疏散

- 利用条件。一二级耐火公共建筑安全出口全部直通室外确有困难
- 分隔。防火墙与相邻防火分区分隔
- 面积。>1000㎡直通室外安全出口≥2个，≤1000㎡≥1个
- 宽度。疏散净宽度不应大于规范所需总净宽度的30%
- 地下借道。只能地下借道，无30%宽度要求，可互借，每防火分区须有1个直通室外独立安全出口

## 规范依据

- GB 50016-2014 第5.5.17条。疏散距离
- GB 50016-2014 第5.5.20条。百人指标
- GB 50016-2014 第5.5.21条。安全出口/疏散门

## 考试出题角度

- 判断楼梯间类型（住宅/公共/厂房/地下各种高度）
- 计算疏散宽度（人员密度+百人指标+净宽校验）
- 疏散距离计算（设自喷×1.25、外廊/楼梯间增减）
- 住宅安全出口数量判断
