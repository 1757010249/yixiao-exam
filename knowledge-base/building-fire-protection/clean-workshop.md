# 洁净厂房防火

> 定义（《洁净厂房设计规范》GB 50073-2013）：洁净室指空气悬浮粒子浓度受控的房间；洁净区指空气悬浮粒子浓度受控的限定空间。

## 一、生产类别举例

| 类别 | 典型工作间 |
|---|---|
| 甲 | 微型轴承装配精研间、装配前检查间；精密陀螺仪装配清洗间；磁带涂布烘干工段；丁酮/丙酮/环乙酮等易燃溶剂物理提纯间、光致抗蚀剂配制间；集成电路厂**闪点<28℃**易燃液体化学清洗间、外延间、常压化学气相沉积间、化学试剂贮存间 |
| 乙 | **胶片厂的洗印车间** |
| 丙 | 计算机房磁盘贮存间；显像管厂装配工段烧枪间；磁带装配工段；集成电路厂的**氧化、扩散间、光刻间** |
| 丁 | 液晶显示器件厂溅射间、彩膜检验间；光纤预制棒 MCVD/OVD 沉淀间、火抛光、芯棒烧缩及拉伸间、拉纤间；彩色荧光粉厂的蓝粉、绿粉、红粉制造间 |
| 戊 | 半导体器件/集成电路工厂的切片间、磨片间、抛光间；光纤光缆工厂的光纤筛选检验区 |

## 二、耐火等级与防火分区

- 耐火等级**不应低于二级**
- 甲、乙类生产的洁净厂房**宜为单层**；防火分区最大允许面积：单层宜 **3000m²**、多层宜 **2000m²**
- 丙、丁、戊类：防火分区按 GB 50016 有关规定执行

## 三、建筑构造

| 部位 | 要求 |
|---|---|
| 顶棚与壁板 | 洁净室顶棚、壁板及夹芯材料应为不燃烧体，不得采用有机复合材料；耐火极限≥**0.4h**；疏散走道顶棚≥**1.0h** |
| 隔断措施 | 同一防火分区内洁净生产区与一般生产区之间设不燃烧体隔断；隔墙及相应顶棚≥**1h**；隔墙上门窗≥**0.6h**；穿管线空隙紧密填堵 |
| 技术竖井 | 井壁不燃烧体≥**1h**；检查门≥**0.6h**；各层或间隔一层楼板处用相当于楼板耐火极限的不燃体水平分隔 |

## 四、安全疏散

- 每一生产层、每一防火分区或每一洁净区安全出口 ≥2 个
- 甲、乙类可设 1 个的条件：每层洁净生产区总建筑面积≤**100m²** 且同一时间生产人员≤**5人**
- 疏散路线不应经过曲折的人员净化路线；疏散距离按 GB 50016
- 安全疏散门向疏散方向开启并加闭门器；**不得采用吊门、转门、侧拉门、卷帘门、电控自动门**

## 五、专用消防口

- 同层洁净室（区）外墙应设可供消防人员进入的门窗；门窗洞口间距 **>80m** 时应设专用消防口
- 尺寸：宽≥**750mm**、高≥**1800mm**，有明显标志；楼层专用消防口应设阳台，从二层开始向上架设钢梯
- 外墙吊门、电控自动门、装有栅栏的窗均不得作为消防入口

## 六、消防设施

| 设施 | 要求 |
|---|---|
| 消防给水 | **必须设置**；洁净室生产层及可通行的上、下技术夹层设室内消火栓 |
| 消火栓参数 | 用水量≥**10L/s**；水枪数≥**2只**；充实水柱≥**10m**；每只水枪出水量≥**5L/s** |
| 灭火器 | 各场所必须配置（按 GB 50140） |
| 固定灭火 | 贵重设备房间：自动喷水**宜采用预作用式**；气体灭火**不得用卤代烷1211**及致窒息、二次损害灭火剂 |
| 排烟 | **疏散走廊应设机械排烟**；排烟风管不燃材料、耐火极限 >**0.5h** |
| 备用照明 | 应设置 |
| 火灾报警 | 生产层、技术夹层、机房、站房均应设探测器；生产区及走廊设手动报警按钮 |

## 易错点 / 陷阱

- **乙类只有一个**：胶片厂洗印车间（易误判为丙类）
- **氧化/扩散/光刻间=丙类** vs 化学清洗间（闪点<28℃）=甲类
- 顶棚壁板 0.4h vs 疏散走道顶棚 1.0h vs 隔断墙 1h vs 门窗/竖井检查门 0.6h，数值易混
- 消火栓充实水柱 **10m**（不是 7m）

## 记忆方法

- 甲类记忆锚点：闪点<28℃化学清洗间（与通用甲类液体闪点规则一致）
- 专用消防口"750×1800"联想：宽如半人、高如一人

## 规范依据

- GB 50073-2013《洁净厂房设计规范》第6章（工艺设计及净化空调）、第7章（消防与安全）、附录B（火灾危险性分类举例）

## 考试出题角度

- **实务**。生产类别判断（给具体工作间定甲乙丙丁戊）、防火分区面积、消火栓参数
- **案例**。洁净厂房安全出口设置条件、专用消防口尺寸判断
