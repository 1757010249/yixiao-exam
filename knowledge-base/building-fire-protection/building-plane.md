# 平面布置

## 设备用房布置总则

**布置原则**
- 燃油/燃气锅炉、油浸变压器、柴油发电机房等宜设置在**建筑外专用房间**
- 贴邻民用建筑时，用防火墙分隔，不应贴邻人员密集场所，耐火等级≥二级
- 布置在民用建筑内时，不应在人员密集场所的上一层/下一层/贴邻

**防火分隔标配（口诀：二墙一楼半）**
- 耐火极限≥2.00h防火隔墙 + 1.50h不燃性楼板
- 隔墙楼板不应开洞口，确需开时用甲级防火门窗

## 锅炉房（口诀：首层地下一层靠外墙，储油间三墙隔）

| 项目 | 要求 |
|---|---|
| 布置位置 | 首层靠外墙 或 地下一层靠外侧；不应贴邻救援出入口/疏散楼梯/主疏散通道 |
| 常负压燃气锅炉房 | 可设屋顶，与通向屋面安全出口水平距离≥6m |
| 相对密度≥0.75可燃气体锅炉 | 不得设在地下或半地下 |
| 分隔 | 2.00h防火隔墙+1.50h楼板，甲级防火门窗 |
| 储油间 | 总储存量≤1m³；3.00h防火隔墙+甲级防火门 |
| 变压器容量 | 油浸变压器总容量≤1260kV·A，单台≤630kV·A（口诀：总1260单630） |
| 通风 | 燃气锅炉房应设独立通风系统 |
| 爆炸泄压 | 燃气锅炉房应设**爆炸泄压设施** |
| 疏散门 | 应直通室外或安全出口 |

## 柴油发电机房（口诀：首层地下一二层，储油1m³记心间）

| 项目 | 要求 |
|---|---|
| 布置位置 | 首层或地下一、二层 |
| 分隔 | 2.00h防火隔墙+1.50h楼板，甲级防火门 |
| 储油间 | 总储存量≤1m³；3.00h防火隔墙+甲级防火门 |
| 柴油闪点 | 不应低于60℃ |
| 通风 | 应设独立通风系统 |
| 疏散门 | 应直通室外或安全出口 |

### 燃料供给管道规定（P85-86）

- 进入建筑物前和设备间内管道上均应设置**自动和手动切断阀**
- 储油间油箱应密闭，且应设**通向室外的通气管**，通气管上设**带阻火器的呼吸阀**
- 油箱下部应设**防止油品流散设施**

## 变压器室

| 项目 | 要求 |
|---|---|
| 布置位置 | 首层或地下一层靠外墙部位 |
| 事故储油设施 | 油浸变压器下面应设能储存**全部油量**的事故储油设施 |
| 分隔 | 变压器室之间、变压器室与配电室之间用**2.00h 防火隔墙** |
| 容量 | 油浸变压器总容量≤1260kV·A，单台≤630kV·A |
| 干式变压器 | 未作限制 |

## 消防水泵房通风

- 消防水泵房通风按 **6次/h** 换气，并应设排水设施

## 消防控制室（口诀：乙级门记心间）

| 项目 | 要求 |
|---|---|
| 布置位置 | 首层或地下一层，靠外墙 |
| 防火分隔 | 2.00h隔墙+1.50h楼板 |
| 门 | 开向建筑内的门用**乙级防火门**（直通室外门无规定） |
| 禁止 | 严禁无关电气线路和管路穿过 |
| 其他 | 防水淹、防潮、防啮齿动物 |

## 消防水泵房（口诀：不在地下三层，甲级门是标配）

| 项目 | 要求 |
|---|---|
| 布置位置 | 不应设置在地下三层及以下 |
| 门 | **甲级防火门** |
| 室内温度 | 不应低于5℃，有人值班不低于10℃ |
| 防水 | 应采取防水淹技术措施 |
| 位置限制 | 不宜在有防振/安静要求房间的上下层或毗邻 |

## 其他设备用房

| 用房 | 防火隔墙/楼板 | 门 |
|---|---|---|
| 通风空调机房 | 2.00h/1.50h | 甲级防火门 |
| 变配电室 | - | 甲级防火门 |
| 防烟排烟机房 | 2.00h/1.50h | **甲级防火门**（用户 2026-08-20 定稿，差异见下注） |
| 报警阀组、气体储瓶间 | - | **乙级防火门** |
| 消防电梯机房 | 与普通电梯机房2.00h隔墙 | - |

**直通室外或屋面的防火门无级别要求（P97）**。直接通向室外地面或屋面的疏散门，无防火门耐火等级（级别）要求

**防烟排烟机房门等级差异注（用户 2026-08-20 定稿）**。知识库按**甲级**记录。依据：奇门遁甲竖向 P21 甲级门组（"水泵房、排烟机房、油浸变压器、锅炉房、柴油机房 2H 隔墙+1.5H 楼板+甲级门"）、横向"重要设备用房"（消防控制室/消防水泵房/排烟机房/…常闭甲级防火门）、人防规范 GB 50098（2016 综合真题第 85 题人防场景"排烟机房采用防火墙和常闭甲级防火门"判定符合）。**差异**：讲义 1号书 P143-154（GB 50016-2014 第6.2.7条原文）将防烟排烟机房归入"其他设备房间"，按原文文字该组应为**乙级**防火门；GB 51251-2017 第3.3.5条/第4.4.5条仅要求送风机房/排烟机房设专用机房并符合现行国标，未另定门等级。**考试记忆**：民用建筑按甲级记忆，人防工程亦甲级；若按规范条文原文逐字解释防烟排烟机房可作"乙级（其他设备房间）"理解，两口径并存，以甲级为主。

**口诀**。小气包乙级门——消防控制室、气体储瓶间、报警阀组室用乙级门，其他甲级门

## 竖井分隔（电梯井/管道井/强弱电井）

### 消防电梯井（GB 50016 第7.3.5条）
- 消防电梯井、机房与相邻电梯井、机房之间设**2.00h无洞口防火隔墙**
- 井底排水。排水井容量≥2m³，排水泵排水量≥10L/s；前室门口宜设挡水设施
- 禁止用防火卷帘/防火玻璃墙替代防火隔墙（除货梯前室无法设防火门的开口外）

### 电梯井墙耐火极限（构件表）
| 一级 | 二级 | 三级 | 四级 |
|---|---|---|---|
| 不2.0 | 不2.0 | 不1.5 | 难0.5 |

### 管道井/电气竖井检查门等级（口诀：上天入地甲级门）
| 情况 | 检查门等级 |
|---|---|
| 埋深>10m 的电气竖井、管道井、排烟道、排气道、垃圾道 | **甲级**防火门 |
| 超高层建筑 | **甲级**防火门 |
| 层间无防火分隔的竖井、住宅建筑合用前室 | **乙级**防火门 |
| 其他建筑 | **丙级**防火门 |

- 管道穿越防火墙或楼板应**防火封堵**；防火阀两侧各2m范围内用不燃材料
- 防排烟管道井检修门。乙级防火门（见 smoke-control.md）

### 避难区井道分隔
- 避难层设备管道区与避难区。3.00h防火隔墙
- 管道井/设备间与避难区。2.00h防火隔墙
- 管道井和设备间的门不应直接开向避难区；连通时设防火隔间，隔间门甲级防火门

## 功能用房布置

### 人员密集场所 / 公众聚集场所定义（P82）

- **人员密集场所**。公众聚集场所，医院的门诊楼、病房楼，学校的教学楼、图书馆、食堂和集体宿舍，养老院、福利院，托儿所、幼儿园，公共图书馆的阅览室，公共展览馆、博物馆的展示厅，劳动密集型企业的生产加工车间和员工集体宿舍，旅游、宗教活动场所等
- **公众聚集场所**。宾馆、饭店、商场、集贸市场、客运车站候车室、客运码头候船厅、民用机场航站楼、体育场馆、会堂以及公共娱乐场所等
- **公共娱乐场所**。具有娱乐功能的夜总会、音乐茶座、酒吧间、游艺厅、录像厅等

### 商店、展览建筑
- 营业厅/展览厅三级耐火等级应布置在首层或二层；四级布置在首层
- 地下限制。不应设置在地下三层及以下
- 地下禁止。不应经营、储存、展示甲、乙类物品

### 托儿所、幼儿园、老年人照料设施
- 宜独立设置，不应设在地下或半地下
- 一二级耐火等级不超过3层；三级不超过2层；四级为单层
- 一二级布置在首层、二层或三层；三级在首层或二层

### 老年人照料设施（独立内容）

- 宜独立设置；与其他建筑上下组合建造时，宜设置在**下部**
- 分隔。2.00h 防火隔墙 + 1.00h 楼板 + 乙级防火门
- 耐火等级。除木结构建筑外，耐火等级不应低于三级
- 独立建造。一二级耐火等级建筑高度≤**54m**；三级耐火等级不超过**2层**
- 公共活动用房、康复与医疗用房设置在地下时，应设在地下一层且每间建筑面积≤**200㎡**、人数≤**30人**
- 设置在地上**四层及以上**时，每间建筑面积≤200㎡、人数≤30人
- **居室、休息室不应设置在地下室、半地下室**

### 医院、疗养院的住院部

- **住院部不应设置在地下或半地下**
- 三级耐火等级建筑不超过 **2层**；设置在三级耐火等级建筑内时，应布置在**首层或二层**
- 病房楼相邻护理单元之间设**2.00h 防火隔墙**，门采用**甲级防火门**，设置在走道上的防火门应**常开**
- 重症监护室应**独立分区**，设甲级防火门

### 教学建筑、食堂、菜市场

- 三级耐火等级不超过 **2层**；四级耐火等级为**单层**
- 设置在三级耐火等级建筑内时，应布置在首层或二层
- **教学楼**不应设置在四级耐火等级建筑内

### 歌舞娱乐放映游艺场所

- **不应布置在地下二层及以下**楼层
- 宜布置在一、二级耐火等级建筑内**首层、二层、三层的靠外墙部位**
- 不宜布置在袋形走道的两侧或尽端
- 确需布置在地下一层时，地面与室外出入口地坪高差≤**10m**
- 布置在地下或四层及以上楼层时，一个厅室建筑面积≤**200㎡**
- 分隔。**2.00h 防火隔墙 + 1.00h 不燃性楼板 + 乙级防火门**，厅室之间及与建筑其他部位分隔，疏散门不应直通疏散楼梯间

### 电影院、剧场、礼堂（口诀：2H隔墙+甲级门）
- 与相邻部位分隔。**2.00h防火隔墙+甲级防火门**（竖版奇门遁甲 P20"电影院剧场礼堂 2H隔墙+甲级门"）
- 布置位置。宜布置在首层、二层或三层；**采用三级耐火等级建筑时不应超过2层**（22题考点，GB 5.4.7），不应布置在三层及以上楼层
- 四层及以上或地下楼层。一个厅室疏散门≥2个，建筑面积不宜大于400㎡
- 地下/半地下。宜设在地下一层，不应在地下三层及以下
- 高层建筑内应设火灾自动报警系统及自动喷水灭火系统
- 舞台与观众厅之间。3.00h防火隔墙；舞台上部与闷顶之间1.50h隔墙+乙级门；舞台下部灯光操作室2.00h隔墙

### 中间仓库（P28）

| 类型 | 要求 |
|---|---|
| 甲乙类中间仓库 | 靠外墙布置，储量≤1昼夜需要量；防火墙+1.50h不燃楼板+甲级门 |
| 丙类中间储罐 | 3.00h防火隔墙+1.50h楼板；容量≤5m³；甲级防火门 |
| 丁戊类中间仓库 | 2.00h防火隔墙+乙级门+1.00h楼板 |

**中间仓库细则（P97-98）**
- 甲乙类中间仓库储量≤**1昼夜**需要量（手表厂汽油可放宽至1-2昼夜）

### 不应设置在地下或半地下（口诀：甲乙有粉丝）

- 甲、乙类生产场所
- 甲、乙类仓库
- 有**粉尘爆炸危险**的生产场所、滤尘设备间
- 邮袋库、丝麻棉毛类物质库

### 民用建筑内禁止事项（P88）

- 民用建筑内不应设置生产车间和其他库房
- 经营、存放、使用甲、乙类物品的商店、作坊、储藏间，**严禁附设**在民用建筑内

## 楼层设置汇总（P99）

| 楼层 | 可布置 |
|---|---|
| 屋顶 | 常负压锅炉房 |
| 4层及以上 | 电影院/会议厅（≤400㎡、2个疏散门）、歌舞娱乐（≤200㎡）、老年人照料设施（≤200㎡且≤30人） |
| 首层 | 病房、幼儿园、老年人居室、甲乙类厂房仓库、邮袋库、相对密度≥0.75 锅炉房 |
| 地下一层 | 锅炉房、油浸变压器、歌舞娱乐、消防控制室、老年人活动用房 |
| 地下二层 | 消防水泵房、柴油发电机房、电影院、商场营业厅 |
| 无规定 | 干式变压器 |

## 贴临要求汇总（P100）

| 贴临对象 | 分隔要求 |
|---|---|
| 锅炉房贴临民用建筑 | 防火墙 + 耐火等级二级 |
| 办公室贴临甲乙类厂房 | 防爆墙 + 二级 + 独立安全出口 |
| 分控制室贴临甲乙类厂房 | 3.00h 防火隔墙 |
| 变配电站（甲乙类厂房专用） | 贴临时用防火墙或防爆墙 |
| 液化石油气贴临民用建筑 | 防火墙，且不应贴临高层、住宅、人员密集场所 |

## 储油间容量汇总（P100）

| 位置 | 储油量 |
|---|---|
| 民用建筑 | ≤**1m³** |
| 厂房 | ≤**5m³** |
| 室外埋地 | ≤**15m³**（埋地储罐面向建筑物4m 范围内外墙为防火墙时，防火间距不限） |

## 厂房、仓库平面布置（P96-98）

- **员工宿舍**严禁设在厂房、仓库内
- 办公室、休息室设在丙、丁类仓库内。**2.00h 防火隔墙 + 1.00h 楼板（一级耐火等级用1.50h楼板）+ 独立安全出口 + 乙级防火门**
- 丙、丁类物流建筑。耐火等级≥二级；物流作业区与辅助办公区之间设**3.00h 防火隔墙 + 2.00h 楼板**，且设置**独立的安全出口**

### 办公室、休息室
- 贴邻甲乙类厂房。二级耐火+独立安全出口+防爆墙分隔
- 设在丙类厂房内。乙级门+2.00h隔墙+1.00h楼板+独立安全出口
- **办公室不能贴临甲、乙类仓库**

## 考试出题角度

- 各类设备用房布置位置判断（地下几层、靠外墙等）
- 防火分隔等级（2h隔墙+1.5h楼板）与门的级别
- 储油间/变压器容量限制
- 中间仓库、办公室布置要求
