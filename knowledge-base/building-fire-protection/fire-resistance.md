# 耐火等级

## 建筑材料燃烧性能分级

| 等级 | 类别 | 典型材料 |
|---|---|---|
| A | 不燃 | 砖墙、钢屋架、钢筋混凝土 |
| B1 | 难燃 | 阻燃木质门、酚醛泡沫、水泥刨花板 |
| B2 | 可燃 | 木头、竹子、塑料 |
| B3 | 易燃 | - |

附加等级标识：T（毒性）、D（滴落）、S（产烟），**口诀：手电筒**
- d0：600s内无燃烧滴落物；d1：600s内滴落物持续不超10s；d2：未达d1

## 耐火极限三要素（易混点）

耐火极限 = 承载能力 + 完整性 + 隔热性三者中**最短的失效时间**决定

| 要素 | 含义 |
|---|---|
| 承载能力 | 抵抗垮塌的能力 |
| 耐火完整性 | 防止火焰热气穿透 |
| 耐火隔热性 | 背火面温度不超过规定值 |

**影响耐火极限的6要素口诀**：老鼠要造条狗
（老=材料老化、鼠=材料属性、要=环境要求、造=构造方式、条=试验条件、狗=结构特性）

## 重要调整（易错陷阱）

1. 二级耐火等级建筑内采用不燃材料的吊顶，耐火极限不限
2. **二级和三级耐火等级建筑内门厅、走道的吊顶，应采用不燃材料**（22题考点，ex-2haoshu 31题；不能采用难燃材料）
3. 三级耐火等级的**医疗建筑、中小学校的教学建筑、老年人照料设施及托儿所、幼儿园的儿童用房和儿童游乐厅等儿童活动场所**的吊顶，应采用不燃材料；用难燃材料时耐火极限≥0.25h
4. 二类高层住宅建筑耐火等级不低于二级；一类高层不低于一级
5. **上人平屋顶**。一、二级耐火等级厂房（仓库）的上人平屋顶，屋面板耐火极限分别不应低于 **1.50h** 和 **1.00h**；屋顶承重构件的耐火极限不能低于屋面板
6. **甲乙类厂房/甲乙丙类仓库防火墙 4.00h**。甲、乙类厂房和甲、乙、丙类仓库内的防火墙，其耐火极限不应低于 **4.00h**（其余防火墙为3.00h）
7. **建筑高度>100m 民用建筑楼板**。耐火极限不应低于 **2.00h**

## 钢结构特性（耐火考点）

- 温度 **150℃以下** 钢材性质变化很小
- **300-400℃** 钢材强度和弹性模量显著下降
- **600℃** 钢材强度趋于零
- **无防火保护** 钢构件的耐火时间仅 **0.25-0.5h**
- 钢构件防火保护。喷头间距 **2.2m**，沿钢屋架上方布置

## 构件耐火极限放宽条件（考点）

| 放宽场景 | 要求 |
|---|---|
| 4层及以下一二级丁戊类厂房非承重外墙(不燃) | 耐火极限不限 |
| 一级耐火等级单层甲类厂房柱 | 耐火极限不应低于2.50h |
| 二级耐火等级多层住宅预应力楼板 | 耐火极限不应低于0.75h |
| 二级耐火等级厂房房间隔墙(难燃墙体) | 耐火极限不应低于0.75h |

### 构件放宽口诀（5号书讲义）

| 口诀 | 对应放宽 |
|---|---|
| **单多屋顶工一拳** | 一级单多层厂房/仓库设自喷全保护，屋顶承重构件耐火极限放宽至1.00h（原1.50h） |
| **单工一级二级柱** | 单层厂房一级耐火等级柱的要求 |
| **甲乙高仓外，外墙有放宽** | 甲乙类高层仓库非承重外墙，不燃0.25h、难燃0.50h |
| **二多预应力，变0.75** | 二级耐火等级多层住宅预应力楼板放宽至0.75h |
| **二哥难气我** | 二级耐火等级厂房/仓库房间隔墙，难燃0.75h（原不燃0.50h） |

## 厂房耐火等级判断（GB 50016-2014 第3.2.1条）

| 条件 | 耐火等级要求 |
|---|---|
| 高层厂房、甲乙类厂房 | ≥二级 |
| 建筑面积≤300㎡ 独立单层甲乙类厂房 | 可三级 |
| 建筑高度>50m 高层厂房 | ≥一级 |
| 地下厂房 | ≥一级 |
| 单多层丙类厂房、多层丁戊类厂房 | ≥三级 |
| 使用或产生丙类液体的厂房及有火花、赤热表面、明火的丁类厂房 | ≥二级（单层丙类液体≤500㎡、单层丁类≤1000㎡ 可三级） |
| 特殊贵重设备或物品的建筑 | ≥二级 |
| 锅炉房 | ≥二级（燃煤锅炉总蒸发量≤4t/h 可三级） |
| 油浸变压器室、高压配电装置室 | ≥二级 |

## 仓库耐火等级（GB 50016-2014 第3.2.7条）

| 等级 | 适用仓库（口诀：2筒3仓） |
|---|---|
| 一级 | 储存可燃液体的多层丙类仓库；>32m 高层丙类仓库；每个防火分隔间>3000㎡ 的其他多层丙类仓库；Ⅰ类飞机库；甲类3、4项仓库 |
| 二级 | 高架仓库/高层仓库/甲类仓库/多层乙类仓库（高甲多乙）、粮食筒仓 |
| 三级 | 单层乙类/单层丙类/储存可燃固体的多层丙类/多层丁戊类仓库、粮食平房仓 |

| 等级 | 适用建筑 |
|---|---|
| 一级（口诀：阿姨私生二弟） | 一类高层民用；二层及二层半式/多层式民用机场航站楼；A类广播电影电视建筑；四级生物安全实验室；地下、半地下建筑 |
