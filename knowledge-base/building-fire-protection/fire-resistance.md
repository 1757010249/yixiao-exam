# 耐火等级

## 建筑材料燃烧性能分级

| 等级 | 类别 | 典型材料 |
|---|---|---|
| A | 不燃 | 砖墙、钢屋架、钢筋混凝土 |
| B1 | 难燃 | 阻燃木质门、酚醛泡沫、水泥刨花板 |
| B2 | 可燃 | 木头、竹子、塑料 |
| B3 | 易燃 | - |

附加等级标识：T（毒性）、D（滴落）、S（产烟），**口诀：手电筒**
- d0：600s内无燃烧滴落物；d1：600s内滴落物持续不超10s；d2：未达d1

## 耐火极限三要素（易混点）

耐火极限 = 承载能力 + 完整性 + 隔热性三者中**最短的失效时间**决定

| 要素 | 含义 |
|---|---|
| 承载能力 | 抵抗垮塌的能力 |
| 耐火完整性 | 防止火焰热气穿透 |
| 耐火隔热性 | 背火面温度不超过规定值 |

**影响耐火极限的6要素口诀**：老鼠要造条狗
（老=材料老化、鼠=材料属性、要=环境要求、造=构造方式、条=试验条件、狗=结构特性）

## 重要调整（易错陷阱）

1. 二级耐火等级建筑内采用不燃材料的吊顶，耐火极限不限
2. 三级耐火等级的医疗、教学、老年人照料、托儿所幼儿园儿童用房等吊顶，应采用不燃材料；用难燃材料时耐火极限≥0.25h
3. 二类高层住宅建筑耐火等级不低于二级；一类高层不低于一级

## 构件耐火极限放宽条件（考点）

| 放宽场景 | 要求 |
|---|---|
| 4层及以下一二级丁戊类厂房非承重外墙(不燃) | 耐火极限不限 |
| 一级耐火等级单层甲类厂房柱 | 耐火极限不应低于2.50h |
| 二级耐火等级多层住宅预应力楼板 | 耐火极限不应低于0.75h |
| 二级耐火等级厂房房间隔墙(难燃墙体) | 耐火极限不应低于0.75h |

### 构件放宽口诀（5号书讲义）

| 口诀 | 对应放宽 |
|---|---|
| **单多屋顶工一拳** | 一级单多层厂房/仓库设自喷全保护，屋顶承重构件耐火极限放宽至1.00h（原1.50h） |
| **单工一级二级柱** | 单层厂房一级耐火等级柱的要求 |
| **甲乙高仓外，外墙有放宽** | 甲乙类高层仓库非承重外墙，不燃0.25h、难燃0.50h |
| **二多预应力，变0.75** | 二级耐火等级多层住宅预应力楼板放宽至0.75h |
| **二哥难气我** | 二级耐火等级厂房/仓库房间隔墙，难燃0.75h（原不燃0.50h） |
