# 特殊建筑考点汇总（逐类对比）

> 本条目集中竖向 P50-58 特殊建筑逐类对比表。平面布置/楼层限制等已散点覆盖于 building-plane.md，本表作集中对照补充。

## 锅炉房（竖向P50）

- 耐火等级。不低于二级，≤4T/h 燃煤锅炉房三级
- 防火间距。和甲乙厂房/甲类仓库按明火确定（≥30m）；其他按丁类厂房；≤4T/h 或 ≤2.8MW 燃煤锅炉按民用间距
- 防火分隔。贴临建筑用防火墙（二级），不能贴临人密
- 平面布置。建筑内只能首层及地下一层；常压锅炉房可设屋顶，屋顶常(负)压燃气锅炉距通向屋面安全出口≥6m；不应布置人密场所上一层/下一层/贴邻（防爆措施可贴临）；**2.0+1.5+甲级门**分隔（住宅锅炉房 2+1+乙级门）；火灾报警+灭火设施+直通室外安全出口；相对密度≥0.75 的可燃气体锅炉不得设地下/半地下；民用建筑内储油间≤1m³，单独锅炉房按工业计算储罐≤5m³
- 通风换气。燃油锅炉房正常3/事故6次/h；燃气锅炉房正常6/事故12次/h（防爆事故风机）
- 选址。最小频率风向**上风侧**
- 电力线路。不宜裸线/绝缘线明敷，用金属管/电缆布线，不宜沿锅炉烟道/载热体表面敷设，电缆不得在煤场下通过

## 医疗建筑（竖向P51）

- 防火分隔/楼梯间。护理单元 2+甲；其他房间 2+1+乙；避难间 2+甲；多层封闭/高层防烟楼梯
- 耐火等级。三级≤2层，住院不地下；人防住院部可设地下一层
- 疏散距离。单多层出口之间 35/30/25；袋形走道 20/15/10；高层病房 24/12、高层其他 30/15
- 避难救援。高层病房楼2层及以上设避难间；每避难间服务护理单元≤2个；每护理单元按25㎡净面积计算；独立机械防烟、外窗乙级窗、电话、广播、指示标志
- 疏散宽度。首层疏散外门/疏散出口/疏散走道/疏散楼梯。高层公共医疗 1.3/0.8/1.4(单)1.5(双)/1.3；单多层医疗 1.1/0.8/1.1/1.1
- 注。门诊大厅属人密场所，宽度按1.4m计算；走道尽端不能一个门，其他位置≤75㎡可一个门
- 消防设施。自喷、报警、>5000m³消火栓、快速响应洒水喷头、自喷中1级、≥50张床灭火器严重危险、保温A级、人密照度3LX、楼梯间/避难间10LX

## 儿童场所（竖向P52）

- 防火分隔。其他房间 2+1+乙（一级耐火楼板1.5H）
- 耐火等级/平面布置。三级≤2层，四级1层；**不能地下且不能4层及以上**
- 安全疏散。疏散距离25/20/15，袋形走道20/15/10；走道尽端不能一个疏散门，其他位置≤50㎡可一个门；多层敞开楼梯间；不可以一个楼梯、不可以一个出口；在其他建筑内应设独立出口
- 消防设施。大中型幼儿园自喷、报警、≥50张床严重危险灭火器、快速响应洒水喷头、自喷轻危险、照度3LX、>15m或>10000m³消火栓、保温A级人密

## 歌舞娱乐（竖向P55）

- 防火分隔。其他房间 2+1+乙
- 耐火等级/平面布置。4层及以上、地下一层每个厅室≤200㎡；**不能地下2层及以下**，地下埋深≤10m；地下百人指标取1
- 安全疏散。疏散距离25/20/15（出口之间）、9（袋形走道）；≤50㎡且≤15人可一个疏散门

## 老年人照料设施（竖向P54）

- 防火分隔。其他房间 2+1+乙
- 耐火等级/平面布置。三级≤2层，一二级≤54m且4层及以上；地下一层活动室≤200㎡且≤30人，休息室不地下（人防老年人不能地下）
- 安全疏散。疏散距离25/20/15、20/15/10（袋形走道）；走道尽端不能一个疏散门，其他位置≤50㎡可一个门；多层封闭楼梯间、高层防烟楼梯间；不可以一个楼梯
- 消防设施。自喷、报警、快速响应洒水喷头、自喷轻危险、≥50张床灭火器严重危险、照度3LX、>5000m³消火栓、保温A级人密、组合>500㎡时A级
- 灭火救援。**5层及以上且总建筑面积>3000㎡**设消防电梯；**3层及以上总建筑面积>3000㎡**设避难间；供失能老年人使用且层数>2层，按核定使用人数配简易防毒面具

## 电影院（竖向P53）

- 防火分隔。2+甲与其他部位分隔；设在其他建筑内需1个独立安全出口和疏散楼梯；宜设独立建筑内
- 耐火等级/平面布置。一二级观众厅宜首层/二层/三层，三级≤2层，不能地下3层；四层及以上时一个厅疏散门≥2个且面积≤400㎡
- 观众厅疏散。走道净宽按每100人≥0.6m且≥1.0m；边走道≥0.8m；横走道间座位排数≤20排；纵走道间座位数≤22个（排距≥0.9m时可增1倍但≤50个）
- 疏散指标。观众厅≤2500座（一二三级）：门走道平坡0.65/阶梯0.85；≤1200座（三级）：0.75/1.00；楼梯0.75/1.00
- 消防设施。高层建筑内应设火灾自动报警和自动喷水；自喷中1级；灭火器观众厅中、舞台严重

## 商业网点（竖向P57）

- 防火分隔。网点之间 2H 防火隔墙**无洞口**；网点和住宅 2H 隔墙无洞口+2H 不燃性楼板
- 面积。**不大于300㎡**
- 功能。百货店、副食店、粮店、邮政所、储蓄所、理发店、洗衣店、药店、洗车店、餐饮店
- 位置。住宅的**首层或首层+二层**

## 考试出题角度

- 各类特殊建筑的防火分隔（2+甲 / 2+1+乙 / 2H无洞口）
- 楼层限制（锅炉房/儿童/歌舞/老年人/影院的最高/最低层数）
- 疏散距离对比（25/20/15、袋形走道各档）
- 商业网点面积≤300㎡、住宅首层+二层
- 老年人照料设施消防电梯/避难间设置条件（5层3000㎡ / 3层3000㎡）
