# 汽车加油、加气站防火

## 一、站级划分

### 加油站等级（柴油罐容积折半计入油罐总容积）

| 级别 | 油罐总容积 V(m³) | 单罐容积 |
|---|---|---|
| 一级 | 150 < V ≤ 210 | ≤50m³ |
| 二级 | 90 < V ≤ 150 | ≤50m³ |
| 三级 | V ≤ 90 | 汽油罐≤30，柴油罐≤50 |

### LPG 加气站等级

| 级别 | LPG罐总容积 V(m³) | 单罐容积 |
|---|---|---|
| 一级 | 45 < V ≤ 60 | ≤30m³ |
| 二级 | 30 < V ≤ 45 | ≤30m³ |
| 三级 | V ≤ 30 | ≤30m³ |

## 二、联合建站禁令（口诀：母N不合建，母油不合建，PN不合建）

不应联合建站的四种组合：
1. CNG 加气**母**站与加油**N**（油）站——"母油不合建"
2. CNG 加气母站与 **LNG** 加气站——"母N不合建"
3. **LPG 加气站与 CNG 加气站**——"PN不合建"
4. LPG 加气站与 LNG 加气站

> 可与电动汽车充电设施联合建站；充电设施应布置在辅助服务区内。

## 三、选址与站区布置

| 项目 | 要求 |
|---|---|
| 城市建成区/中心区 | 不宜建一级加油站、一级加气站、一级合建站、CNG加气母站；宜靠近城市道路但不宜选在城市干道交叉路口附近 |
| 架空线路 | 架空电力线路不应跨越加油加气作业区；架空通信线路不应跨越加气作业区 |
| 出入口 | 车辆入口和出口分开设置 |
| 车道宽度 | CNG母站：单车道≥4.5m、双车道≥9m；其他类型：单车道≥4m、双车道≥6m |
| 道路 | 转弯半径不宜小于9m；坡度≤8%且宜坡向站外；作业区停车位和道路**不得用沥青路面** |
| 围墙 | 工艺设备与站外建构筑物间宜设高度≥2.2m 不燃烧体实体围墙；距离大于安全间距1.5倍且大于25m时可设非实体围墙；面向车辆出入口道路一侧可不设 |
| 明火 | 作业区内不得有明火地点或散发火花地点；爆炸危险区域不应超出站区围墙和可用地界线 |
| 站房 | 可布置在加油加气作业区内 |
| 经营性餐饮/汽车服务 | 不应布置在作业区内（间距按三类保护物）；设明火设备时视为明火地点；加油站内燃煤设备不得按设油气回收折减距离 |

## 四、工艺设备

- 加油机**不得设在室内**
- 自封式加油枪；汽油枪流量≤**50L/min**
- 加油岛端部加油机附近设防撞柱（栏），高≥0.5m
- 油罐车卸油必须采用**密闭卸油**方式
- 地上LPG储罐支座：钢筋混凝土，耐火极限≥**5h**
- 通气管：汽油罐与柴油罐**分开设置**；管口高出地面≥4m；沿墙柱敷设高出建筑物顶面≥2m；设阻火器；公称直径≥50mm

## 五、灭火器材配置

| 对象 | 配置 |
|---|---|
| 加气机（每2台） | ≥2具 5kg 手提式干粉（不足2台按2台） |
| 加油机（每2台） | ≥2具 5kg 手提式干粉，或 1具5kg干粉+1具6L泡沫（不足2台按2台） |
| 地上LPG/LNG储罐、CNG储气设施 | 2台≥35kg 推车式干粉（两介质储罐距离>15m分别配置） |
| 地下储罐 | 1台≥35kg 推车式干粉（>15m分别配置） |
| LPG/LNG泵、压缩机操作间（棚） | 每50m² ≥2具 5kg 手提式干粉 |
| 灭火毯沙子 | 一二级加油站：毯5块+沙2m³；三级：毯≥2块+沙2m³；合建站按同级别加油站 |

## 六、可燃气体检测报警

- 加气站、加油加气合建站**应设**可燃气体检测报警系统
- 一级报警设定值≤爆炸下限的 **25%**
- LPG/LNG 储罐设液位上限下限报警和压力上限报警装置
- 报警器宜集中设在控制室或值班室；配不间断电源
- LNG 泵设超温超压自动停泵保护装置
- 爆炸危险区域以外照明可选非防爆型；罩棚下非爆炸危险区域灯具防护等级≥IP44

## 七、消防给水设置

| 情形 | 要求 |
|---|---|
| 应设 | 加氢站、加油加气站的 **LPG 设施**；设地上LNG储罐的一、二级LNG加气站；地上LNG储罐总容积>60m³的合建站 |
| 可不设 | 加油站、CNG加气站、三级LNG加气站、埋地/地下/半地下LNG储罐各级加气站及合建站；合建站地上LNG储罐总容积≤60m³ |

## 易错点 / 陷阱

- 柴油罐**折半**计入总容积（等级划分关键）
- 三级加油站单罐：汽油30 / 柴油50，别混
- 一级报警25%（人防/综合管廊是20%/25%，不同场所数字易串）
- 消防给水"应设"核心是 LPG 和地上LNG；纯加油站（只加油）不设给水系统

## 记忆方法

- 合建禁令口诀：母N不合建、母油不合建、PN不合建
- 等级分界数字链：加油站 90/150/210；LPG站 30/45/60
