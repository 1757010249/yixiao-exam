# 城市综合管廊防火

> 定义：按统一规划、设计、施工和维护原则，建于城市地下用于容纳**两类及以上**城市工程管线的构筑物及附属设施。又称共同沟、综合管沟、共同管道。

## 一、分类

### 按容纳管线

| 类型 | 特点 |
|---|---|
| 干线综合管廊 | 容纳城市**主干**工程管线，采用**独立分舱**方式建设 |
| 支线综合管廊 | 容纳城市**配给**工程管线，采用单舱或双舱方式建设 |
| 缆线管廊 | **浅埋沟道**方式，有可开启盖板但内部空间不满足人员正常通行；容纳电力电缆和通信线缆 |

### 按结构形式

现浇混凝土综合管廊 / 预制拼装综合管廊

## 二、火灾原因

1. 天然气管道泄漏，造成燃烧和爆炸事故
2. 电力线路过载引起电缆温升超限，造成电力电缆火灾并蔓延
3. 蒸汽管道的不当运行，导致爆炸事故

## 三、舱室火灾危险性分类

| 管线种类 | 火灾危险性 |
|---|---|
| 天然气管道 | **甲** |
| 阻燃电力管道 | 丙 |
| 通信线缆 | 丙 |
| 热力管道 | 丙 |
| 污水管道 | 丁 |
| 雨水管道塑料管等难燃管道 | 丁 |
| 雨水管道钢管、球墨铸铁管等不燃管材 | 戊 |

## 四、耐火与防火分隔（核心：3.00h）

| 部位 | 要求 |
|---|---|
| 主结构体 | 不燃性结构，耐火极限≥**3.00h** |
| 不同舱室之间 | 不燃性结构分隔≥**3.00h** |
| 天然气舱/电缆舱每隔200m分隔 | ≥3.00h 不燃性墙体；甲级防火门；管线穿越用阻火包封堵 |
| 交叉口及各舱室交叉部位 | ≥3.00h 不燃性墙体；甲级防火门；阻火包封堵 |

## 五、天然气管道专项

- 天然气**调压装置不应设在管廊内**
- 分段阀宜设管廊外部；设在内部时应具有远程关闭功能；进出管廊应设具有远程关闭功能的紧急切断阀
- 天然气舱排风口与其他舱室排风口、进风口、人员出入口及周边建（构）筑物口部距离≥**10m**；各类孔口不得与其他舱室连通，设明显警示标识
- 报警浓度设定值（上限）≤爆炸下限的 **20%**；紧急切断设定值 ≤爆炸下限的 **25%**
- 浓度 >爆炸下限 20% 时启动事故段及相邻分区事故通风设备；风机应防爆

## 六、通风

| 项目 | 一般舱室 | 天然气舱 |
|---|---|---|
| 正常通风换气次数 | ≥2次/h | ≥6次/h |
| 事故通风换气次数 | ≥6次/h | ≥12次/h |

- 通风口出风风速不宜大于 **5m/s**；加防小动物金属网格，网孔净尺寸≤**10mm×10mm**
- 发生火灾时，火灾分区及相邻分区通风设备应能自动关闭

## 七、灭火设施与报警

- 灭火器：人员出入口、逃生口、配电夹层等处配置 **2具≥3kg** 手提式干粉灭火器；沿线设置间距≤**50m**
- 自动灭火系统：**干线**管廊容纳电力电缆的舱室、**支线**管廊容纳 **6根及以上**电力电缆的舱室**应设置**；其他电缆舱室宜设置
- 火灾自动报警系统设置条件同自动灭火系统（干线电缆舱 / 支线≥6根电缆舱）
- 应设置**事故后机械排烟设施**

## 八、逃生口与出入口

- 每个舱室应设人员出入口、逃生口，出入口宜与逃生口、吊装口、进风口结合设置且**不少于2个**

| 舱室类型 | 逃生口间距 |
|---|---|
| 电力电缆舱室 | 不宜大于 **400m** |
| 天然气管道舱室 | 不宜大于 **200m** |
| 热力管道舱室 | ≤400m；蒸汽介质时≤**100m** |
| 其他管道舱室 | 不宜大于 400m |

- 逃生口尺寸≥**1m×1m**；圆形时内径≥1m

## 九、供电与照明

- 消防设备、监控与报警设备、应急照明按**二级负荷**供电；天然气舱的监控报警设备、紧急切断阀、事故风机也按二级负荷
- 以**防火分区**作为配电单元
- 非消防设备用阻燃电缆；火灾时需继续工作的消防设备用耐火电缆；天然气舱内电气线路**不应有中间接头**（敷设符合 GB 50058-2014）
- 疏散应急照明照度≥**5lx**，持续供电≥**60min**；灯具防护等级不宜低于 **IP54**
- 安全出口标志灯设在出入口和各防火分区防火门上方；疏散指示标志距地坪 **1.0m** 以下，间距≤**20m**
- 一般照明：人行道平均照度≥15lx、最低≥5lx；出入口和设备操作处局部100lx；监控室≥300lx

## 易错点 / 陷阱

- **3.00h 是管廊主旋律**（主结构体/舱室间/200m分隔/交叉口全是3.00h），与其他构筑物不同
- 换气次数：一般舱 2/6 vs 天然气舱 6/12（正常/事故），别记反
- 逃生口间距"不宜大于"（电力400m/其他400m）vs 热力蒸汽"不应大于100m"，措辞和数值都不同
- 报警20% vs 切断25%

## 记忆方法

- 舱室危险性："甲天丙电通热，丁污雨塑，戊钢雨"（天然气独甲；电力通信热力丙；污水塑料雨水丁；钢管雨水戊）
- 逃生口间距："天二百，电四百，蒸一百"
