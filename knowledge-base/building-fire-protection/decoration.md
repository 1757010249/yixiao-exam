# 装修防火

## 装修材料燃烧性能分级

### A级（不燃）口诀：铜铁石泥土
- 金属类。钢铁、铝、铜合金、金属复合板、铝扣板、木纹金属板
- 石材陶瓷类。花岗石、大理石、水磨石、天然石材、瓷砖、马赛克
- 水泥制品类。水泥制品、混凝土制品、石膏板、石灰制品
- 玻璃板材类。玻璃、玻镁板、硅酸钙板

### B1级（难燃）口诀：绿幕护阻硬多难
- 石膏/矿棉类。纸面石膏板、纤维石膏板、矿棉板、玻璃棉装饰吸声板
- 板材类。水泥刨花板、难燃胶合板、难燃中密度纤维板、难燃木材、彩色难燃人造板
- 复合材料类。铝箔复合材料、铝塑板、难燃玻璃钢平板
- 墙面特有。难燃PVC塑料护墙板、难燃墙纸
- 地面特有。硬PVC塑料地板、难燃羊毛地毯
- 织物。经阻燃处理的各类难燃织物

### B2级（可燃）
各类天然木材、胶合板、塑料壁纸、复合壁纸、半硬质PVC塑料地板等

### B3级（易燃）
严禁使用

## 装修材料特殊升级

| 情况 | 升级结果 |
|---|---|
| 纸面石膏板/矿棉板+金属龙骨 | 可作为A级使用 |
| 小于300g/㎡纸质/布质壁纸+A级基材 | 可作为B1级使用 |
| 无机装修涂料+A级基材 | 可作为A级使用 |
| 有机涂料(湿涂覆比<1.5kg/㎡,干膜≤1.0mm)+A级基材 | 可作为B1级使用 |

## 装修通用要求

- 不应擅自减少、改动、拆除消防设施、疏散指示、安全出口、疏散走道
- 消火栓箱门不应被装饰物遮掩，四周颜色与箱门有明显区别或设发光标志
- 疏散走道/安全出口顶棚、墙面不应采用镜面反光材料

### 记号说明（通用记号）
- 3A = 顶棚+墙面+地面均A级
- 2A = 顶棚+墙面A级
- 1A = 仅顶棚A级

### 提高一级情形
- 无窗房间（除A级外提高一级）
- 经常使用明火器具的餐厅/科研试验室

### 全A级场所
- 设备用房（水泵房、送排烟机房、配电室等）全A
- 电加热供暖室内装修全A
- 变形缝填充材料A级，两侧基层表面B1

## 永不降级场所（核心考点）

| 场所 | 要求 |
|---|---|
| 地上疏散走道/安全出口门厅 | 顶A，其他B1（1A） |
| 中庭/走马廊/开敞楼梯/自动扶梯 | 顶A，墙A，其他B1（2A） |
| 消防控制室等重要房间 | 顶A，墙A，其他B1（2A） |
| 建筑物内厨房 | 顶A，墙A，地A（3A） |
| 地下疏散走道/安全出口门厅 | 顶A，墙A，地A（3A） |
| 疏散楼梯间和前室 | 顶A，墙A，地A（3A） |
| 歌舞娱乐游艺场所(地上) | 顶A，墙B1，地B1...（1A） |
| 文物/重要图书档案(地上) | 顶A，墙A，地B1...（2A） |
| 民用建筑内库房/贮藏间 | 所有部位不低于B1 |

**记忆**。疏散楼梯间/地下走道/厨房=3A（顶墙地全A）；地下歌舞娱乐/文保/机房统一升2A；地下文物库房升5A

## 放宽条件（易错点）

| 情形 | 放宽内容 |
|---|---|
| 面积<100㎡房间+2h隔墙+甲级门 | 所有装修降低一级 |
| 单多层仅设自动灭火 | 除顶棚外所有装修降低一级 |
| 同时设自喷+报警（双自） | 所有装修降低一级 |
| 裙房<500㎡房间+自灭+2h隔墙+甲级门 | 顶/墙/地降低一级 |
| 高层设双自(除>400㎡观众厅/会议厅) | 除顶棚外降低一级 |

## 建筑保温

### 保温材料分级
| 等级 | 材料 |
|---|---|
| A级 | 矿棉、岩棉 |
| B1级 | 胶粉聚苯颗粒 |
| B2级 | 聚苯乙烯泡沫塑料板(EPS/XPS)、硬泡聚氨酯 |
| B3级 | 严禁使用 |

### 内保温
- 人员密集场所/用火燃油燃气场所/疏散楼梯间/避难走道/避难间/避难层 → 应A级（只看场所不看高度）
- 其他场所 → 低烟低毒且不低于B1级

### 外保温（口诀：人员密集A，住宅看高度）
- 人员密集场所建筑 → 外墙外保温应A级
- 住宅H>100m → 应A级
- 住宅27m<H≤100m → 宜A级；可采用B1级（每层防火隔离带≥300mm，门窗耐火完整性≥0.5h）

### 防护层
- 不燃材料；B1级保温材料时防护层厚度≥10mm（首层≥15mm）
