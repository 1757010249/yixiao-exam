# 电气防火

## 灯具与可燃物距离（GB 50016-2014 第10.2.4条）

| 灯具类型 | 与可燃物（可燃材料）距离 |
|---|---|
| 普通灯具 | ≥0.3m |
| 高温灯具、卤钨灯及 100-500W 灯具 | ≥0.5m |
| 501-2000W 灯具 | ≥0.7m |
| 2000W 以上大功率灯具 | ≥1.2m |

- 卤钨灯（高温灯具）等不应直接安装在可燃装修材料或可燃构件上
- 可燃物品库房不应设置卤钨灯等高温照明灯具

## 绝缘电阻（GB 50016-2014 第10.2.6条）

- 电气线路相线间、相线与零线（地）间的**绝缘电阻不应小于 0.5MΩ**（低于 0.5MΩ 视为绝缘不合格，易引发电气火灾）

## 电线电缆选择（GB 51348-2019 第7章）

| 场景 | 电缆选择要求 |
|---|---|
| 一般场所 | 优先采用**铜芯**电缆 |
| 氨压缩机房（氨有腐蚀性） | 应采用**铝芯**电缆（铜遇氨易腐蚀，采用铝芯更耐腐蚀） |
| 人员密集场所 | 普通聚氯乙烯（PVC）电缆不适用，应采用阻燃电缆 |
| 清洁干燥场所 | 可选用交联聚乙烯绝缘电缆 |
| 水平高差大、移动式设备 | 采用橡胶（橡皮）绝缘电缆 |

## 阻燃电缆与耐火电缆

- **阻燃电缆**。遇火不易延燃，阻止火焰蔓延；用于火灾危险性较大的场所
- **耐火电缆**。在火灾中仍能在一定时间内保持通电能力（耐火特性），用于消防配电线路及火灾延续时间内需保持通电的回路
- **明敷（明线敷设）的耐火电缆截面不应小于 2.5mm²**，确保机械强度与耐火性能
- **MI 电缆**（矿物绝缘电缆）。由铜芯、铜护套、氧化镁绝缘构成，耐火性能最优，可用于消防线路明敷
- 耐火电缆与阻燃电缆的区别。阻燃电缆考虑延燃性，耐火电缆考虑耐火（保持通电）性，二者不可混用概念

### 消防系统回路线缆选型（90题考点，齐门遁甲横版）

| 回路 | 线缆要求 |
|---|---|
| 消防供电线路（水泵等） | **耐火铜芯**电线电缆 |
| **消防联动控制线路** | **耐火铜芯**电线电缆（A项"阻燃"错误） |
| 火灾报警总线 | 阻燃或阻燃耐火电线电缆 |
| 消防专用电话线路 | 阻燃或阻燃耐火电线电缆 |
| 消防应急广播线路 | 阻燃或阻燃耐火电线电缆（E项"必须耐火"错误） |

> 口诀。耐火线路=供电+联动控制；阻燃耐火线路=报警总线/广播/电话等传输线路

## 过载保护（GB 50054-2011）

- 保护电器的动作特性应满足。保护电器额定电流或整定电流不大于线路导体允许持续载流量
- **过载保护动作（脱扣）电流不应超过导体允许载流量的 1.45 倍**，防止线路过载过热引发火灾

## 照明电压（GB 50016-2014 第10.2.5条）

| 场所 | 照明电压 |
|---|---|
| 一般照明 | 220V |
| 行灯（手持移动照明） | 不应超过 36V |
| 金属容器内、特别潮湿场所 | 不应超过 12V |
| 隧道、地下构筑物等场所照明 | 应符合相应规范要求 |

## 分支回路电流（GB 51348-2019 第7.2节）

- 每个照明分支回路所接灯具数量不宜过多，分支回路额定电流不宜超过 **16A**，所接灯具数量不超过 **25 个**
- 分支回路电流 **25A** 时，所接灯具数量不超过 **60 个**
- 采用**高强度气体放电灯**的分支回路，电流不应超过 **30A**
- 插座回路。每回路插座数量不宜超过 10 个（住宅）等，按规范执行

## 电动机防火

- 电动机应安装在**不燃**材料（机座、基础上），远离可燃物
- 电动机与墙壁间净距不小于 **1m** 的通道；与其他设备的**裸露带电部分**距离不应小于 **1m**（1号书 P233）
- 绝缘要求。380V 电动机绕组绝缘电阻 ≥**0.5MΩ**；**6KV** 及以上高压电动机 ≥**6MΩ**
- 启动限制。电动机**冷态启动连续不超过 5 次**，**热态启动连续不超过 2 次**，避免过载发热
- 电动机应有过载、短路、失压、断相等保护，传动部位应有防护罩
- 长期停用的电动机启动前应检测绝缘电阻合格

## 规范依据

- GB 50016-2014 第10.2.1~10.2.7条。电气装置防火
- GB 50016-2014 第10.2.8条。可燃材料库房照明要求
- GB 50016-2014 第10.2.9条。消防配电线路要求
- GB 51348-2019《民用建筑电气设计标准》。电线电缆选择、分支回路
- GB 50054-2011《低压配电设计规范》。过载保护（1.45 倍）

## 易错点 / 陷阱

- 灯具距离按功率分档。0.3 / 0.5 / 0.7 / 1.2m，注意 501-2000W 是 0.7m 不是 0.5m
- 绝缘电阻 0.5MΩ 是相线间与相线对地的底线值
- 氨压缩机房用铝芯（铜会腐蚀），人员密集场所不用普通 PVC 电缆
- 耐火电缆与阻燃电缆是不同概念；明敷耐火电缆截面 ≥2.5mm²
- 照明电压。一般220、行灯36、金属容器/特别潮湿12
- 电动机冷态启动 ≤5 次、热态启动 ≤2 次

## 考试出题角度

- 实务。灯具与可燃物距离、照明电压、绝缘电阻数值
- 综合。电气线路检查、电动机维护检查、电缆选型是否合规
- 案例。商场/仓库电气防火措施是否满足要求
