# 地铁防火

## 一、火灾危险性与特点

**火灾危险性**：①空间小、人员密度和流量大 ②用电设施设备繁多 ③动态火灾隐患多

**火灾特点**：①火情探测和扑救困难 ②易导致人员窒息 ③产生有毒烟气、排烟排热效果差 ④人员疏散困难

## 二、耐火等级（口诀：地下易变心=一级）

### 一级（地下易变心）

1. 地下车站及其出入口通道、风道
2. 地下区间、联络通道、区间风井及风道
3. 控制中心
4. 主变电所
5. **易燃物品库、油漆库**
6. 地下停车库、列检库、停车列检库、运用库、联合检修库及其他检修用房

### 不低于三级

- 地上车站及地上区间；地下车站出入口地面厅、风亭等地面建（构）筑物
- 运用库、检修库、综合维修中心的维修综合楼、物质总库的库房、调机库、牵引降压混合变电所、洗车机库（棚）、不落轮镟库、工程车库和综合办公楼等生活辅助建筑

## 三、商铺与非地铁功能场所

- 站台层、站厅付费区、站厅非付费区乘客疏散区及疏散通道内：**严禁**设商铺和非地铁运营用房
- 站厅非付费区疏散区外商铺：不得经营储存甲乙类商品和可燃性液体类商品；每个站厅商铺总面积≤**100m²**、单处≤**30m²**；用≥2.00h防火隔墙或≥3.00h防火卷帘分隔；商铺内设火灾自动报警和灭火系统
- 站厅层与站台层之间设商业场所时：站台至站厅楼梯扶梯不得与商业场所连通，穿越部位周围设无门窗洞口的防火墙

## 四、车辆基地与特殊用房

| 用房 | 要求 |
|---|---|
| 车辆基地上部设其他功能场所 | 分隔楼板≥3.00h；承重构件≥3.00h、楼板≥2.00h；上部与车辆基地人员安全出口分别独立、不得借用 |
| 酸性蓄电池充电间 | 宜独立建造，不与值班室等经常有人场所相邻；合建时靠外墙单层设置+防火墙分隔+甲级防火门窗 |
| 油漆库及预处理库 | 宜独立建造；油漆存放间/漆工间/干燥间用防火墙+甲级门分隔；不发火花地面；不设办公休息更衣室；与联合检修库合建时布置在外墙一侧+无门窗洞口防火墙 |

## 五、防火分区

| 部位 | 最大允许建筑面积 |
|---|---|
| 地下车站站台+站厅公共区 | 可划同一防火分区，站厅公共区≤**5000m²** |
| 地下车站设备管理区 | 与公共区分区，≤**1500m²**（水泵房/污水废水泵房/厕所/盥洗/茶水/清扫不计入） |
| 地上车站站厅公共区 | ≤5000m² |
| 地上设备管理区 | ≤2500m²；建筑高度>24m高架车站设备管理区≤1500m² |
| 地下车库/列检库/停车列检库/运用库/联合检修库 | 单独划分，≤**6000m²**；设自动灭火系统时不限 |
| 地下一层侧式站台与同层站厅 | 可划同一防火分区，但站台上任一点至直通地面疏散通道口≤50m（>50m 时加≥2.00h防火隔墙） |

### 换乘车站分隔

| 类型 | 分隔要求 |
|---|---|
| 上下重叠平行站台 | 下层穿越上层开口部位≥2.00h防火隔墙；上下层联系楼梯除通行部位可用≥3.00h防火卷帘外均≥2.00h隔墙 |
| 多线同层平行换乘 | 各站台之间≥2.00h纵向防火隔墙，延伸至站台有效长度外≥10m |
| 点式换乘通道 | 换乘梯通行部位可用≥3.00h卷帘，其余≥2.00h隔墙 |
| 站厅站台间设备层 | 楼梯扶梯穿越部位周围设无门窗洞口防火墙 |

## 六、安全疏散

- **站台疏散时间**：超高峰小时最大客流时，一列进站列车乘客及候车乘客 **4min 内撤离站台、6min 内疏散至站厅或其他安全区域**
- 站厅公共区至少2个直通室外安全出口；相邻出口最小水平距离≥20m；换乘共用站厅每条线≥2个
- 设备管理区每个防火分区出口≥2个且至少1个直通地面；值守人员≤3人可借用相邻分区防火门或通向站厅出口
- 设备管理用房疏散门至安全出口：两出口之间≤40m、袋形走道≤22m
- 车库列检库室内最远一点至安全出口≤45m（设自动灭火≤60m）
- 出入口通道长度不宜>100m；>100m 时增设安全出口，通道内任一点至最近安全出口≤50m
- 地下一层侧式站台：每侧至少2个直通地面安全出口；站台与站厅间设防火隔墙时至少2个门洞（间距≥10m）；未设隔墙时任一点至地面疏散时间≤6min
- **联络通道**：两条单线载客运营地下区间之间应设；相邻联络通道最小水平距离≤600m；通道内设一道并列二樘反向开启的甲级防火门
- **纵向疏散平台**：单侧临空宽≥0.6m、双侧临空宽≥0.9m
- 消防专用通道：地下车站应设；车站超过3层（含3层）时应设为防烟楼梯间
- 疏散用自动扶梯：一级负荷、不燃材料、事故时保持运行、平时运行方向与疏散方向一致、下部空间防火分隔

## 七、防排烟

| 项目 | 要求 |
|---|---|
| 排烟风机耐温 | 地下车站/区间：280℃连续≥1.0h；地上车站/控制中心及其他附属建筑：280℃连续≥0.5h |
| 区间排烟风机运转时间 | ≥区间乘客疏散所需最长时间 |
| 风机切换 | 静态转事故状态≤30s；运转状态转事故状态≤60s |
| 区间排烟风速 | 纵向通风断面≥2m/s 且 ≤11m/s |
| 排烟量 | ≥60m³/(m²·h)按防烟分区分别计算；含轨道区按列车设计火灾规模；地下站台保证站厅到站台楼梯口≥1.5m/s向下气流 |
| 最小风量 | 排烟风机风量≥7200m³/h |
| 排烟管道 | 不燃材料；不应穿越前室或楼梯间（必须穿越时耐火极限≥2.00h）；共用机房时机房内排烟管道≥1.50h |
| 防烟分区 | 挡烟垂壁或建筑结构划分，不跨越防火分区；站厅公共区≤2000m²、设备管理区≤750m² |
| 挡烟垂壁 | 不燃材料、耐火极限≥0.50h、凸出顶棚≥0.5m；下缘距地面/踏步面≥2.3m；楼扶梯穿越楼板开口部位、吊顶高差<0.5m部位应设 |
| 应设排烟场所 | 地下/封闭车站站厅站台公共区；防火分区内总建筑面积>200m²的地下设备管理区；单个>50m²经常有人或可燃物多的房间；连续长度大于一列列车长度的地下区间和全封闭车道；>20m内走道；>60m地下换乘/连接/出入口通道 |
| 合用系统 | 机械防烟排烟可与正常通风合用，转换时间≤180s |

## 八、消防供电与装修

- 消防用电为**一级负荷**；火灾自动报警系统、环境与设备监控系统、变电所操作电源、地下车站及区间应急照明为**特别重要负荷**
- 应急照明专用回路，公共区与设备管理区分回路；备用照明和疏散照明不同一分支回路
- 装修材料：
  - 地下车站公共区和设备管理区：顶棚墙面地面及垃圾箱全 A 级
  - 地上车站公共区：墙面顶棚及垃圾箱 A 级，地面≥B1级
  - 疏散部位和消防专用通道全 A 级（站台门绝缘层、地上自然排烟房间地面可为B1）
  - 广告灯箱/导向标志/座椅/电话亭/售检票亭等固定设施≥B1
  - 禁用石棉制品、玻璃纤维、塑料类制品
- 自动喷水灭火系统：建筑面积>6000m² 的地下/半地下/上盖有其他功能建筑的停车库、列检库、停车列检库、运用库、联合检修库应设
- 防火封堵：管线穿越防火墙/隔墙/楼板紧密填实；穿越处两侧各1.0m内保温材料不燃
- 防火门窗：防火墙/前室入口/联络通道处甲级门；防火隔墙上乙级门；防火墙窗口固定式甲级窗、防火隔墙固定式乙级窗；**乘客疏散通道上不应设防火卷帘**

## 易错点 / 陷阱

- 排烟风机 280℃：地下1.0h vs 地上0.5h
- 防烟分区：站厅2000 vs 设备管理区750
- 疏散时间：4min撤离站台 / 6min到站厅
- 设备管理区防火分区：地下1500 / 地上2500 / 高架24m以上1500
- 联络通道600m + 反向开启甲级防火门并列二樘

## 记忆方法

- 耐火一级口诀：**地下易变心**（地下车站、易燃品库油漆库、变电所、控制中心、地下车库运用库）
- 数字链：4min/6min → 45m/60m → 100m/50m → 600m联络通道

## 规范依据

- GB 51298-2018《地铁设计防火标准》第4章（地下车站）、第5章（区间）、第6章（车辆基地）、第7章（消防给水及灭火设施）、第8章（防排烟与应急疏散）

## 考试出题角度

- **实务**。耐火等级判断、防火分区面积、商铺限制参数、排烟参数
- **案例**。站台火灾应急处置（联动释放闸机/禁后续列车进站/商场侧卷帘——注意电梯不可切断电源直接停站厅）

## 真题 / 例题

- 地铁火灾危险性说法错误的：D（站台公共区火灾蔓延具有跳跃性）（讲义P63例题）
- 站台火灾应急处置错误的：A（将电梯停至站厅后切断所有电梯和扶梯电源）（讲义P69例题）
