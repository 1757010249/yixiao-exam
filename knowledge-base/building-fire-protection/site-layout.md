# 总平面布局与防火间距

## 建筑选址

- 易燃易爆工厂/仓库/专用车站码头 → 设在城市边缘或独立安全地带
- 甲乙丙类液体仓库 → 宜布置在地势较低处（防火灾威胁周围）
- 乙炔站 → 严禁布置在可能被水淹没的地方（遇水产生可燃气体）
- 散发可燃气体/粉尘的车间 → 宜布置在明火或散发火花地点**全年最小频率风向的上风侧**
- 液化石油气储罐区 → 全年最小频率风向上风侧，地势平坦开阔，四周设≥1.0m不燃实体防护墙
- 桶装/瓶装甲类液体 → 不应露天存放

## 防火间距量法

| 对象 | 量法 |
|---|---|
| 建筑物之间 | 相邻建筑外墙最近水平距离；外墙有凸出可燃/难燃构件时从凸出外缘算 |
| 建筑与储罐 | 建筑外墙至储罐外壁最近水平距离 |
| 储罐之间 | 相邻两储罐外壁最近水平距离 |
| 与道路/铁路 | 建筑外墙/储罐外壁/堆垛外缘距路边或铁路中心线水平距离 |

## 厂房防火间距计算

**公式。S = A + B1 + B2**

| 参数 | 取值 |
|---|---|
| A（基准值） | 一般取10；有甲类厂房取12；有高层厂房取13 |
| B1（本建筑修正） | 一二级取0；三级取2；四级取4 |
| B2（相邻建筑修正） | 一二级取0；三级取2；四级取4 |

**特殊固定值**
- 甲类厂房与人员密集场所 ≥50m；与明火/散发火花地点 ≥30m
- 乙类厂房与重要公共建筑 ≥50m；与明火/散发火花地点 ≥30m

## 防火间距减免规定（易错点）

### 不限情形
1. 两座厂房相邻较高一面外墙为防火墙 → 不限（**但甲类厂房之间不应小于4m**）
2. 相邻两座高度相同的一二级建筑，任一侧外墙为防火墙且屋顶耐火极限≥1.00h → 不限（甲类厂房之间不应小于4m）

### 减为6m/4m
条件。两座均一二级，较低一面外墙为防火墙且屋顶无天窗+耐火极限≥1.00h；或较高一面外墙开口设甲级防火门/窗/卷帘/水幕
- 甲乙类厂房之间 → 不应小于6m
- 丙丁戊类厂房之间 → 不应小于4m

### 减少25%
条件。丙丁戊类厂房相邻两面外墙均不燃 + 无外露可燃屋檐 + 门窗洞口面积各≤外墙5% + 门窗不正对开设
→ 防火间距可按规定值减少25%

### 减少2m
- 单多层戊类厂房之间及与戊类仓库 → 可减少2m（高层戊类不适用）

### 特殊规定
- 单多层戊类厂房与民用建筑 → 按民用建筑计算
- 为丙丁戊厂房服务的独立生活用房 → 按民用建筑，与所属厂房间距≥6m
- 总容量≤15m³丙类液体储罐直埋厂房外墙外，面向储罐4m内外墙为防火墙 → 间距不限
- 厂区围墙与厂内建筑间距不宜小于5m

## 防火间距不足措施（口诀：改提高）

1. 改。改变生产使用性质，降低火灾危险性，提高耐火等级
2. 提。调整工艺流程，限制储存量，提高构件耐火极限
3. 拆。拆除部分耐火等级低、占地面积大、适用性不强的新建建筑物
4. 设。设置独立的室外防火墙

## 消防车道（P67）

- 车道的净宽和净空高度均不应小于4.0m
- 转弯半径应满足消防车转弯要求
- 消防车道与建筑之间不应设置妨碍消防车操作的障碍物
- 环形消防车道。高层民用建筑、超过3000座体育馆、超过2000座会堂、占地面积>3000㎡商店/展览建筑等应设
- 沿建筑两个长边设置消防车道。建筑高度>50m 或 长边长度>建筑高度的建筑

## 消防车登高操作场地

- 场地长度和宽度分别不应小于15m和10m（建筑高度>50m时，长度和宽度分别≥20m和10m）
- 场地靠建筑外墙一侧的边缘距离建筑外墙不宜小于5m，且不应大于10m
- 场地的坡度不宜大于3%

## 考试出题角度

- 厂房防火间距计算（S=A+B1+B2）
- 减免条件判断（防火墙/甲级门窗/25%减少等）
- 选址风向判断（上风侧/下风侧）
- 消防车道设置条件
