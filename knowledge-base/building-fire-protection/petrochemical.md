# 石油化工企业防火

## 一、火灾危险性与火灾特点

**火灾危险性**：①原料中间体及产品易燃易爆 ②工艺装置泄漏易形成爆炸性混合物 ③温度压力参数控制不当易引发爆炸火灾 ④违章操作等人为因素

**火灾特点**：①爆炸与燃烧并存，易造成人员伤亡 ②燃烧速度快，火势发展迅猛 ③易形成立体火灾 ④火灾扑救困难

## 二、液化烃及可燃液体火灾危险性分类（GB 50160 表3.0.3）

| 类别 | 特征（闪点 Ft） | 典型物质 |
|---|---|---|
| **甲A**（液化烃） | 15℃蒸气压>0.1MPa 的烃类液体及类似液体 | 液化氯甲烷、液化乙烯/乙烷/丙烯/丙烷、液化丁烷/丁烯、液化石油气、液化环氧乙烷、二甲胺、三甲胺、二甲醚等（口诀：**液化二三甲**） |
| **甲B** | Ft <28℃（甲A以外） | 原油、石脑油、汽油、戊烷、己烷、苯、甲苯、二甲苯、甲醇、乙醇、丙酮、乙醚、乙醛、二硫化碳、丙烯腈等 |
| **乙A** | 28≤Ft<45℃ | 煤油、喷气燃料、丙苯、异丙苯、苯乙烯、丁醇、环己酮、冰醋酸、液氨 |
| **乙B** | 45≤Ft<60℃ | 轻柴油、环戊烷、氯乙醇、二甲基甲酰胺、二乙基苯、液硫 |
| **丙A** | 60≤Ft≤120℃ | 重柴油、20号重油、苯胺、锭子油、酚、甲醛、糠醛、乙二醇、丙二醇、辛醇 |
| **丙B** | Ft >120℃ | 蜡油、100号重油、渣油、变压器油、润滑油、液体沥青、甘油、二甘醇、三甘醇 |

### 操作温度升级规则（42章经电子卡·小项6补充）

操作温度超过特定温度点时，火灾危险性应升级判定：

| 原类别 | 条件 | 升级为 |
|---|---|---|
| 丙A类液体 | 操作温度超过其**闪点** | **乙A类** |
| 丙B类液体 | 操作温度超过其**沸点** | **乙A类** |
| 丙B类液体 | 操作温度超过其**闪点**（未超沸点） | **乙B类** |

- 逻辑。操作温度高于闪点意味着液面上方蒸气浓度可达燃烧范围，危险性按更高级别液体对待

## 三、区域规划

- 应远离人口密集区、饮用水源地、重要交通枢纽；宜位于邻近城镇或居民区**全年最小频率风向的上风侧**
- 山区丘陵：生产区避免布置在窝风地带
- 沿江河布置：宜位于邻近江河城镇、重要桥梁、大型锚地、船厂等重要构筑物的**下游**
- 防止泄漏可燃液体和受污染消防水排出厂外
- **公路和地区架空电力线路严禁穿越生产区**；地区输油（输气）管道不应穿越厂区
- 区域排洪沟不宜通过生产区；应防泄漏液体和污染消防水流入排洪沟

## 四、总平面布置（风向规律总结）

| 设施 | 布置要求 |
|---|---|
| 散发可燃气体设施（工艺装置/罐组/装卸区/全厂性污水处理场） | 宜在人员集中场所及明火地点的**全年最小频率风向的上风侧** |
| 空分站 | 布置在空气清洁地段，宜位于散发乙炔/可燃气体/粉尘场所的全年最小频率风向的**下风侧** |
| 全厂性高架火炬 | 宜位于生产区**全年最小频率风向的上风侧** |
| 罐区泡沫站 | 罐组防火堤外的非防爆区，与可燃液体罐防火间距≥**20m** |
| 办公楼/中央控制室/化验室/总变电所等重要设施 | 布置在**相对高处** |
| 液化烃罐组/可燃液体罐组 | 不应毗邻布置在高于工艺装置、重要设施或人员集中场所的阶梯上；不宜紧靠排洪沟 |
| 中央控制室 | 宜布置在行政管理区 |
| 总变电所（架空电力线进出厂区） | 布置在厂区边缘 |

### 厂区绿化

- 生产区不应种植含油脂较多的树木，宜选含水分多的树种
- 工艺装置或罐组与消防车道之间不宜种植绿篱或茂密灌木丛
- 可燃液体罐组防火堤内：可种高度≤15cm 含水分多的常青草皮
- **液化烃罐组防火堤内严禁绿化**

## 五、消防站与消防车道

### 消防站（厂内）

- 服务范围按行车路程计≤**2.5km**，接火警后到达火场时间≤5min；丁、戊类局部场所可加大到4km
- 位置：便于通往工艺装置区和罐区；避开工厂主要人流道路；远离噪声场所；宜位于生产区全年最小频率风向的下风侧
- （石油库）消防车库、办公室、控制室宜布置在储罐区全年最小频率风向的下风侧

### 消防车道

- 可燃液体储罐区、可燃气体储罐区、装卸区及化学危险品仓库区应设**环形消防车道**（受地形限制可设带回车场的尽头式）
- 一般要求：路面宽≥**6m**、内缘转弯半径≥**12m**、净空高≥**5m**
- 占地>80000m² 的装置或联合装置、含单罐>50000m³ 的可燃液体罐组：路面宽≥**9m**、转弯半径≥**15m**

## 易错点 / 陷阱

- **风向口诀辨析**："散发可燃气体设施"和"高架火炬"是**上风侧**；"空分站"和"厂内消防站"是**下风侧**——最易混
- 甲A是液化烃（蒸气压判定），不是闪点判定；甲B才看闪点<28℃
- 消防车道大型装置9m/15m vs 一般6m/12m
- 罐区泡沫站20m间距、"防火堤外非防爆区"

## 记忆方法

- 甲类液体口诀：**液化二三甲**（液化烃+二甲胺+三甲胺+二甲醚）
- 风向记忆："怕气的上风躲（散发可燃气设施上风），要净风的下风吸（空分站下风）"
