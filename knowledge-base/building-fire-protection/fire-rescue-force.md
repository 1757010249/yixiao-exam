# 灭火救援力量（消防站与分级调派）

## 一、城市消防站分类

| 类型 | 职能 | 辖区面积 | 执勤人数/班次 | 车辆数 |
|---|---|---|---|---|
| 一级普通消防站 | 火灾扑救+一般抢险救援主体力量 | ≤**7km²** | 30~45人 | 5~7辆 |
| 二级普通消防站 | 同上 | ≤4km² | 15~25人 | 2~4辆 |
| 小型普通消防站 | 多位于城市中心区 | ≤2km² | 15人（两个战斗班） | 2辆 |
| 特勤消防站 | 特种灾害救援+特殊火灾扑救；地级及以上城市应设 | 兼有辖区时同一级站（≤7km²） | 45~60人 | 8~11辆 |
| 战勤保障消防站 | 装备器材储备运输维修保养+应急综合保障；地级及以上及经济发达城市应设 | **不单独划分辖区**（10min到场） | 40~55人（下设技术/生活/卫勤/物资/社会联勤5个分队，每分队8~11人） | — |

- 近郊区及其他规划控制区普通站辖区面积不宜大于 **15km²**
- 兼有辖区任务的特勤站，同一辖区内一般不再另设一级站

## 二、规划布局核心：15min消防时间

- 布局原则：接到出动指令后 **5min 内到达辖区边缘**（战勤站10min）
- **15min消防时间**（火灾初起阶段）：发现起火 **4min** + 报警和指挥中心处警 **2.5min** + 接到指令出动 **1min** + 行车到场 **4min** + 开始出水扑救 **3.5min**

## 三、选址要求

1. 设在辖区内适中位置、便于车辆迅速出动的临街地段，靠近城市应急救援通道
2. 执勤车辆主出入口两侧宜设交通信号灯、标志、标线
3. 距医院、学校、幼儿园、托儿所、影剧院、商场等人员较多公共建筑主要疏散出口≥**50m**（防警报惊慌）
4. 辖区内有易燃易爆危险品单位的，设在常年主导风向的**上风或侧风处**（最小频率下风侧），边界距该部位≥**200m**
5. 消防车库门朝向城市道路，**后退红线不宜小于15m**（合建小型站除外）

## 四、火警分级（一至五级，一级最低五级最高）

| 等级 | 颜色 | 主要情形 |
|---|---|---|
| 一级 | 绿 | 无人员伤亡被困且燃烧面积小的普通建筑火警；带电设备/线路火警 |
| 二级 | 蓝 | 较少人员伤亡被困；燃烧面积大的普通建筑；燃烧面积小的高层/地下/人员密集/易燃易爆/重要/特殊场所火警 |
| 三级 | 黄 | 少量伤亡被困；燃烧面积小→上述特殊场所升级描述 |
| 四级 | 橙 | 较多伤亡被困；燃烧面积较大 |
| 五级 | 红 | 大量伤亡被困；燃烧面积大 |

### 火警自动升级条件

①重大节日/重要政治活动/政治敏感区域 ②风力6级以上或阵风7级以上、冰冻严寒等恶劣气候 ③**当日22时至次日6时** ④同一地点报警电话持续增多成灾迹象明显 ⑤其他

## 五、应急救援分级（一至四级，一级最低四级最高）

| 等级 | 颜色 | 主要情形 |
|---|---|---|
| 一级 | 蓝 | 无伤亡被困；危害不大短时能排除（小型建筑倒塌、较轻交通事故、一般自然灾害、群众求助） |
| 二级 | 黄 | 较少伤亡被困；少量危化品泄漏、较严重交通事故、较大型建筑倒塌、小面积爆炸 |
| 三级 | 橙 | 少量伤亡被困；重大交通事故、大型建筑倒塌、大量危化品泄漏、二次污染风险 |
| 四级 | 红 | 较多伤亡被困；危化品泄漏/毒气扩散、大量建筑倒塌、特大爆炸、恐怖事件、严重自然灾害 |

- 救援自动升级条件比火警少"恶劣气候"一项（无风力条款）

## 六、调派原则

- 第一出动先调派**普通消防站**
- 高层/地下轨道交通/大型商业综合体/石油化工等灾情或普通站无法应对时：同时调派**特勤消防站**
- **三级及以上**火警和应急救援任务：同时调派**战勤保障消防站**

## 七、单位专职消防队（《消防法》第39条应建单位）

1. 大型核设施单位、大型发电厂、民用机场、主要港口
2. 生产储存易燃易爆危险品的大型企业
3. 储备可燃重要物资的大型仓库基地
4. 火灾危险性较大、距国家综合性消防救援队较远的其他大型企业
5. 距离较远、列为全国重点文物保护单位的古建筑群管理单位

管理要求：24h执勤值守轮值轮班；接受当地县级以上消防救援机构调度指挥；纳入县区接警调度体系按就近调派；"5min到场"

## 八、微型消防站（救早灭小、"3min到场"）

| 项目 | 社区微型消防站 | 重点单位微型消防站 |
|---|---|---|
| 人员 | 站长1名+队员≥5名（保安员/治安联防队员/社区工作人员兼职志愿） | ≥6人；站长（消防安全管理人兼任）/副站长/消防员/控制室值班员，配车加驾驶员岗 |
| 值守 | 24h值守分班编组 | 24h在岗在位 |
| 调派 | 1min内核实警情启动处置并拨119；3min到场处置 | 控制室值班员核实火情启动程序；3min到场 |
| 器材 | 消防摩托车+灭火水枪水带等；可选小型消防车 | 灭火器水枪水带；外线电话对讲机；建筑物内和避难层设器材存放点 |

## 九、乡镇消防队

| 项目 | 一级乡镇专职队 | 二级乡镇专职队 | 乡镇志愿队 |
|---|---|---|---|
| 建立条件 | 建成区>5km²或常住>50000人；易燃易爆+劳动密集集中乡镇；全国重点镇 | 建成区2~5km²或常住20000~50000人；省级重点镇中心镇；历史文化名镇；其他经济发达人口集中乡镇 | — |
| 消防员人数 | ≥15（专职≥8） | ≥10（专职≥5） | ≥8（专职≥2） |
| 水罐/泡沫车 | ≥2 | ≥1 | ≥1 |
| 消防摩托车 | 2 | 1 | 1 |

- 选址同城市消防站（距公共建筑疏散出口≥50m、距危化品部位≥200m上风侧风）
- 人员构成：正副队长各1名；每班组≥4名消防员+班组长1名；明确1名通信员1名安全员（志愿队驾驶员可兼通信员）

## 易错点 / 陷阱

- 辖区面积：一级7 / 二级4 / 小型2 / 特勤同级一级 / 近郊区15（km²）
- 到场时间：普通站5min / 战勤站10min / 微型站3min / 单位专职队5min
- 火警五级（绿蓝黄橙红）vs 应急救援四级（蓝黄橙红）——颜色起点不同
- 升级条件：火警含恶劣气候，应急救援无此条
- 战勤保障调派门槛是"三级及以上"，不是所有级别

## 记忆方法

- 15min分配口诀："发现4、报警2.5、出动1、行车4、出水3.5"
- 分级颜色："绿蓝黄橙红"火警从绿起；救援没有绿色直接蓝色起步
