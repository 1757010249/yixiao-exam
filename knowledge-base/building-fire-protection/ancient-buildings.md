# 古建筑防火

## 一、火灾危险性（五大特点）

1. 耐火等级低，火灾荷载大
2. 组群布局，火势蔓延迅速
3. 形体高大，有效控制火势难
4. 远离城镇，灭火救援困难
5. 用火用电多，管理难度大

## 二、消防救援力量配置

| 项目 | 要求 |
|---|---|
| 单位专职消防队 | 距国家综合性消防救援队较远、列为**全国重点文物保护单位**的古建筑群管理单位应建立 |
| 消防站 | 改造规划中可建多种形式消防站；选址不破坏整体格局、到场时间最短；规模小型适用，不追求大而全 |
| 消防点 | 与最近消防站较远、消防站接警后 **5min 内不能到达**时应设置；以 5min 内到达火点为标准选址；优先利用原有建筑及场地，建筑面积不宜小于 **15m²**；严寒寒冷地区保温；设明显标志 |

## 三、防火分隔与间距

| 项目 | 要求 |
|---|---|
| 消防分区 | 保持文物建筑风貌真实性完整性；单个消防分区占地面积宜 **3000~5000m²** |
| 分区划分 | 宜用既有防火墙、道路、水系、广场、绿地划分；可拆除个别阻碍分区的非文物建筑 |
| 保护区分隔 | 防火保护区与控制区之间宜采取道路、水系、广场、绿地等防火隔离带或其他有效防火措施 |
| 相邻建筑间距 | 参照 GB 50016 留出足够防火间距；无法开辟时设防火墙、水幕等分隔设施 |
| 森林郊野古建筑 | 周围开辟宽 **30~50m** 防火隔离带；秋冬季节清除 **30m** 范围内杂草、干枯树枝等可燃物 |

## 四、防火管理

- **禁止**：保护范围内堆存柴草、木料等易燃可燃物品；主要殿屋设置生产生活用火（厢房、走廊、庭院需用时必须有防火安全措施）
- **严禁**：将煤气、液化石油气引入古建筑内；使用卤钨灯等高温照明灯具和电炉等电加热器具
- 照明限制：不准使用荧光灯和大于 **60W** 的白炽灯
- 灯饰材料燃烧性能不应低于 **B1级**，且不得靠近可燃物

## 易错点 / 陷阱

- **30-50m 隔离带 vs 清除 30m 杂草**：两个数字不同，隔离带是开辟宽度、清杂是范围半径
- 消防点面积"不宜小于15m²"是**下限**不是上限
- >60W 白炽灯禁用，≤60W 可用；荧光灯同样不准使用

## 记忆方法

- 五大特点口诀联想："低大高远多"（耐火低荷载大、形体高、离城远、火电源多）
- 数字链：5min 消防点 → 15m² → 3000~5000m² 分区 → 30-50m 隔离带

## 规范依据

- GB 50016-2014《建筑设计防火规范》（相邻建筑面积参照）
- 《文物建筑防火设计导则（试行）》（消防分区、消防点设置要求）

## 考试出题角度

- **实务/综合**。消防点设置条件（5min、15m²）、消防分区面积、隔离带宽度数字判断
