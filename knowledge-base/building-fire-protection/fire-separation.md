# 防火分隔

## 上下层开口防火（GB 50016-2014 第6.2.5条）

建筑外墙上、下层开口之间应防止火灾向上层蔓延：

| 措施 | 要求 |
|---|---|
| 实体墙 | 高度不应小于 **1.2m** |
| 防火挑檐 | 挑出宽度不应小于 **1.0m**，且长度不小于开口宽度 |
| 设置自喷时 | 上下层开口之间的实体墙高度可减至 **0.8m** |
| 防火玻璃墙 | 高层建筑防火玻璃墙耐火完整性 ≥**1.00h**；多层建筑 ≥**0.50h**（外窗耐火完整性不低于玻璃墙要求） |
| 住宅户间 | 相邻户开口之间的墙体宽度 ≥**1.0m**；小于 1.0m 时在开口之间设置突出外墙 ≥**0.6m** 的隔板 |

### 水平开口间距汇总口诀（室外2m、转角翻倍4m、室内1m）

| 情况 | 距离 | 规范条文 |
|---|---|---|
| 室外疏散楼梯周围墙面（除疏散门）不设门窗洞口 | 2m | GB 50016-2014 第6.4.5条 |
| 防火墙两侧门窗洞口最近边缘水平距离 | 2m | GB 50016-2014 第6.1.3条 |
| 防火墙内转角两侧门窗洞口最近边缘水平距离 | 4m（转角翻倍） | GB 50016-2014 第6.1.4条 |
| 楼梯间、前室及合用前室外墙窗口与两侧门窗洞口 | 1m | GB 50016-2014 第6.4.1条 |
| 墙壁水泵接合器与门窗孔洞净距 | 2m | GB 50974-2014 |

**例外（竖向开口，勿套用 2m）**。建筑外墙上、下层开口之间防蔓延措施——实体墙≥1.2m、防火挑檐挑出≥1.0m、设自喷时实体墙减至0.8m（GB 50016-2014 第6.2.5条）；住宅相邻户开口间墙体宽≥1.0m（不足时突出外墙≥0.6m隔板）。

> 记忆锚。室外2m、转角翻倍4m、室内1m。

## 防火墙构造（GB 50016-2014 第6.1节）

| 项目 | 要求 |
|---|---|
| 高出屋面 | 防火墙应高出屋面 ≥**0.5m**（屋盖耐火极限≥0.50h 时不受此限） |
| 凸出外墙 | 建筑外墙为难燃/可燃墙体时，防火墙凸出墙外表面 ≥**0.4m**，且两侧外墙均为宽度 ≥**2.0m** 的不燃性墙体 |
| 内转角 | 防火墙不宜设在转角处；确需设置时，内转角两侧墙上门窗洞口最近边缘水平距离 ≥**4.0m** |
| 门窗洞口 | 防火墙上确需开设门窗时，应设不可开启或火灾时能自动关闭的**甲级**防火门、窗 |
| 管道 | **可燃气体和甲、乙、丙类液体的管道严禁穿过防火墙** |
| 排气道 | 防火墙内不应设置排气道 |
| 承重 | 防火墙应直接设置在建筑的基础或框架、梁等承重结构上，从楼地面基层隔断至梁、楼板或屋面板底面基层 |

## 防火卷帘（GB 50016-2014 第6.5.3条）

| 防火分隔部位宽度 | 防火卷帘最大宽度 |
|---|---|
| ≤30m | ≤10m |
| >30m | ≤该部位宽度的 1/3，且 ≤20m |
| 中庭部位 | 宽度不受限制 |

- 防火卷帘应具有火灾时**靠自重自动关闭**的功能
- 应具有**防烟性能**，与楼板、梁、墙、柱之间的空隙应采用防火封堵材料封堵
- 耐火极限不低于所处部位隔墙的耐火极限要求

## 防火门分级（GB 12955-2008 / GB 50016-2014 第6.5.1条）

按耐火性能分为三类：

| 分类 | 名称 | 耐火极限 |
|---|---|---|
| A 类 | 隔热防火门（完全隔热） | 甲级 A1.50h、乙级 A1.00h、丙级 A0.50h |
| B 类 | 部分隔热防火门 | 部分隔热（耐火隔热性降低） |
| C 类 | 非隔热防火门 | 只要求耐火完整性，不要求隔热性 |

等级对应口诀。**A0.50 丙、A1.00 乙、A1.50 甲**

## 防火门设置要求（GB 50016-2014 第6.5.1条）

- 经常有人通行处的防火门宜采用**常开**防火门（火灾时自动关闭并有信号反馈）
- 常闭防火门应设明显标志，火灾时能自行关闭并具有信号反馈功能
- 防火门应能在其内外两侧**手动开启**
- **双扇防火门**应具有**按顺序关闭**的功能（顺序闭门器）
- 防火门关闭后应具有防烟性能
- 设置在变形缝附近的防火门应设在楼层数较多的一侧，门开启后不应跨越变形缝

## 防火窗（GB 50016-2014 第6.5.2条）

- 防火窗应采用可开启的防火窗，固定扇采用防火玻璃
- 安装应牢固、严密，关闭严密，耐火性能满足要求
- 火灾时能自动关闭（与火灾自动报警系统联动）

## 防火阀与排烟防火阀

**防火阀（GB 50016-2014 第9.3.11条）**：
- 动作温度 **70℃** 自动关闭（输送气体温度70℃及以上时，动作温度应高于输送气体温度且不低于70℃）
- **厨房排油烟管道**上的防火阀动作温度为 **150℃**
- 防火阀两侧各 **2m** 范围内的风管及其绝热材料应采用不燃材料
- 设置部位口诀"**平管分区变阁楼**"（水平风管与竖向风管交接处、穿越防火分区处、变形缝两侧等）

**排烟防火阀**：
- 安装在排烟系统管道上，动作温度 **280℃** 自动关闭（280℃ 时排烟风机应停止运行）

## 竖井检查门（GB 50016-2014 第6.2.9条）

| 情况 | 检查门等级 |
|---|---|
| 电缆井、管道井等常规井壁检查门 | 丙级防火门 |
| 埋深 >10m 的地下建筑井壁 | 甲级防火门 |
| 超高层建筑井壁 | 甲级防火门 |
| 层间无分隔（上下贯通无层间隔断）的井道 | 乙级防火门 |
| 住宅建筑内的合用前室 | 乙级防火门 |

- 电缆井、管道井应在每层楼板处采用不低于楼板耐火极限的不燃材料封堵
- 井壁上的检查门应采用防火门

## 防火封堵

- 管道穿过防火墙、防火隔墙、楼板处，空隙应采用防火封堵材料填塞密实
- 电缆井、管道井与房间、走道等相连通的孔洞应用防火封堵材料封堵
- 建筑内的变形缝不应设置可燃材料，变形缝处的防火封堵应满足耐火要求

## 电梯层门

- **电梯层门的耐火完整性不应低于 2.00h**
- 电梯井应独立设置，井内严禁敷设可燃气体和甲、乙、丙类液体管道及与电梯无关的电缆、电线
- 消防电梯的电梯井及机房应与相邻电梯井、机房分隔

## 易错点 / 陷阱

- 防火墙上严禁穿可燃气体和甲、乙、丙类液体管道
- 中庭防火卷帘宽度不限，一般部位按 10m / 1/3 且 20m 控制
- 防火门 A 类隔热分三级。甲1.50、乙1.00、丙0.50
- 防火阀 70℃（厨房排油烟 150℃）、排烟防火阀 280℃，不要混淆
- 电梯层门耐火完整性 ≥2.00h 是常考数字

## 考试出题角度

- 实务。上下层开口防火措施数值、防火卷帘宽度、防火门等级
- 综合。防火墙构造检查、防火阀/排烟防火阀设置检查
- 案例。建筑内防火分隔是否满足要求（商业中庭、竖井）
