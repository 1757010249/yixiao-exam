# 火灾基础知识

## 燃烧的本质与条件

- **本质**。可燃物与氧化剂作用发生的放热反应，通常伴有火焰、发光和（或）发烟现象
- **着火三角形**。可燃物 + 助燃物（氧化剂）+ 引火源（温度），三者同时具备才能燃烧
- **着火四面体**。在着火三角形基础上增加**链式反应自由基**（未受抑制的链式反应），用于解释有焰燃烧
- 燃烧必要充分条件。可燃物、助燃物、引火源、链式反应（自由基）四者缺一不可

## 燃烧分类

按燃烧发生瞬间的特点分为着火（点燃/自燃）与爆炸；按燃烧物的形态和燃烧方式分为：

| 类型 | 要点 |
|---|---|
| 扩散燃烧 | 可燃气体从喷口流出与空气边混合边燃烧，混合发生在燃烧过程中（如天然气管道泄漏燃烧），燃烧较稳定 |
| 预混燃烧 | 可燃气体与空气预先混合后再燃烧，混合发生在燃烧之前，可能产生回火、爆炸 |
| 闪燃 | 液体挥发的蒸气与空气混合后遇火源一闪即灭的燃烧现象（一闪即灭，不会持续） |
| 沸溢 | 重质油品（含水油品）受热使水分汽化，油品被冲出容器外（沸溢性外溢） |
| 喷溅 | 重质油品火灾中水垫层受热汽化膨胀，将油品从罐内向罐外喷出，比沸溢更剧烈 |
| 表面燃烧 | 可燃固体表面被点燃后在表面发生的燃烧（如木炭、焦炭，无火焰） |
| 分解燃烧 | 可燃固体受热分解出可燃气体后再燃烧（多数固体如此） |
| 阴燃 | 无火焰的缓慢燃烧，多发生在疏松多孔固体（如锯末、纸张堆垛），是火灾的初期隐蔽阶段 |

## 燃点相关参数

| 参数 | 定义与要点 |
|---|---|
| 闪点 | 规定条件下可燃液体表面挥发的蒸气遇火源能发生闪燃的最低温度。闪点越低火灾危险性越大，是液体火灾危险性分类依据 |
| 燃点（着火点） | 可燃物遇火源能持续燃烧的最低温度。固体火灾危险性主要看燃点 |
| 自燃点 | 可燃物在空气中不需外部火源、依靠自身发热达到的最低引燃温度。与压力、浓度、散热条件等有关 |
| 热分解温度 | 可燃固体开始热分解并产生可燃气体的温度，与固体火灾危险性相关 |
| 氧指数 | 规定条件下，材料在氧氮混合气体中刚好能维持燃烧的最小氧浓度（体积分数）。氧指数越高越难燃 |
| 爆炸温度极限 | 可燃液体蒸气浓度达到爆炸下限/上限对应的液体温度范围，低于下限或高于上限均不爆炸 |

## 燃烧产物与烟气危害

- 燃烧产物。CO₂、CO、H₂O、SO₂、NOₓ 等
- **CO 致死**。CO 与血红蛋白结合能力是氧的 200-300 倍，火灾中导致人员死亡的主要因素
- **烟气减光性**。烟气中固体微粒使可见光衰减，严重影响人员疏散视线
- 烟气危害。缺氧、中毒、高温灼伤、减光（视线受阻）、产生恐慌
- 热释放速率是评价火灾危险性的重要指标

## 火灾分类（GB/T 4968-2008，A-F 类）

| 类别 | 燃烧物质 | 举例 |
|---|---|---|
| A 类 | 固体物质火灾 | 木材、棉、毛、麻、纸张 |
| B 类 | 液体或可熔化固体物质火灾 | 汽油、煤油、原油、甲醇、乙醇、沥青、石蜡 |
| C 类 | 气体火灾 | 煤气、天然气、甲烷、乙烷、氢气、乙炔 |
| D 类 | 金属火灾 | 钾、钠、镁、铝镁合金 |
| E 类 | 带电火灾 | 变压器、电缆等带电设备 |
| F 类 | 烹饪器具内的烹饪物火灾 | 动植物油脂 |

## 火灾等级（特别重大/重大/较大/一般）

口诀"**313-151**"。按死亡人数、重伤人数、受灾户数、直接经济损失四档划分，取高者：

| 等级 | 死亡人数 | 重伤人数 | 受灾户数 | 直接经济损失 |
|---|---|---|---|---|
| 特别重大 | ≥30 人 | ≥100 人 | ≥100 户 | ≥3 亿元 |
| 重大 | 10-30 人 | 50-100 人 | 50-100 户 | 1 亿-3 亿元 |
| 较大 | 3-10 人 | 10-50 人 | 10-50 户 | 3000 万-1 亿元 |
| 一般 | <3 人 | <10 人 | <10 户 | <3000 万元 |

（"以上"含本数，"以下"不含本数；取高者判定。另有无人员伤亡、财产损失<1000元的"轻微火灾"类别。）

记忆。"313-151"。死亡 30·10·3；重伤 100·50·10；经济损失 3 亿·1 亿·3000 万

> 注：火灾等级划分依据《火灾统计管理规定》最新口径（特别重大≥3亿元/重大1亿-3亿/较大3000万-1亿+受灾户数100/50/10户）。原 KB 记录的经济损失旧值（1亿/5000万/1000万）已按新口径校正，依据奇门横向P5、竖向P5及内蒙古自治区政府2026年《火灾事故应急预案》政策解读。

## 火灾常见原因

- 电气（电气线路和设备故障是引起火灾的首要原因）
- 用火不慎、吸烟、玩火、生产作业违章、放火、雷击、自燃等

## 建筑火灾蔓延传热基础

| 传热方式 | 特点 |
|---|---|
| 热传导 | 依靠分子热运动传热（固体为主），如金属构件导热引燃相邻可燃物 |
| 热对流 | 流体（气体、液体）流动传热，是烟气竖向蔓延的主要方式，热烟气流向楼梯间、竖井形成"烟囱效应" |
| 热辐射 | 以电磁波形式传递热量，不依赖介质，是火灾由起火房间向相邻房间、相邻建筑蔓延的主要方式 |

## 室内火灾发展阶段

1. **初期增长阶段**（阴燃→明火），火灾处于增长状态，温度较低
2. **充分发展阶段**（轰燃后），可燃物全面燃烧，温度急剧升高，达到火灾最大破坏阶段
3. **衰减阶段**，可燃物基本烧尽，温度下降

**轰燃**。室内火灾由局部燃烧转变为所有可燃物表面同时燃烧的现象。判定条件。室内热烟气温度约 **600℃**，或地面接收到的热辐射通量约 **20kW/㎡**

**回燃**。室内火灾进入缺氧燃烧阶段后，若门窗突然开启，大量空气涌入与高温可燃气体混合，瞬间发生爆炸式燃烧（爆燃）的现象

## 防火与灭火基本方法

| 方法 | 原理 | 措施 |
|---|---|---|
| 冷却灭火 | 降低温度至燃点以下 | 水灭火 |
| 隔离灭火 | 将可燃物与火源/助燃物隔离 | 关闭阀门、拆除可燃构件、设防火分隔 |
| 窒息灭火 | 隔绝助燃物（降低氧浓度） | 泡沫、CO₂、氮气、沙土覆盖 |
| 化学抑制（中断链式反应） | 中断链式反应自由基 | 干粉、卤代烷灭火剂 |

## 爆炸分类

- **物理爆炸**。物理状态变化引起，前后物质成分不变（如锅炉爆炸、液化气钢瓶受热超压爆炸）
- **化学爆炸**。化学反应引起，物质成分改变，速度极快（如炸药爆炸、可燃气体/粉尘爆炸）
- **核爆炸**。核裂变或核聚变释放巨大能量（原子弹、氢弹）

## 粉尘爆炸

**粉尘爆炸特点**：
- **连续多次爆炸**是粉尘爆炸的最大特点（第一次冲击波扬起沉积粉尘引发二次爆炸）
- 所需点火能量大、爆炸压力上升速度慢但压力高
- 释放的能量大、破坏力强
- 分 **I 型（一般）** 与 **II 型（强烈）** 粉尘爆炸，爆炸火焰温度可达 **2000-3000℃**
- 粉尘爆炸应同时具备。粉尘本身可燃、悬浮在空气中并达到爆炸极限浓度、有足够能量的引火源、受限空间

## 爆炸极限及影响因素

- **爆炸极限**。可燃气体/蒸气/粉尘与空气混合遇火源能发生爆炸的最低浓度（下限）与最高浓度（上限）之间的范围
- 爆炸下限越低、范围越宽，爆炸危险性越大

**4 个影响因素**：
1. **初始温度**。温度升高 → 下限降低、上限升高，爆炸范围变宽，危险性增大
2. **初始压力**。压力增大 → 爆炸极限范围扩大（压力降低范围缩小）
3. **惰性介质（惰性气体/杂质）含量**。惰性气体含量增加 → 范围变窄（氧浓度降低）
4. **点火源能量（引燃能量）**。点火能量增大 → 爆炸范围扩大

## 火源分类

- 明火焰（火柴、打火机、焊接火花）、高温物体、电火花、撞击摩擦火花、化学反应放热、光线照射聚焦、雷电、静电等
- 常见引火源。明火、电火花、高温物体、静电、雷击

## 易燃液体三级分级

按闪点划分（闪点越低危险性越大）：

| 级别 | 火灾危险性 | 典型物质 |
|---|---|---|
| I 级 | 最高 | 乙醚、乙醇、苯、丙酮等低闪点液体 |
| II 级 | 较高 | 煤油、樟脑油、松节油等 |
| III 级 | 中等 | 轻柴油等较高闪点液体 |

口诀"**乙醚醛酮 / 香蕉石锤**"。I 级典型物。乙醚、醛类、酮类；II 级典型物。香蕉水（乙酸酯类混合液）、石蜡油（煤油）类联想记忆

注。讲义未给出具体闪点界限数值，I/II/III 级对应闪点界限以教材原文及 GB 6944 为准

## 易燃固体分级

- 易燃固体按燃点和自燃点划分，燃点越低、自燃点越低，危险性越大
- **一级易燃固体**。燃点低、燃烧迅速猛烈（如赤磷、硝化棉、赛璐珞、二硝基苯等）
- **二级易燃固体**。燃点较高、燃烧较慢（如硫磺、镁粉、铝粉、樟脑、萘等）
- 多数易燃固体受热易分解，遇火源极易燃烧

## 易于自燃物质分类

- 自燃物质。不需外部火源，依靠自身氧化放热（或微生物作用放热）积累达到燃点而自行燃烧的物质
- 分类（按自燃难易）：
  - **一类（最易自燃）**。常温下遇空气即能自燃，如黄磷、三乙基铝（需液封/惰性保护）
  - **二类（较易自燃）**。需一定温度才能自燃，如油布、油纸（缓慢氧化积热自燃）
  - **三类（遇水自燃）**。遇水（受潮）产生可燃气体并放热自燃，如金属钠、钾、氢化钠、电石（遇湿易燃）
- 常见易于自燃物质。黄磷、金属钠钾、电石、油布油纸、赛璐珞（受热分解自燃）、煤堆/棉花堆（长期堆放蓄热自燃）

## 易错点 / 陷阱

- 闪燃与阴燃易混。闪燃是液体蒸气一闪即灭；阴燃是无火焰的缓慢燃烧（固体）
- 沸溢与喷溅易混。沸溢是油品含水汽化外溢；喷溅是水垫层汽化将油品喷出，破坏更剧烈
- 轰燃 vs 回燃。轰燃是全面燃烧的开始（600℃/20kW·㎡）；回燃是缺氧状态下补氧发生的爆燃
- 化学爆炸改变物质成分，物理爆炸成分不变
- 粉尘爆炸最容易考"连续多次爆炸"的特点

## 考试出题角度

- 实务。给定物质判断火灾类别（A-F）、火灾等级判定（313-151）、爆炸极限影响因素
- 综合。燃烧条件、防火灭火方法在检查与案例分析中的运用
