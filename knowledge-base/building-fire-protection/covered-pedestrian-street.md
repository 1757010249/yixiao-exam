# 有顶棚的步行街

有顶棚的步行街（商业步行街）两侧建筑之间设置顶棚，两侧商铺依靠步行街作为疏散通道和排烟通道，防火要求较一般的连廊式商业建筑放宽。依据 GB 50016-2014 第5.3.6条，步行街两侧建筑的耐火等级、防火间距、防火分隔、疏散距离等应满足下列要求：

## 总平面要求

| 项目 | 要求 |
|---|---|
| 两侧建筑耐火等级 | 两侧建筑的耐火等级不应低于 **二级** |
| 相对面最近距离 | 步行街两侧建筑相对面的最近距离不应小于 **9m** |
| 步行街长度 | 步行街的长度不宜大于 **300m**（超过时应采取加强措施） |

## 商铺防火分隔

| 项目 | 要求 |
|---|---|
| 商铺之间隔墙 | 商铺之间采用耐火极限 ≥**2.00h** 的防火隔墙分隔 |
| 每间商铺面积 | 每间商铺的建筑面积不宜大于 **300㎡** |
| 面向步行街围护构件 | 面向步行街一侧的围护构件耐火极限 ≥**1.00h**，并采用**乙级防火门、窗** |
| 相邻商铺开口 | 相邻商铺之间面向步行街一侧设置宽度 ≥**1.0m**、耐火极限 ≥**1.00h** 的实体墙（防止火从相邻开口互串） |
| 玻璃墙 | 采用非隔热防火玻璃墙（耐火完整性满足）时，应设置**闭式自动喷水灭火系统**保护 |

## 步行街顶部与排烟

| 项目 | 要求 |
|---|---|
| 出挑宽度 | 回廊或挑檐（挑出构件）的出挑宽度不应小于 **1.2m** |
| 楼板开口 | 步行街顶棚下各层楼板的开口面积不应小于步行街地面面积的 **37%**（形成向上排烟通道） |
| 顶棚承重结构 | 步行街顶棚承重结构耐火极限 ≥**1.00h** |
| 顶棚高度 | 顶棚下檐距地面高度不应小于 **6.0m**（保证消防车通行及排烟） |
| 自然排烟口 | 步行街顶棚设置的**自然排烟口有效面积**不应小于步行街地面面积的 **25%**，且应能直接向外开启（可开启排烟口） |

## 疏散要求

| 项目 | 要求 |
|---|---|
| 步行距离 | 步行街内任一点至最近**室外安全地点**的直线步行距离不应大于 **60m** |
| 疏散门至楼梯口 | 二层及以上商铺的疏散门至最近疏散楼梯口（安全出口）的距离 ≤**37.5m** |
| 疏散通道 | 步行街可视为安全区域（室内安全疏散通道），商铺通过步行街疏散至室外 |

## 消防设施

| 项目 | 要求 |
|---|---|
| 消火栓 | 步行街两侧建筑商铺**外墙每隔 30m** 设置 DN65 消火栓，并配备**软管卷盘或消防水龙** |
| 商铺内 | 步行街两侧的商铺内应设置**自动喷水灭火系统**和**火灾自动报警系统** |
| 回廊 | 步行街**每层回廊**均应设置自动喷水灭火系统 |
| 排烟 | 步行街顶棚设置自然排烟（有效面积 ≥地面面积 25%），机械排烟按规范执行 |

## 规范依据

- GB 50016-2014 第5.3.6条。有顶棚的步行街两侧建筑及步行街防火要求
  - 第1款。两侧建筑耐火等级、相对面最近距离、步行街长度
  - 第2款。商铺间防火隔墙、每间面积、围护构件与门窗
  - 第3款。玻璃墙闭式自喷
  - 第4款。出挑宽度、楼板开口面积、顶棚承重结构与高度
  - 第5款。自然排烟口面积
  - 第6款。疏散距离（60m / 37.5m）
  - 第7款。消火栓设置
  - 第8款。自喷与报警设置

## 易错点 / 陷阱

- 相对面最近距离 ≥9m、步行街长度 ≤300m
- 商铺每间 ≤300㎡、商铺间隔墙 2.00h
- 面向步行街围护构件 ≥1.00h + 乙级门窗；相邻商铺间设 ≥1.0m 宽、≥1.00h 实体墙
- 楼板开口 ≥地面面积 37%、自然排烟口 ≥地面面积 25%（37% 与 25% 区分）
- 任一点至室外安全地点 ≤60m；二层以上商铺疏散门至楼梯口 ≤37.5m
- 顶棚下檐距地 ≥6.0m、出挑宽度 ≥1.2m
- 商铺外墙每隔 30m 设 DN65 消火栓 + 软管卷盘
- 步行街作为安全区域（疏散通道），与一般建筑"每个防火分区独立疏散"不同

## 考试出题角度

- 实务。步行街防火参数（9m/300m/300㎡/37%/25%/60m/37.5m）
- 综合。步行街防火分隔、排烟设施、疏散距离检查
- 案例。商业步行街建筑防火设计是否满足 GB 50016 第5.3.6条
