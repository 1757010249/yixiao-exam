# 消防安全责任制

## 消防工作方针与原则

- **方针**。预防为主、防消结合
- **原则**。政府统一领导、部门依法监管、单位全面负责、公民积极参与（口诀：公布账单）

## 单位消防安全职责（消防法第16条，7+1项）

| 序号 | 职责 |
|---|---|
| 1 | 落实消防安全责任制，制定制度、规程、预案 |
| 2 | 按国标/行标配置消防设施器材，设置标志，定期检验维修 |
| 3 | 每年至少1次全面检测建筑消防设施，记录完整存档备查 |
| 4 | 保障疏散通道、安全出口、消防车通道畅通；防火防烟分区、防火间距符合标准 |
| 5 | 组织防火检查，消除火灾隐患 |
| 6 | 组织针对性消防演练 |
| 7 | 法律法规规定的其他职责 |
| +1 | **单位主要负责人是本单位消防安全责任人** |

## 消防安全责任人 vs 消防安全管理人（易混点）

| 对比 | 消防安全责任人（法定第一责任人，通常为法人） | 消防安全管理人（执行管理负责人） |
|---|---|---|
| 定位 | 对单位消防工作负总责 | 对消防安全责任人负责 |
| 主要职责 | 确定逐级责任、批准制度规程、组织防火检查、处理重大问题 | 组织实施消防安全管理工作 |
| 特别 | 未确定管理人的单位，管理工作由责任人负责 | 定期向责任人报告情况，及时报告重大问题 |

**口诀**。责任人定责任批制度，管理人组织实施

## 消防安全重点单位（消防法第17条）

重点单位除履行第16条职责外，额外4项（口诀：重建查岗）
1. 确定消防安全管理人，组织实施消防安全管理工作（重）
2. 建立消防档案，确定重点部位，设置防火标志，严格管理（建）
3. 实行每日防火巡查，建立巡查记录（查）
4. 对职工进行岗前消防安全培训，定期组织培训和演练（岗）

### 重点单位界定（口诀分类）

| 类别 | 举例（口诀） |
|---|---|
| 会展类 | 体育场馆、会堂、公共展览馆、博物馆展示厅（体会展） |
| 交通类 | 民用机场航站楼、客运车站候车室、客运码头候船厅（车马船） |
| 商贸类 | 宾馆、饭店、商场、市场（吃住买） |
| 公共类 | 影剧院、图书馆阅览室、医院门诊楼、大学教学楼等 |
| 儿童/养老 | 托儿所、儿童游乐厅、养老院、中小学教学楼、集体宿舍 |
| 娱乐类 | 歌舞厅、录像厅、放映厅、卡拉OK、夜总会、游艺厅、网吧、酒吧 |

## 多单位共用建筑

- 同一建筑由两个以上单位管理/使用 → 明确各方责任，确定责任人统一管理
- 共用疏散通道、安全出口、消防设施、消防车通道
- 物业服务企业 → 维护管理区域内共用消防设施，提供消防安全防范服务

## 禁止行为

- 不得损坏、挪用、擅自拆除/停用消防设施器材
- 不得埋压、圈占、遮挡消火栓或占用防火间距
- 不得占用、堵塞、封闭疏散通道、安全出口、消防车通道
- 人员密集场所门窗不得设置影响逃生和灭火救援的障碍物

## 火灾报警与扑救

- 任何人发现火灾 → 立即报警；任何单位个人无偿为报警提供便利；**严禁谎报火警**
- 人员密集场所 → 现场工作人员立即组织引导疏散
- 任何单位 → 立即组织力量扑救；邻近单位给予支援
- 任何单位和**成年人** → 参加有组织的灭火工作（个人无此义务，成年人才有）

## 规范依据

- 消防法第16条。单位消防安全职责
- 消防法第17条。消防安全重点单位
- 机关、团体、企业、事业单位消防安全管理规定

## 考试出题角度

- 责任人与管理人的职责区分
- 重点单位额外4项职责
- 禁止行为判断
- 火灾报警义务主体（成年人）
