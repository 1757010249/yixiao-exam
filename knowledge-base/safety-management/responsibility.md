# 消防安全责任制

## 消防工作方针与原则

- **方针**。预防为主、防消结合
- **原则**。政府统一领导、部门依法监管、单位全面负责、公民积极参与（口诀：公布账单）

## 单位消防安全职责（消防法第16条，7+1项）

| 序号 | 职责 |
|---|---|
| 1 | 落实消防安全责任制，制定制度、规程、预案 |
| 2 | 按国标/行标配置消防设施器材，设置标志，定期检验维修 |
| 3 | 每年至少1次全面检测建筑消防设施，记录完整存档备查 |
| 4 | 保障疏散通道、安全出口、消防车通道畅通；防火防烟分区、防火间距符合标准 |
| 5 | 组织防火检查，消除火灾隐患 |
| 6 | 组织针对性消防演练 |
| 7 | 法律法规规定的其他职责 |
| +1 | **单位主要负责人是本单位消防安全责任人** |

## 消防安全责任人 vs 消防安全管理人（易混点）

| 对比 | 消防安全责任人（法定第一责任人，通常为法人） | 消防安全管理人（执行管理负责人） |
|---|---|---|
| 定位 | 对单位消防工作负总责 | 对消防安全责任人负责 |
| 主要职责 | 确定逐级责任、批准制度规程、组织防火检查、处理重大问题 | 组织实施消防安全管理工作 |
| 特别 | 未确定管理人的单位，管理工作由责任人负责 | 定期向责任人报告情况，及时报告重大问题 |

**口诀**。责任人定责任批制度，管理人组织实施

### 消防安全责任人7项职责 / 消防安全管理人8项职责（61号令，讲义234-235页）

| 消防安全责任人（7项） | 消防安全管理人（8项） |
|---|---|
| ① 贯彻执行消防法规，保障单位消防安全符合规定，掌握本单位消防安全情况 | ① 拟订年度消防工作计划，组织实施日常消防安全管理 |
| ② 统筹安排生产、经营、管理等活动中的消防安全管理工作 | ② 组织制订消防安全制度和保障消防安全的操作规程并检查督促落实 |
| ③ 批准实施消防安全制度，为本单位消防安全提供必要的经费和组织保障 | ③ 拟订消防安全工作的资金投入和组织保障方案 |
| ④ 确定逐级消防安全责任，批准实施消防安全制度和保障消防安全的操作规程 | ④ 组织实施防火检查和火灾隐患整改工作 |
| ⑤ 组织防火检查，督促落实火灾隐患整改，及时处理涉及消防安全的重大问题 | ⑤ 组织实施对本单位消防设施、灭火器材和消防安全标志的维护保养，确保完好有效 |
| ⑥ 根据消防法规的规定建立专职消防队、义务消防队 | ⑥ 管理专职消防队、义务消防队，组织消防训练 |
| ⑦ 组织制定符合本单位实际的灭火和应急疏散预案，并实施演练 | ⑦ 组织开展员工消防知识、技能的宣传教育和培训，组织灭火和应急疏散预案的实施和演练 |
| — | ⑧ 单位消防安全责任人委托的其他消防安全管理工作 |

**注意**。未确定消防安全管理人的单位，消防安全管理工作由消防安全责任人负责实施（与前面"未确定管理人的单位，管理工作由责任人负责"一致）。

## 消防安全重点单位（消防法第17条）

重点单位除履行第16条职责外，额外4项（口诀：重建查岗）
1. 确定消防安全管理人，组织实施消防安全管理工作（重）
2. 建立消防档案，确定重点部位，设置防火标志，严格管理（建）
3. 实行每日防火巡查，建立巡查记录（查）
4. 对职工进行岗前消防安全培训，定期组织培训和演练（岗）

### 重点单位界定（口诀分类 + 面积界限）

| 类别 | 举例（口诀） | 面积界限 |
|---|---|---|
| 会展类 | 体育场馆、会堂、公共展览馆、博物馆展示厅（体会展） | 体育场馆/会堂/博物馆展示厅 > **2万㎡** |
| 交通类 | 民用机场航站楼、客运车站候车室、客运码头候船厅（车马船） | > **1.5万㎡** |
| 商贸类 | 宾馆、饭店、商场、市场（吃住买） | > **1万㎡** |
| 公共类 | 影剧院、图书馆阅览室、医院门诊楼、大学教学楼等 | > **2500㎡** |
| 儿童/养老 | 托儿所、儿童游乐厅、养老院、中小学教学楼、集体宿舍 | 托幼/养老院/病房楼/中小学教学楼 > **1000㎡** |
| 娱乐类 | 歌舞厅、录像厅、放映厅、卡拉OK、夜总会、游艺厅、网吧、酒吧 | 歌舞厅/录像厅/桑拿浴室/网吧/酒吧 > **500㎡** |

**不限面积情形**。一类高层住宅、城市轨道交通/隧道工程、单体建筑面积 > 4万㎡ 或高度 > 50m 的公共建筑

### 消防安全重点单位界定标准（61号令版，11类，讲义248页）

| 序号 | 类别 |
|---|---|
| 1 | 商场（市场）、宾馆（饭店）、体育场（馆）、会堂、公共娱乐场所等公众聚集场所 |
| 2 | 医院、养老院、寄宿制学校、托儿所、幼儿园 |
| 3 | 国家机关 |
| 4 | 广播电台、电视台、邮政、通信枢纽 |
| 5 | 客运车站、码头、民用机场 |
| 6 | 公共图书馆、展览馆、博物馆、档案馆、具有火灾危险性的文物保护单位 |
| 7 | 发电厂（站）、电网经营企业 |
| 8 | 易燃易爆化学物品的生产、充装、储存、供应、销售单位 |
| 9 | 服装、制鞋等劳动密集型生产、加工企业 |
| 10 | 重要的科研单位 |
| 11 | 高层公共建筑、地下铁道、地下观光隧道等地下公共建筑、粮棉木材等可燃物资大型仓库堆场、重点工程的施工现场等（参照标准界定） |

**易混淆提示**。本表（61号令版重点单位界定）与**住建部令第51号第14条**特殊建设工程的界定是**两套独立体系**，勿混淆。上面的面积界限属于住建部令第51号第14条特殊建设工程（讲义221-222、230-231页），**并非《消防法》第14条**（消防法第14条仅规定具体办法由国务院住建部门规定，不列面积界限）。

## 公众聚集场所告知承诺管理（讲义222-223页）

- 投入使用、营业前，向县级以上地方人民政府消防救援机构申请消防安全检查
- **告知承诺方式**。材料齐全的当场/受理之日起**1个工作日内**作出许可决定；消防救援机构对取得许可的单位在**20日内**进行核查
- **不采用告知承诺方式**。自受理之日起**10个工作日内**现场检查，检查合格后作出许可决定
- 未经消防安全检查或检查不合格的，不得投入使用、营业
- 经核查发现与承诺内容不符、责令限期改正逾期不改正的 → 依法撤销许可

## 多单位共用建筑

- 同一建筑由两个以上单位管理/使用 → 明确各方责任，确定责任人统一管理
- 共用疏散通道、安全出口、消防设施、消防车通道
- 物业服务企业 → 维护管理区域内共用消防设施，提供消防安全防范服务

### 多单位共用建筑5条职责（讲义249页）

| 序号 | 职责 |
|---|---|
| 1 | 建设（产权）单位向使用单位提供符合消防安全的验收合格证明文件 |
| 2 | 在租赁、委托合同中明确各方消防安全责任，以及专有部分、共用部分的管理责任 |
| 3 | 确定责任人，对共用疏散通道、安全出口、建筑消防设施、消防车通道统一管理 |
| 4 | 物业服务单位对共用消防设施维护管理，及时劝阻、制止违规行为 |
| 5 | 局部施工需要使用明火时，施工区域与非施工区域采取防火分隔措施，并指定专人监护 |

## 火灾高危单位额外6条职责（讲义248页）

| 序号 | 职责 |
|---|---|
| 1 | 定期召开消防安全工作例会 |
| 2 | 鼓励消防安全管理人取得注册消防工程师资格；消防安全责任人及消防安全特有工种人员经专门培训 |
| 3 | 建立专职消防队或微型消防站，配备相应消防装备 |
| 4 | 按照国家标准配置应急逃生设施 |
| 5 | 建立消防安全评估制度，评估结果向社会公开 |
| 6 | 参加火灾公众责任保险 |

## 员工"四懂四会"（讲义249页）

- **四懂**。懂火灾危险性、懂预防措施、懂扑救方法、懂逃生方法
- **四会**。会报火警、会用灭火器材、会扑救初起火灾、会组织疏散逃生
- 口诀。**葡萄遇险、拥抱葡萄**

> 注。口诀"葡萄遇险、拥抱葡萄"为助记，逐字对应以讲义原文为准。

## 13项消防安全制度（讲义249页）

**口诀**。巡检淫财控电演兑换燃爆评

单位应建立健全的消防安全制度共13项，涵盖防火巡查检查、用火用电管理、火灾隐患整改、消防控制室值班、消防设施器材维护管理、灭火和应急疏散预案演练、消防安全培训教育、消防档案管理、消防工作考评奖惩等。记忆口诀"巡检淫财控电演兑换燃爆评"（逐项精确对应以讲义原文为准）。

## 禁止行为

- 不得损坏、挪用、擅自拆除/停用消防设施器材
- 不得埋压、圈占、遮挡消火栓或占用防火间距
- 不得占用、堵塞、封闭疏散通道、安全出口、消防车通道
- 人员密集场所门窗不得设置影响逃生和灭火救援的障碍物

## 火灾报警与扑救

- 任何人发现火灾 → 立即报警；任何单位个人无偿为报警提供便利；**严禁谎报火警**
- 人员密集场所 → 现场工作人员立即组织引导疏散
- 任何单位 → 立即组织力量扑救；邻近单位给予支援
- 任何单位和**成年人** → 参加有组织的灭火工作（个人无此义务，成年人才有）

## 规范依据

- 消防法第16条。单位消防安全职责
- 消防法第17条。消防安全重点单位
- 机关、团体、企业、事业单位消防安全管理规定

## 考试出题角度

- 责任人与管理人的职责区分
- 重点单位额外4项职责
- 禁止行为判断
- 火灾报警义务主体（成年人）
