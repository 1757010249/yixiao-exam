# 检查与维护

## 防火检查频次（核心记忆）

| 单位/场所 | 防火检查频次 |
|---|---|
| 机关、团体、事业单位 | 至少每季度1次 |
| 其他单位 | 至少每月1次 |
| 养老机构 | 每月至少1次全面检查；重要节假日和重大活动前必须检查 |

## 防火巡查频次（核心记忆）

| 单位/场所 | 防火巡查频次 |
|---|---|
| 公众聚集场所（营业期间） | 至少每2小时1次 |
| 公众聚集场所（营业结束） | 应对营业现场进行检查，消除遗留火种 |
| 医院、寄宿制学校、托儿所、幼儿园 | 应加强**夜间防火巡查** |
| 消防安全重点单位 | 每日巡查1次 |
| 养老机构重点部位（老年人居室等） | 白天每日至少2次 |
| 养老机构夜间 | 全区域每2小时至少1次，24小时不间断 |

**口诀记忆**。公众场所两小时，重点单位每日巡，医院学校重夜间

## 隐患整改

- 单位对存在的火灾隐患，应当及时予以消除
- 重大火灾隐患。由单位确定为本单位重大火灾隐患，立即整改
- 隐患整改决策。组织防火检查，督促落实隐患整改，及时处理重大问题

## 消防档案管理（易错点）

| 档案 | 保存年限 |
|---|---|
| 原始技术资料（施工/验收/检测） | **长期保存** |
| 消防控制室值班记录表 | 不少于1年 |
| 建筑消防设施巡查记录表 | 不少于1年 |
| 建筑消防设施检测记录表 | 不少于5年 |
| 故障维修记录表 | 不少于5年 |
| 维护保养计划表/记录表 | 不少于5年 |

**口诀**。原始长期存，值班巡查1年，检测维保5年

## 维护管理口诀（5号书讲义）

| 口诀 | 对应内容 |
|---|---|
| **编制两日点人名** | 灭火器维修合格证内容（维修编号、总质量、生产日期、维修日期、维修机构名称/地址等） |
| **强冲严** | 管网安装完毕后试验顺序。强度试验→冲洗→严密性试验 |
| **童工采柱莽** | 消防给水检测内容。水源供水能力、水泵接合器通水加压、储水设备结构、水泵流量性能、系统联动测试 |

## 消防控制室管理

### 值班制度
- 实行每日24h专人值班，**每班不少于2人**
- 值班人员持有消防专业技能鉴定证书

### 应急处置程序
1. 接到火灾警报 → 立即以最快方式确认火灾
2. 火灾确认后 → 确认火灾报警联动控制开关处于自动状态，同时拨打119准确报警（说明着火单位地点、起火部位、着火物种类、火势大小、报警人姓名联系电话）
3. 立即启动应急疏散和初起火灾扑救预案，同时报告单位消防安全负责人

### 消防控制室资料（应保存）
- 总平面布局图、消防设施平面布置图、系统图、安全出口布置图、重点部位位置图
- 消防安全管理规章制度、应急灭火预案、应急疏散预案
- 消防安全组织结构图（责任人、管理人、专职/义务消防人员）
- 培训记录、演练记录
- 值班、检查、巡查情况记录

### 图形显示装置
- 采用中文标注和中文界面；界面对角线≥430mm
- 10s内显示火灾报警信号和反馈信号；100s内显示其他输入信号

## 培训与演练

| 对象 | 频次 |
|---|---|
| 消防安全重点单位员工 | 至少每年1次培训 |
| 人员密集场所员工 | 至少每半年1次培训 |
| 新上岗/进新岗位员工 | 上岗前培训 |
| 消防安全重点单位演练 | 至少每半年1次 |
| 其他单位演练 | 至少每年1次 |

## 规范依据

- 机关、团体、企业、事业单位消防安全管理规定 第26条。防火检查
- 机关、团体、企业、事业单位消防安全管理规定 第28条。防火巡查
- GB 25201。消防控制室通用技术要求

## 考试出题角度

- 防火检查/巡查频次对比（机关季度 vs 其他单位每月）
- 档案保存年限（1年 vs 5年 vs 长期）
- 消防控制室值班制度（2人、24h）
- 应急处置程序顺序
