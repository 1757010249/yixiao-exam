# 检查与维护

## 防火检查频次（核心记忆）

| 单位/场所 | 防火检查频次 |
|---|---|
| 机关、团体、事业单位 | 至少每季度1次 |
| 其他单位 | 至少每月1次 |
| 养老机构 | 每月至少1次全面检查；重要节假日和重大活动前必须检查 |

## 防火巡查频次（核心记忆）

| 单位/场所 | 防火巡查频次 |
|---|---|
| 公众聚集场所（营业期间） | 至少每2小时1次 |
| 公众聚集场所（营业结束） | 应对营业现场进行检查，消除遗留火种 |
| 医院、寄宿制学校、托儿所、幼儿园 | 应加强**夜间防火巡查** |
| 消防安全重点单位 | 每日巡查1次 |
| 养老机构重点部位（老年人居室等） | 白天每日至少2次 |
| 养老机构夜间 | 全区域每2小时至少1次，24小时不间断 |

**口诀记忆**。公众场所两小时，重点单位每日巡，医院学校重夜间

## 防火巡查6项 vs 防火检查12项内容（讲义250-251页）

### 防火巡查（6项，日常动态、即时性排查，无强制书面记录）

| 序号 | 内容 |
|---|---|
| 1 | 用火、用电有无违章情况 |
| 2 | 安全出口、疏散通道是否畅通，安全疏散指示标志、应急照明是否完好 |
| 3 | 消防设施、器材和消防安全标志是否在位、完整 |
| 4 | 常闭式防火门是否处于关闭状态，防火卷帘下是否堆放物品影响使用 |
| 5 | 消防安全重点部位的人员在岗情况 |
| 6 | 其他消防安全情况 |

### 防火检查（12项，定期全面、系统性检查，须填写检查记录并签名）

| 序号 | 内容 |
|---|---|
| 1 | 火灾隐患的整改情况以及防范措施的落实情况 |
| 2 | 安全疏散通道、疏散指示标志、应急照明和安全出口情况 |
| 3 | 消防车通道、消防水源情况 |
| 4 | 灭火器材配置及有效情况 |
| 5 | 用火、用电有无违章情况 |
| 6 | 重点工种人员以及其他员工消防知识的掌握情况 |
| 7 | 消防安全重点部位的管理情况 |
| 8 | 易燃易爆危险物品和场所防火防爆措施落实情况 |
| 9 | 消防（控制室）值班情况和设施运行、记录情况 |
| 10 | 防火巡查情况 |
| 11 | 消防标志的设置和完好、有效情况 |
| 12 | 其他需要检查的内容 |

**区别**。巡查是日常动态即时性排查（无强制书面记录）；检查是定期全面系统性检查（**必须填写记录并签名**）。

## 当场改正的8类违反消防规定行为（讲义251页）

| 序号 | 行为 |
|---|---|
| 1 | 违章进入生产、储存易燃易爆危险物品场所的 |
| 2 | 违章使用明火作业、在具有火灾爆炸危险场所吸烟的 |
| 3 | 安全出口、疏散通道上锁、遮挡、占用，影响疏散的 |
| 4 | 消火栓、灭火器材被遮挡、影响使用或挪作他用的 |
| 5 | 常闭式防火门处于开启状态，防火卷帘下堆放物品影响使用的 |
| 6 | 消防设施管理、值班人员和防火巡查人员脱岗的 |
| 7 | 违章关闭消防设施、切断消防电源的 |
| 8 | 其他可以当场改正的行为 |

发现上述行为，单位应当立即改正，并做好记录；不能当场改正的，进入火灾隐患整改流程。

## 隐患整改

- 单位对存在的火灾隐患，应当及时予以消除
- 重大火灾隐患。由单位确定为本单位重大火灾隐患，立即整改
- 隐患整改决策。组织防火检查，督促落实隐患整改，及时处理重大问题

## 重大火灾隐患直接判定口诀（用户自创）

> **【直接判定】的哥冷库报金莲，老少不宜多羞耻。**
> **补七项。宿爆耐 / 避独 / 分救**

**故事联想**。的哥开出租车去冷库送货，报告对讲机说自己看见了金莲，这事儿老少不宜，传出去多羞耻。

**第一句"的哥冷库报金莲"**（通用建筑/场所类）

| 字 | 对应直接判定项 |
|---|---|
| 的 | 地下（甲乙类地下、地下装修、地下出口不足） |
| 哥 | 分隔（疏散楼梯未分隔、冷库分隔） |
| 冷库 | 冷库防火分隔、保温材料不符 |
| 报 | 未设/失效自动报警、固定灭火系统 |
| 金 | 金属夹芯板芯材＜A级 |
| 莲 | 卷帘（疏散设施设栅栏、卷帘门） |

**第二句"老少不宜多羞耻"**（其他场所类）

| 字 | 对应直接判定项 |
|---|---|
| 老 | 老年人场所 + 劳动密集型企业 |
| 少 | 儿童场所（老少=儿童老人楼层位置不符） |
| 不 | 安全出口不足/封堵 + 病房楼、宾馆 |
| 宜 | 易燃易爆危险品场所 |
| 多 | 多产权/多业态管理责任不明 |
| 羞 | 装修（违规装修、地下装修不符） |
| 耻 | 电池（电池储能电站） |

**补全七项**（按场所分组，原口诀遗漏项）

| 场所类 | 补的字 | 对应直接判定项 |
|---|---|---|
| 劳动密集型 | 宿爆耐 | 厂房宿舍、防爆泄压、耐火等级 |
| 儿童老人医院 | 避独 | 避难间不符、未设独立疏散 |
| 通用建筑 | 分救 | 防火分区超标、救援口障碍 |

**适用范围**。本口诀仅覆盖重大火灾隐患**直接判定**情形，不含综合判定。

依据。GB 35181《重大火灾隐患判定方法》

## 重大火灾隐患综合判定6类（讲义266-267页）

| 类别 | 具体情形 |
|---|---|
| 总平面布置 | 消防车道/消防车登高操作场地被占用或不足、防火间距不足、消防控制室位置不符合要求 |
| 耐火等级、防火分隔与装修 | 耐火等级不匹配、防火分区面积超标、架空层电动车未有效分隔、防火门/防火卷帘损坏、幕墙与楼板间竖向缝隙未封堵、装修材料燃烧性能不符合GB 50222 |
| 安全疏散 | 楼梯间形式不符合要求、安全出口数量不足、疏散门损坏、楼梯间装修材料不符、未设应急照明/疏散指示标志、备用电源供电时间不符合GB 55037 |
| 消防设施 | 消防水源、消火栓、自动灭火系统、防排烟系统、火灾自动报警系统、消防电梯未设置或不能正常使用 |
| 电气 | 用电负荷等级不符、未设专用回路、未设自动切换装置、电气线路可燃材料敷设、线路烧蚀炭化、设备端子烧蚀 |
| 消防安全管理 | 消防控制室值班人员未持证、消防水泵控制柜处于手动状态、常开防火门/常开阀门关闭、外窗阳台设障碍物、消防救援口设障碍物、动火作业未审批、灭火和应急疏散预案未编制 |

### 不应判定为重大火灾隐患的3种情形（讲义265页）

1. 标准修订引起的
2. 已停产停业、无现实火灾危险的
3. 能够当场整改完毕的

### 劳动密集型企业定义（讲义265页）

- 生产加工车间的火灾危险性为**丙类**
- 同一时间生产作业**人数>50人**
- 人均**建筑面积<20㎡**

## 消防控制室管理

### 值班制度
- 实行每日24h专人值班，**每班不少于2人**
- 值班人员持有消防专业技能鉴定证书

### 应急处置程序
1. 接到火灾警报 → 立即以最快方式确认火灾
2. 火灾确认后 → 确认火灾报警联动控制开关处于自动状态，同时拨打119准确报警（说明着火单位地点、起火部位、着火物种类、火势大小、报警人姓名联系电话）
3. 立即启动应急疏散和初起火灾扑救预案，同时报告单位消防安全负责人

### 消防控制室资料（应保存）
- 总平面布局图、消防设施平面布置图、系统图、安全出口布置图、重点部位位置图
- 消防安全管理规章制度、应急灭火预案、应急疏散预案
- 消防安全组织结构图（责任人、管理人、专职/义务消防人员）
- 培训记录、演练记录
- 值班、检查、巡查情况记录

### 图形显示装置
- 采用中文标注和中文界面；界面对角线≥430mm
- 10s内显示火灾报警信号和反馈信号；100s内显示其他输入信号

## 应急预案编制与演练（讲义271-281页）

### 预案内容（5项）
1. 单位的基本情况、消防安全重点部位
2. 应急组织机构及其职责
3. 灭火和应急疏散程序（报警、接警处置、灭火、疏散）
4. 扑救初起火灾的程序和措施
5. 通讯联络、安全防护救护的程序和措施

### 预案分级（按伤亡程度分五级）

| 级别 | 伤亡程度 |
|---|---|
| 一级 | 无人员伤亡 |
| 二级 | 3人以下（含3人） |
| 三级 | 3-10人 |
| 四级 | 10-30人 |
| 五级 | 30人以上 |

### 预案分类与编制程序
- 分类。总预案、分预案、专项预案
- 编制程序5步。调查分析评估 → 确定演练目标 → 制定演练方案 → 演练实施与记录 → 总结讲评改进

### 组织机构（7组）
指挥机构、灭火行动组、疏散引导组、通信联络组、安全保卫组、防护救护组、后勤保障组

### 应急响应（分级到场）
- 一级预案。值班带班负责人到场指挥
- 二级预案。消防安全管理人到场
- 三级以上预案。消防安全责任人到场

### 演练频率
- 消防安全重点单位。每**半年**至少1次
- 火灾高危单位。每**季度**至少1次
- 其他单位。每**年**至少1次
- 火灾高发季节。进行全要素综合演练
- 每月进行疏散演练（重点单位）

### 演练分类与总结讲评
- 分类。桌面演练、模拟演练、实战演练（按形式）
- 演练结束须进行总结讲评，形成书面记录

## 灭火第一、第二战斗力量（讲义258页）

- **第一战斗力量**。员工发现火灾立即呼救，起火部位现场员工在**1min内**形成（就近使用灭火器、消火栓扑救初起火灾）
- **第二战斗力量**。火灾确认后，单位在**3min内**形成（由通信联络组、灭火行动组、疏散引导组、安全救护组、现场警戒组组成）

**口诀**。1分钟第一力量，3分钟第二力量

## 消防安全重点部位定义与管理方法（讲义259页）

### 重点部位（5类）
1. 容易发生火灾的部位
2. 一旦发生火灾对消防安全有重大影响的部位
3. 性质重要、发生事故影响全局的部位
4. 财产集中的部位
5. 人员集中的部位

### 管理方法（6种）
制度管理、标识化管理、教育管理、档案管理、日常管理、应急管理

## 消防档案内容（讲义260-261页）

### 基本情况（9项）
单位概况、消防审核/验收法律文书、消防组织情况、消防安全制度、消防设施器材情况、专职/义务消防队、重点工种人员情况、新产品/新技术合格证明、灭火和应急疏散预案

### 管理情况

## 火灾隐患整改流程（讲义252页）

1. 无法当场改正的火灾隐患 → 消防归口管理部门**上报**单位消防安全管理人/责任人，并提交**整改方案**
2. 消防安全责任人/管理人明确**整改措施、期限、责任主体**，落实整改资金
3. 整改期间落实防范措施，确保消防安全；对不能确保消防安全的高危部位**停产停业**
4. 整改完成后，及时组织验收，记录整改情况并**存档**
5. 自身无力解决的重大火灾隐患 → 向**主管部门或政府**报告
6. 消防机构责令限期改正的火灾隐患，在期限内整改完毕

## 各系统冲洗试压强度总结（竖向P155-159）

### 试验顺序

| 系统 | 试验顺序 |
|---|---|
| 消火栓 | 强度 → 冲洗 → 严密性 |
| 自动喷水 | 强度 → 冲洗 → 严密性 |
| 水喷雾/泡沫 | 强度 → 冲洗 → 防腐 |
| 细水雾 | 冲洗 → 强度 → 吹扫 |

### 强度试验压力

| 管材 | 压力条件 | 试验压力 |
|---|---|---|
| 钢管 | P≤1.0MPa | 1.5P，且不小于1.4MPa |
| 钢管 | P>1.0MPa | P+0.4 |
| 球墨铸铁管 | P≤0.5MPa | 2P |
| 球墨铸铁管 | P>0.5MPa | P+0.5 |
| 钢丝网骨架塑料复合管 | — | 1.5P，且不小于0.8MPa |
| 自动喷水 | P≤1.0 | 1.5P 且不小于1.4MPa；P>1.0 → P+0.4 |
| 水喷雾/泡沫、细水雾 | — | 1.5P |

- 试压用压力表不应少于2只；精度不应低于1.5级，量程应为试验压力值的1.5~2倍

### 合格标准

| 系统 | 合格标准 |
|---|---|
| 消火栓/自动喷水 | 稳压30min，管网无泄漏、无变形，压力降≤0.05MPa |
| 水喷雾/泡沫 | 试验压力后稳压10min无损坏变形，降至设计压力稳压30min，压力不降、无渗漏 |
| 细水雾 | 试验压力后稳压5min无损坏变形，降至设计压力稳压120min，压力不降、无渗漏、无变形 |
| 严密性 | 水压稳压24h无泄漏；气压严密性试验 0.28MPa，稳压24h压力降≤0.01MPa |

### 冲洗与吹扫

- 冲洗。排水管截面面积≥被冲洗管道截面面积60%；流速≥1.5m/s，排出水色和透明度与入口水目测一致为合格
- 吹扫。压力≤设计压力，流速≥20m/s，5min内靶板上无锈渣/灰尘/水渍及其他杂物为合格
