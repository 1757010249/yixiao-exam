# 管理周期汇总（横向对比）

## 一、大型商业综合体周期（竖向P175）

| 周期 | 内容 |
|---|---|
| 维保 | 5 日出报告 |
| 每月 | 柴油启动；月单项检查；管道清洗（季度）；综合研判（季度） |
| 半年 | 联动检查；培训；演练 |
| 每年 | 全面检测；>10万㎡每年联合演练 |
| 每周/每月/季度/年 | 每周1天训练、每月1次演练、季度6天、联合演练1次、每年轮训10天 |

## 二、高层建筑周期

| 建筑类型 | 检查周期 |
|---|---|
| 公共（高层） | 半月检查 |
| 住宅（高层） | 月检查 |
| 超高层 | 半年演练 |
| 非超高 | 年演练 |
| 公共（高层） | 半年培训 |
| 住宅（高层） | 每年培训 |

## 三、培训演练周期

| 单位类型 | 培训/演练 |
|---|---|
| 消防安全重点单位 | 年培训 / 半年演练 |
| 公共聚集场所 | 半年培训 |
| 机关团体 | 季度检查 |
| 其他单位 | 月检查 |
| 高危单位 | 季度演练 |
| 其他单位 | 年演练 |
| 内部预案 | 月演练 |
| 宾馆、商场、公共娱乐 | 半年演练 |
| 其他人密场所 | 每年演练 |

## 四、其他管理周期

| 事项 | 周期 |
|---|---|
| 三项备案 | 5 日 |
| 事故异议 | 15 日内 |
| 消防技术档案 | 6 年 |
| 重点单位 | 日巡查 |
| 公共聚集消防检查 | 10 个工作日 |
| 人密场所 | 月例会 |
| 公共聚集 | 营业 2H 巡查一次 |
| 大型群众活动 | 20 日许可，7 日内检查 |
| 公共聚集场所告知承诺 | 1 个工作日发许可，20 日内检查 |
| 养老院 | 夜间 2H 巡查一次 |

## 考试出题角度

- 大型商业综合体 vs 高层 vs 培训演练的周期对比
- 维保报告期限（5日出报告）
- 各项备案/许可时限（5日/15日/6年/20日/1个工作日）
