# 灭火器

## 灭火器铭牌标识（11项，口诀：三生三C明星泪，终极驱使文雅三说明）

1. 灭火器的名称、型号和灭火剂类型
2. 灭火种类和灭火级别
3. 使用温度范围
4. 驱动气体名称和数量
5. 水压试验压力（永久性标示）
6. 生产许可证编号或认证标记
7. 生产连续序号（钢印永久性方法，在不受内压的底圈上标识）
8. 生产日期
9. 制造厂名称
10. 使用方法（图形说明，铭牌明显位置，筒身上不超过120°弧度）
11. 再充装说明和日常维护说明

## 配置基本要求

- 灭火器摆放应稳固，铭牌朝外
- 手提式灭火器宜设置在灭火器箱内或挂钩、托架上，顶部离地高度≤1.50m，底部离地≥0.08m

## 灭火器分类（3号书讲义 P322-324）

- 按移动方式。手提<20kg/推车≥20kg
- 按压力形式。贮气瓶式/贮压式/化学反应式
- 按灭火剂。水基/干粉/CO₂/洁净气体

## 灭火器型号解读（P321）

- MEZABC2 / MFZ2 / MFTZ50 / MT5 / MS / Q9 / MS / T9 / MP3 / MPAR3 / MJ / B6 等

## 适用火灾类型选择（P326）

| 火灾类型 | 适用灭火器 |
|---|---|
| A类 | 水基水雾/ABC干粉 |
| B类 | 抗溶性（极性溶剂） |
| C类 | - |
| D类 | 7150/干砂/铁屑/土 |
| E类 | >1kV不能带电扑救 |
| F类 | CO₂不适用F类 |

## 灭火器规格（P325）

- 手提水基。2/3/6/9L
- 手提干粉。1/2/3/4/5/6/8/9/12kg
- 手提CO₂。2/3/5/7kg
- 推车水基。20/45/60/125L
- 推车干粉。20/50/100/125kg

| 危险等级 | 场所举例 |
|---|---|
| 严重危险级 | 50间房及以上旅馆、50张床及以上医院/养老院/托儿所、100张床及以上学校宿舍、200㎡及以上公共娱乐、500㎡及以上车站码头、1000㎡及以上易燃易爆商店、2000㎡及以上图书馆展览馆 |

## 工业建筑危险等级（P329-332）

- 厂房按甲乙丙丁戊生产场所
- 库房按甲乙丙丁戊储存场所

### 工业场所危险等级举例（易混点，P329-331、奇门总结）

| 危险等级 | 场所举例 |
|---|---|
| 严重危险级 | 酒精度60°及以上的白酒库房、各工厂的总控制室/分控制室、甲/乙类液体储罐区、液化石油气储罐区及桶装库房 |
| 中危险级 | **油淬火处理车间**、火柴/香烟/糖/茶叶库房、油浸变压器室、木工厂房、丙类液体储罐区及桶装库房 |
| 轻危险级 | **原木库房、原木堆场**、丁戊类液体储罐区及桶装库房 |

> 易错辨析。60°白酒=严重危险级、油淬火处理车间=中危险级、原木库房=轻危险级、工厂总控制室=严重危险级
> **桶装库房按内容物分级**。液化石油气/甲乙类液体（严重）、丙类液体（中）、丁戊类液体（轻）--3号书 P329-331

### 储罐区灭火器配置判定链（79题）

- **煤油（乙类）储罐区 → 严重危险级B类火灾**（汽油甲类、煤油乙类）
- 单位面积灭火级别配置指标。严重危险级B类 U=0.5㎡/B
- 修正系数。甲/乙/丙类液体储罐区 K=0.3
- 计算。Q=K·S/U=0.3×500/0.5=**300B**（煤油储罐占地500㎡）

## 灭火器灭火级别表（P337-342）

水基、泡沫、ABC干粉、CO₂、BC干粉各级别数值（按危险等级对应 3A/2A/1A、89B/55B/21B 等）。

## 修正系数 K（P339）

| 设置情况 | K |
|---|---|
| 未设消火栓和灭火系统 | 1.0 |
| 设消火栓 | 0.9 |
| 设灭火系统 | 0.7 |
| 消火栓+灭火系统都设 | 0.5 |
| 露天堆场/甲乙丙液体储罐/可燃气体储罐区 | 0.3 |

## 歌舞娱乐放映游艺场所/网吧/商场/寺庙/地下场所（P340）

- Q=1.3KS/U（口诀：晚上鞠吓死）

## 配置计算步骤（P336-342）

1. 划分计算单元
2. 确定危险等级/单位灭火级别最大保护面积
3. Q=KS/U
4. 修正系数
5. 每点 Qe=Q/N
6. 每点具数
7. 校核保护距离

## 最大保护距离（A类，P343）

| 型式 | 严重 | 中 | 轻 |
|---|---|---|---|
| 手提 | 15m | 20m | 25m |
| 推车 | 30m | 40m | 50m |

## 最大保护距离（BC类，P343）

| 型式 | 严重 | 中 | 轻 |
|---|---|---|---|
| 手提 | 9m | 12m | 15m |
| 推车 | 18m | 24m | 30m |

> 依据。奇门总结 P4040、横向OCR P5891。B类手提保护距离 严重9m/中12m/轻15m，推车翻倍 18m/24m/30m。

## 配置其他要求（P344）

- 计算单元≥2具
- 每设置点≤5具
- 住宅公共部位>100㎡配1具1A，每增100㎡增配1具

## 不相容灭火剂（P344）

- 磷酸铵盐 ≠ 碳酸氢钠/钾
- 碳酸氢钠 ≠ 蛋白泡沫
- 蛋白/氟蛋白泡沫 ≠ 水成膜泡沫

## 配置计算（简）

- 计算单元划分 → 计算单元最小需配灭火级别 → 各设置点配置
- K系数。仅消火栓0.9；消火栓+自喷0.5（详见真题）

## 考试出题角度

- 铭牌标识内容（三生三C口诀）
- 配置要求（铭牌朝外、离地高度）
- 灭火器配置计算
