# 泡沫灭火系统

## 系统概述与分类

**系统组成**。泡沫液储罐、泡沫消防水泵、泡沫液泵、泡沫比例混合器（装置）、泡沫产生装置、压力容器、火灾探测与启动控制装置、控制阀门及管道

**系统特点**。通过机械作用将泡沫灭火剂、水与空气充分混合并产生泡沫实施灭火；安全可靠、经济实用、灭火效率高、无毒性

### 喷射方式分类

| 类型 | 特点 |
|---|---|
| 液上喷射 | 泡沫从液面上喷入被保护储罐；泡沫不易受油污染，可用廉价普通蛋白泡沫；有固定式、半固定式、移动式三种 |
| 液下喷射 | 泡沫从液面下喷入被保护储罐，注入液体燃烧层下部，上升至液面并扩散形成泡沫层；通常为固定式和半固定式 |

### 系统结构分类

| 类型 | 构成 |
|---|---|
| 固定式 | 固定泡沫消防泵/混合液泵 + 泡沫比例混合器 + 泡沫产生器 + 管道 |
| 半固定式 | 固定泡沫产生器 + 部分管道，泡沫消防车/机动泵用水带连接 |
| 移动式 | 消防车/机动泵/有压水源 + 泡沫比例混合器 + 泡沫枪/炮/移动产生器，水带连接 |

### 发泡倍数分类（口诀记忆）

| 类型 | 发泡倍数 | 适用 |
|---|---|---|
| 低倍数 | <20 | 甲、乙、丙类液体储罐及石油化工装置区**首选** |
| 中倍数 | 20~200 | 实际应用较少，多作辅助灭火设施 |
| 高倍数 | >200 | — |

### 储罐类型适用

- **固定顶储罐**。液上或液下喷射均可；非水溶性可选两者，**水溶性只选液上**
- **外浮顶储罐**。只选液上喷射
- **内浮顶储罐**。只选液上喷射

### 枪炮禁限口诀（7、9不枪 / 18不炮 / 浮顶水溶不炮）

- 高度>7m 或直径>9m 的固定顶储罐，**不得选用泡沫枪**作为主要灭火设施
- 直径>18m 的固定顶储罐，**不得选用泡沫炮**
- 非水溶性外浮顶/内浮顶储罐、水溶性甲乙丙类液体立式储罐，**不得选泡沫炮**

### 设计用量

- 扑救一次火灾的泡沫混合液设计用量 = 罐内用量 + 辅助泡沫枪用量 + 管道剩余量，三者之和最大的储罐确定
- 泡沫液储存温度 0~40℃

## 泡沫液选择

| 情形 | 泡沫液要求 |
|---|---|
| 非水溶性储罐固定式 | 应选 3% 型氟蛋白或水成膜泡沫液；环境敏感地区选不含强酸强碱盐的 3% 型氟蛋白；选水成膜时抗烧水平≥C级 |
| 非吸气型喷射装置 | 应选 3% 型水成膜泡沫液 |
| 水溶性液体 | **必须选抗溶水成膜、抗溶氟蛋白或低黏度抗溶氟蛋白泡沫液** |
| 混合储存（单罐≤10000m³） | 可选抗溶水成膜、抗溶氟蛋白或低黏度抗溶氟蛋白 |
| 混合储存（单罐>10000m³） | 应对水溶性和非水溶性储罐**分别**选取泡沫液 |
| 中/高倍数固定式 | 应选 3% 型泡沫液 |
| 海水水源 | 必须选适用于海水的泡沫液 |

### 泡沫液泵要求

- 普通泡沫液泵。允许吸上真空高度 ≥4m
- 抗溶泡沫液泵。允许吸上真空高度 ≥6m；储罐至泵管道长度 ≤5m；泵出口管道长度 ≤10m；平时不得充入泡沫液
- 空载运转。应能耐受 ≥10min

### 常压储罐要求

- 出液口。保障泵进口正压，出液口不应高于储罐最低液面 0.5m
- 吸液口。朝下，设在沉降层之上；蛋白类泡沫液时距罐底面 ≥0.15m

### 储罐灭火系统选择

| 储罐 | 系统类型 |
|---|---|
| 单罐容量>1000m³ 固定顶罐 | 应设**固定式**泡沫灭火系统 |
| 罐壁高度<7m 或容量≤200m³ | 可采用**移动式** |
| 其他储罐 | 宜采用**半固定式** |

### 其他要求

- 辅助泡沫枪最小流量 ≥240L/min
- 泡沫混合液流量 ≥100L/s 时，泵/比例混合装置/控制阀宜具备远程控制
- 泡沫消防水泵启动后输送到保护对象时间 ≤5min（高倍数系统 ≤1min）
- 泡沫消火栓沿防火堤外均匀布置，间距 ≤60m
- 保护面积按储罐横截面积计算

## 储罐设计参数

### 固定顶储罐

- 液下喷射供给强度 ≥6.0L/(min·m²)，连续供给 ≥60min

### 非水溶性液上喷射（固定/半固定，氟蛋白或水成膜）

- 供给强度 6.0L/(min·m²)。甲类 60min、乙类 45min、丙类 30min

### 非水溶性液上喷射（移动式）

- 氟蛋白泡沫液。供给强度 8.0。甲/乙/丙类 60/60/45min
- 水成膜泡沫液。供给强度 6.5。甲/乙/丙类 60/60/45min

### 外浮顶储罐

- 保护面积。按罐壁与泡沫堰板间的**环形面积**确定
- 供给强度 ≥12.5L/(min·m²)；连续供给 ≥60min
- 单个泡沫产生器最大保护周长 ≤24m

### 内浮顶储罐

- 保护面积（钢制单/双盘）。按罐壁与泡沫堰板间环形面积；直径 ≤48m 的易熔材料浮盘按固定顶储罐对待
- 泡沫堰板。距罐壁 ≥0.55m，高度 ≥0.5m
- 单个产生器保护周长 ≤24m

## 易错点 / 陷阱

- **液上 vs 液下**。水溶性液体只选液上；外浮顶/内浮顶只选液上
- **泡沫枪/炮禁限**。7、9不枪；18不炮；浮顶水溶不炮
- **发泡倍数**。低倍数首选（<20），不是越高越好
- **抗溶泡沫液**。水溶性液体必须抗溶，普通泡沫液无效
- **外浮顶保护面积**。环形面积不是横截面积

## 记忆方法

- **7、9不枪 / 18不炮 / 浮顶水溶不炮**。泡沫枪炮禁限
- 低倍数 = 甲、乙、丙类液体储罐及石油化工装置区首选

## 规范依据

- GB 50151-2010《泡沫灭火系统技术标准》第3章（系统选择）、第4章（泡沫液和系统组件）、第5章（储罐设计）

## 考试出题角度

- **实务**。给储罐参数判断系统类型（固定/半固定/移动）、泡沫液选择、供给强度与时间
- **综合**。泡沫液泵要求、常压储罐出液口/吸液口要求、消火栓间距
- **案例**。储罐区消防设计判断（液上/液下选择、枪炮适用性、供给强度核算）
