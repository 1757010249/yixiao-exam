# 各系统横向对比总览（小红书）

> 齐德龙"小红书"74页横向总结的结构化收录。跨系统对比型表格集中于此；单一系统细节见各专项条目。个别 OCR 粘连处以 ⚠ 标注，经视觉复核后在测试报告中销项。

## 一、各系统启动水泵方式对比

| 系统 | 连锁启泵（不经控制器） | 联动启泵（控制器自动） |
|---|---|---|
| 湿式自喷 | 报警阀组压力开关 / 高位水箱出水管流量开关 / 出水干管低压压力开关 | — |
| 干式自喷 | 同湿式（报警阀组压力开关） | — |
| 预作用（单连锁） | 流量开关 / 低压压力开关 / 报警阀组压力开关 | **两只感烟 或 一只感烟+一只手报** |
| 预作用（双连锁） | 同上 | **一只感烟+充气管路压力开关** |
| 雨淋 | 同上 | **两只感温 或 一只感温+一只手报** |
| 消火栓 | 报警阀组压力开关（**干式消火栓才有报警阀**）/ 流量开关 / 低压压力开关 | **消火栓按钮+一只探测器 或 手报** |

通用手动方式（所有系统均有）：控制柜就地/机械应急启动、控制室远程启动（手动优先，控制器无关、控制柜无关）。

- 要点：每种系统启泵方式**任选其一即可**；其余组件仍须设置（可有反馈信号但不参与启泵）
- 消火栓系统设计按2个联动信号、验收按3个信号启动（结合题目所依规范）
- 预作用、雨淋探测器信号可同时启动水泵和快速排气阀前电动阀；**干式自喷的快速排气阀用压力开关启动**

## 二、各系统阀组（报警阀/开式阀组）启动方式对比

| 系统 | 阀组自动启动 | 手动/机械 |
|---|---|---|
| 湿式 | 喷头爆破→平衡破坏→阀组自动启动 | — |
| 干式 | 同湿式 | — |
| 预作用单连锁 | 两只感烟 / 一只感烟+一只手报 | 控制室远程；打开第三腔室手动快开阀 |
| 预作用双连锁 | 一只感烟+充气管路压力开关 | 同上 |
| 雨淋 | 两只感温 / 一只感温+一只手报 | 同上 + 传动管启动（气动/液动） |
| 消火栓（干式） | 消火栓按钮直接启动干式消火栓报警阀组；电动阀/电磁阀/雨淋阀 | 现场打开手动快开阀；控制室远程；快速启闭装置 |

## 三、联动触发对象对比（GB 50116）

| 对象 | 触发信号 |
|---|---|
| 防火门（常开） | 防火分区**两只独立探测器** 或 一只探测器+一只手报 → 关闭 |
| 疏散通道防火卷帘 | 防火分区两只独立感烟 / 一只专用感烟 → **降至1.8m**；任意一只专用感温 → 降至楼板面 |
| 非疏散通道防火卷帘 | 防火分区两只独立探测器 → 直接降至楼板面；控制室也可控制降落 |
| 应急照明 | 报警区域两只独立探测器 → 顺序启动全楼应急照明 |
| 声光警报/广播 | 报警区域两只独立探测器 → 顺序启动全楼 |
| 电梯 | 报警区域两只独立探测器 → 所有电梯停于首层或转换层 |
| 水喷雾/细水雾 | 两只独立探测器 |

## 五、设计温度与环境温度对比

| 系统 | 要求 |
|---|---|
| 灭火系统设计温度（计算基准） | 采用 **20℃** |
| 七氟丙烷/IG541 防护区 | 最低环境温度 ≥**-10℃** |
| 储瓶间及预制灭火系统防护区 | **-10～50℃** |
| 高压 CO₂ 系统 | 环境 **0℃～49℃** |
| 低压 CO₂ 系统 | 环境 **-23℃～49℃** |
| 干粉系统 | 环境 **-20℃～50℃** |
| 泡沫系统（泡沫液储存） | **0℃～40℃** |

## 六、局部应用系统周围风速限制

CO₂ ≤**3m/s**；细水雾 ≤**3m/s**；干粉 ≤**2m/s**

## 七、其他风速总结

| 场景 | 风速 |
|---|---|
| 隧道射流风机排烟 | ≥2m/s 且大于临界风速 |
| 送风口/排烟口 | ≤7m/s；排烟金属风管≤20m/s、非金属≤15m/s |
| 补风 | 自然补风≤3m/s；机械补风≤10m/s；人员密集场所≤5m/s |

## 八、灭火机理对比（口诀：表窒吸乳 / 表窒服进乳 / 化干戈 / 泡芙）

| 系统 | 机理 |
|---|---|
| 水喷雾 | 冷却、窒息、**稀释、乳化** |
| 细水雾 | 冷却、窒息、**辐射热阻隔、浸湿、乳化** |
| CO₂ | 冷却、窒息 |
| 七氟丙烷 | 冷却、窒息、**化学抑制** |
| IG541 | **窒息**为主 |
| 干粉 | 冷却、窒息、隔离、化学抑制 |
| 泡沫 | 窒息、**吸热冷却、隔离、乳化**（口诀泡芙=泡覆） |

## 九、适用火灾类型对比

- 水喷雾：固体表面、丙类液体、饮料酒、电气火灾
- 细水雾：固体表面、液体、可熔化固体、电气火灾
- CO₂：固体表面（部分深位）、液体、可熔化固体、电气、气体（可切断气源）
- 七氟丙烷：固体表面、液体、可熔化固体、电气、气体（可切断气源）
- IG541：同七氟丙烷
- 干粉：固体表面、液体、可熔化固体、气体（可切断气源）；BC类/ABC类区分
- 注释：CO₂ 无预制灭火系统；七氟丙烷、IG541 无局部应用（管网的局部应用）

## 十、控制方式对比

| 系统 | 控制方式 |
|---|---|
| 水喷雾/细水雾泵组 | 自动、手动 |
| 七氟丙烷管网 | 自动、手动、机械应急 |

| CO₂ 管网 | 自动、手动、机械应急；局部应用响应时间>120s时可**不设自动** |
| IG541 管网 | 自动、手动、机械应急；经常有人场所局部应用可不设自动 |

## 十一、喷放时间对比

| 系统 | 时间要求 |
|---|---|
| 七氟丙烷 | 通讯机房/电子机房等全淹没 ≤**8s**；其他防护区 ≤**10s** |
| IG541 | 喷放至设计用量95%时 ≤60s 且 ≥48s |
| CO₂ 全淹没 | ≤1min（扑救固体深位火灾 ≤7min，前2min浓度达30%） |
| CO₂ 局部 | 一般 **≥0.5min**；燃点温度低于沸点温度的液体和可熔化固体 **≥1.5min** |
| 干粉 室内局部 | ≥30s；室外或有复燃危险 ≥60s |

## 十二、动压/静压最小值对比 ✅（小红书P10已经视觉OCR复核，与 fire-hydrant/water-mist/water-supply 交叉核对一致）

| 部位 | 数值 |
|---|---|
| 自动喷水最不利点工作压力（动压） | 0.05MPa |
| 自动喷水静压 | 0.10MPa（有稳压泵时 >0.15MPa） |
| 水幕最不利点 | 0.10MPa |
| 水喷雾喷头工作压力 | 灭火 0.35MPa / 防护冷却 0.2MPa / 甲B乙丙类液体罐冷却 0.15MPa |
| 细水雾动压 | **1.2MPa** |
| 消火栓动压 | 一般 ≥0.25MPa(10m水柱)；高层厂房仓库/净高>8m ≥0.35MPa(13m水柱) |
| 消火栓静压 | 所有住宅、多层公共、二类高层公共 ≥0.07MPa；一类高层公共(H≤100m)、工业建筑 ≥0.10MPa；一类高层公共(H>100m) ≥0.15MPa（设稳压泵时 >0.15MPa） |

> 消火栓静压完整表见 [water-supply.md](fire-facilities/water/water-supply.md) 高位水箱最不利点静压节。

## 十五、管道试验对比（顺序/压力/合格标准）

### 试验顺序口诀

消火栓/自动喷水：**强、冲、严**；水喷雾/泡沫：**强、冲、防腐**；细水雾：**冲、强、吹**

### 水压强度试验压力

| 管道 | 强度试验压力 | 合格标准 |
|---|---|---|
| 钢管 P≤1.0MPa | 1.5P 且≥1.4MPa | 稳压30min，压力降≤0.05MPa且无泄漏变形 |
| 钢管 P>1.0MPa | P+0.4 | 同上 |
| 球墨铸铁管 P≤0.5MPa | 2P | 同上 |
| 球墨铸铁管 P>0.5MPa | P+0.5 | 同上 |
| 钢丝网骨架塑料复合管 | 1.5P 且≥0.8MPa | 同上 |

### 严密性试验

水压严密性：稳压24h无泄漏；气压严密性：24h压力降≤0.01MPa。冲洗排水管截面≥被冲洗管60%，流速≥1.5m/s。

### 气体/干粉管道试验

| 项目 | 要求 |
|---|---|
| 高压CO₂水压强度 | 15.0MPa |
| 低压CO₂水压强度 | 4.0MPa |
| IG541水压强度 | 13.0MPa |
| 七氟丙烷/1301水压强度 | 取水压强度试验压力的2/3（1.15倍最大工作压力） |
| 气动管道 | 驱动气体储存压力；试验压力宜0.2MPa |
| 升压速率 | ≤0.5MPa/s 缓慢升压，保压5min无渗漏变形 |
| 吹扫 | 压缩空气或氮气，末端流速≥20m/s，白布检查无异物 |

## 十七、支吊架间距对比

| 系统 | 要求 |
|---|---|
| 自动喷水 | 支吊架与喷头距离≥300mm 且不宜<300mm；与末端喷头≤750mm |

## 十八、抽检百分比汇总（进场/安装/调试/验收）

详见 [inspection.md](safety-management/inspection.md) 抽检总结节。补充电子卡要点：

- 自喷备用喷头：数量≥安装总数**1%** 且每种≥**10个**
- 水喷雾：管材规格尺寸20%且≥1个；阀门强度严密性10%且≥1个；喷头距离10%且≥5个（安装）
- 细水雾：喷头1%且≥5只；管网20%且≥5个
- 自动报警：防护区/报警区域5个及以下全检，超过5个按20%抽检且≥5个；声光警报/广播等安装100只以下抽20只，超过100只按10%~20%且≥20只；消火栓按钮按5%~10%抽检每个报警区域均抽

## 十九、验收合格判定标准（A/B/C缺陷法）

| 系统 | 判定标准 |
|---|---|
| 自动喷水/水喷雾/细水雾/泡沫 | A=0 且 B≤2 且 B+C≤6 |
| 消防给水 | A=0 且 B≤2 且 B+C≤6（C类缺陷计） |
| 气体/干粉 | 验收项目有1项不合格即不合格 |
| 建筑灭火器 | A=0 且 B≤1 且 B+C≤4 |
| 防排烟 | A=0 且 B≤2 且 B+C≤6 |
| 火灾自动报警 | A=0 且 B≤2 且 B+C≤5%检查项 |
| 应急疏散照明 | A=0 且 B≤2 且 B+C≤5%检查项 |

泡沫系统功能验收（喷水喷泡沫）不合格则整体验收不通过。

## 二十、维护周期对比（详见 inspection.md 维护周期节）

- 消防给水：日（外观/稳压泵启停/冬季防冻）、月（水位水质/模拟启动/末端试水）、季（流量压力测试）、年（水源能力/减压阀/过滤器排渣）
- 自动喷水：月（外观/供水情况/报警阀性能/气压水罐）、季（末端试水/放水试验）、年（通水加压/材质/流量性能/联动测试）
- 水喷雾：月手动、季自动启泵
- 细水雾：月（标识供电/储水箱/分区控制阀）、季（泵组支吊架瓶组）、半年换水？（按卡）、年联动试验
- 气体：日（低压CO₂控制器运行）、月（液位/称重/组件外观）、季度模拟喷气1个防护区（低压CO₂最远）
- 干粉：月（压力外观部件驱动气体充装量）、年（支吊架/模拟启动/防护区）
- 灭火器：月"十佳歌后"、重点场所半月
- 应急照明：月蓄电池、季手动启动、年集中控制联动测试
- 防排烟：月（窗机壁）、季（阀口）、年联动测试
- 泡沫：周（柴油机电量水泵盘车油量驱气压力氮封）、两周除锈渣、月手动启泵、年冲洗喷泡沫/泡沫液检验（保质期≤2年每年、>2年每两年）

## 二十一、通透率总结（吊顶开孔）

| 对象 | 规则 |
|---|---|
| 自喷喷头 | 通透面积占吊顶总面积 **>70%** 时，喷头设在吊顶上方 |
| 感烟探测器 | 镂空率 ≤15% 设吊顶下方；**>30%** 设吊顶上方；15%~30% 试验确定 |
| 地铁站台（活塞风影响） | 镂空率30%~70% 时宜上下同时设置 |
| 排烟储烟仓 | 吊顶开孔不均匀或开孔率≤25% 时，吊顶内空间高度不计入储烟仓厚度；非封闭吊顶开孔率应≥净面积25% |

## 二十二、声压级（分贝）总结

| 设备 | 要求 |
|---|---|
| 家用探测器报警声 | A计权 45~75dB，逐渐增大，初始≤45dB |
| 应急广播扬声器 | 最大间距、距地1.5~1.6m处 >60dB；背景噪声>60dB时应高于背景 **15dB** |
| 火灾警报器 | >60dB；噪声大时高于背景15dB |
| 水力警铃 | 喷嘴处压力≥0.05MPa；距3m远处声强≥**70dB** |
| 防火卷帘启闭噪声 | 距表面垂直1m、距地1.5m处测量，平均噪声≤**85dB** |

## 二十三、流速总结

| 管道 | 流速 |
|---|---|
| 消防水池进水管（计算不具备时） | 平均≤1.5m/s |
| 水泵吸水管 DN<250 | 1.0~1.2m/s；DN>250：1.2~1.6m/s |
| 水泵出水管 DN<250 | 1.5~2.0m/s；DN>250：2.0~2.5m/s |
| 消防给水管道设计流速 | ≤2.5m/s；任何消防管道 ≤7m/s |
| 自喷管道 | 经济流速，必要时>5m/s 但 ≤10m/s |

## 二十四、压力表量程

| 位置 | 要求 |
|---|---|
| 水泵吸水管 | 真空表大量程宜-0.10MPa；压力表量程不低于0.70MPa（视工程） |
| 水泵出水管 | ≥设计工作压力**2倍** 且 ≥1.60MPa |
| 水泵出水总管 | 系统工作压力的 **2~2.5倍** |
| 试压压力表 | ≥2只；精度≥1.5级；量程为试验压力的1.5~2倍 |

## 易错点 / 陷阱

- 预作用充水时间：单连锁2min、双连锁1min（双连锁更快，因为充气压力开关提前参与）
- 七氟丙烷喷放时间 8s/10s 按"通讯机房/其他"分档
- 水力警铃两个数：0.05MPa（喷嘴压力）与 70dB（3m处声强）
- 卷帘噪声85dB 是"平均噪声上限"
- 探测器吊顶镂空率 15%/30% 分界 vs 喷头 70%
