# 气体灭火系统

## 系统对比（奇门遁甲口诀）

### 七氟丙烷 vs IG541 vs CO2

| 对比项 | 七氟丙烷 | IG541 | CO2 |
|---|---|---|---|
| 灭火浓度（通讯机房） | 8%（口诀：通电8） | - | - |
| 灭火浓度（油浸变压器） | 9%（口诀：油变9） | - | - |
| 灭火浓度（图书档案） | 10%（口诀：图文10） | - | - |
| 固体表面灭火浓度 | 5.8% | 28.1% | - |
| 喷头位置 | 防护区净高**2/3以上**（比空气重防流失） | 无高度要求 | 净高2/3以上 |
| 局部应用 | 无 | 无 | 仅CO2有局部应用 |
| 固体深位火灾 | 不能灭 | 不能灭 | **能灭**（喷放时间≤7min，前2min浓度达30%，口诀：表姨生气） |

## 防护区划分（易混点）

| 系统类型 | 防护区最大面积 | 防护区最大容积 |
|---|---|---|
| 无管网（预制）系统 | ≤**500㎡** | ≤**1600m³** |
| 管网系统 | ≤**800㎡** | ≤**3600m³** |

**预制系统**。柜式和悬挂式，适用较小防护区；自动控制+手动控制两种方式（无机械应急）

## 泄压口

- **所有管网气体灭火系统防护区必须设置泄压口**（P207、P213）
- **泄压口高度要求（按灭火剂区分）**
  - 七氟丙烷、CO₂。泄压口应开在防护区净高**2/3以上**（灭火剂比空气重，防流失）
  - **IG541。泄压口无设置高度要求**（可设在防护区下部），只有七氟丙烷和CO₂才有2/3要求（ex-4haoshu.txt 题眼 30）
- 宜设在外墙
- 允许压强≥1200Pa
- 喷放前除泄压口外开口能自行关闭

## 围护结构耐火

- 围护结构及门窗耐火极限≥**0.5h**
- 吊顶≥**0.25h**

## 口诀补充（3号书讲义）

| 口诀 | 对应内容 |
|---|---|
| **表姨生气** | CO2固体深位火灾喷放≤7min，前2min浓度达30% |
| **三生三C明星泪，终极驱使文雅三说明** | 灭火器铭牌标识内容（11项） |

## 灭火机理对比（3号书讲义 P194、P196）

| 灭火剂 | 灭火机理 |
|---|---|
| CO₂ | 窒息+冷却（温室效应） |
| 七氟丙烷 | 窒息+冷却+化学抑制（密度为空气6倍） |
| IG541 | 窒息（52%氮+40%氩气+8%CO₂） |

## 系统分类（P194、P201-204）

- 无管网（预制）。柜式/悬挂式
- 管网。组合分配/单元独立
- 按应用方式。全淹没/局部
- 按加压方式。自压/内储压/外储压

## 组合分配（P209、P213）

- 保护≤8个防护区
- 灭火剂储存量按最大防护区

## 防护区（P206、P212-213）

| 系统类型 | 最大面积 | 最大容积 |
|---|---|---|
| 管网 | ≤800㎡ | ≤3600m³ |
| 预制 | ≤500㎡ | ≤1600m³ |

- 围护结构及门窗耐火≥0.5h、吊顶≥0.25h
- 允许压强≥1200Pa

## 泄压口（P207、P213）

- **必须设置泄压口**；七氟丙烷/CO₂在防护区净高2/3以上，**IG541无高度要求**（可设下部）
- 宜设外墙
- 喷放前除泄压口外开口能自行关闭
- 最低环境温度≥-10℃

## 疏散要求（P213）

- 30s内疏散完毕通道
- 设应急照明与疏散指示

## NOAEL/LOAEL（P209、P213）

| 灭火剂 | NOAEL | LOAEL |
|---|---|---|
| 七氟丙烷 | 9.0% | 10.5% |
| IG541 | 43% | 52% |

## 设计浓度（P215、P219-220）

- 灭火设计浓度≥灭火浓度1.3倍、惰化≥1.1倍
- 实际应用≤设计浓度1.1倍
- 七氟丙烷：通讯机房8%（通电8）、油浸变压器9%（油备9）、图书档案10%（图文10）、固体表面5.8%
- IG541：固体表面28.1%

## 灭火浸渍时间（口诀：20妹子尸骨5点1分起夜）（P215-216、P219-220）

| 灭火剂 | 场所 | 浸渍时间 |
|---|---|---|
| 七氟丙烷 | 木材纸张 | 20min |
| 七氟丙烷 | 通讯机房 | 5min |
| 七氟丙烷 | 其他固体表面 | 10min |
| 七氟丙烷 | 气体液体 | ≥1min |
| IG541 | 木材纸张 | 20min |
| IG541 | 通讯机房 | 10min |
| IG541 | 其他 | 10min |

## 喷放时间（P216、P220）

- 七氟丙烷：通讯机房≤8s、其他≤10s
- IG541：喷至95%用量时48~60s

## 喷头保护高度/半径（P210、P219）

- 最大保护高度≤6.5m；最小≥0.3m
- 安装<1.5m时保护半径≤4.5m；≥1.5m时≤7.5m
- 距顶面≤0.5m

## 预制系统（P211）

- 装置数量≤10台
- 多于1台同时启动、动作响应时差≤2s

## 启动方式（P205、P218）

- 管网：自动+手动+机械应急
- 预制：自动+手动
- 延迟≤30s，无人防护区可无延迟

## CO₂全淹没（P222）

- 不应用于经常有人停留场所
- 开口面积≤总内表面积3%且不设底面
- 固体深位火灾开口自动关闭
- 围护结构0.5h/吊顶0.25h/允许压强1200Pa

## CO₂设计参数（P222-223、P228）

- 设计浓度≥灭火浓度1.7倍且≥34%
- 泄压口净高2/3以上
- 全淹没喷放≤1min
- 固体深位≤7min且前2min浓度达30%
- 局部应用≥0.5min（燃点低于沸点液体≥1.5min）
- 高压系统管网起点压力5.17MPa、低压2.07MPa
- 喷头入口压力高压≥1.4MPa、低压≥1.0MPa

## CO₂储存（P223-224、P228-229）

- 高压储存容器工作压力≥15MPa、泄压19±0.95MPa、环境温度0~49℃
- 低压储存容器设计压力≥2.5MPa、两套泄压2.38±0.12MPa、高压报警2.2MPa、低压1.8MPa、环境温度-23~49℃
- 泄漏损失10%声光报警
- 储存容器间耐火≥二级、排风口距地面≤0.5m、正常排风≥4次/h、事故≥8次/h

## 选择阀（P224、P229）

- 每个防护区一个
- CO₂选择阀工作压力高压≥12MPa、低压≥2.5MPa
- 选择阀在容器阀动作前或同时打开

## 备用量（横向P118、竖向P112）

| 系统 | 备用量触发条件 |
|---|---|
| 七氟丙烷/IG541 | 72h 内不能恢复时，备用量=系统原储存量的100% |
| CO₂ | 保护≥5个防护区或 48h 内不能恢复时，备用量≥设计储存量 |
| 干粉 | 保护>5个防护区/对象，或喷放后 48h 内不能恢复正常 |
| 细水雾 | 48h 不能恢复时，应有备用量 |

## 七氟丙烷组件专用要求（P226）

| 充装压力 | 安全泄压装置动作压力 |
|---|---|
| 2.5MPa | 5.0±0.25 |
| 4.2MPa、充装950kg/m³ | 7.0±0.35 |
| 4.2MPa、充装1120kg/m³ | 8.4±0.42 |
| 5.6MPa | 10.0±0.5 |

- 容器阀与集流管之间设单向阀

## 充装量（P227）

- 七氟丙烷：一级增压≤1120kg/m³、二级增压焊接≤950kg/m³、三级增压≤1080kg/m³
- IG541：一级充压211.15kg/m³、二级281.06kg/m³

## 设计温度（P209、P213、P217）

- 20℃
- 储瓶间/预制防护区环境温度-10~50℃

## 储存装置（P217）

- 操作面距墙≥1.0m且≥储存容器外径1.5倍

## 气体灭火维保周期（竖向P151）

| 周期 | 内容 |
|---|---|
| 每日 | 低压CO₂储存装置运行情况、储存装置间设备状态检查并记录（口诀：日运） |
| 每月 | 低压CO₂液位计检查，灭火剂损失10%时补充；预制灭火系统设备状态；组件无碰撞变形/锈蚀、保护涂层完好、铭牌标志清晰、手动装置防护罩铅封完整；灭火剂和驱动气体储存容器压力≥设计储存压力90%（口诀：高祖压制卫士） |
| 季度 | 可燃物种类；支吊架固定无松动；连接管无变形裂纹老化；喷嘴孔口无堵塞；高压CO₂储存容器逐个称重，灭火剂净重≥设计储存量90%（口诀：喷重） |
| 每年 | 每个防护区1次模拟启动试验 + 1次模拟喷气试验 |

## 考试出题角度

- 三类气体灭火系统的灭火浓度对比
- 防护区面积/容积限值（预制 vs 管网）
- 泄压口、围护结构耐火要求
- 七氟丙烷喷头位置（净高2/3）
