# 气体灭火系统

## 系统对比（奇门遁甲口诀）

### 七氟丙烷 vs IG541 vs CO2

| 对比项 | 七氟丙烷 | IG541 | CO2 |
|---|---|---|---|
| 灭火浓度（通讯机房） | 8%（口诀：通电8） | 12%左右 | - |
| 灭火浓度（油浸变压器） | 9%（口诀：油变9） | - | - |
| 灭火浓度（图书档案） | 10%（口诀：图文10） | - | - |
| 固体表面灭火浓度 | 5.8% | - | - |
| 喷头位置 | 防护区净高**2/3以上**（比空气重防流失） | 无高度要求 | 净高2/3以上 |
| 局部应用 | 无 | 无 | 仅CO2有局部应用 |
| 固体深位火灾 | 不能灭 | 不能灭 | **能灭**（喷放时间≤7min，前2min浓度达30%，口诀：表姨生气） |

## 防护区划分（易混点）

| 系统类型 | 防护区最大面积 | 防护区最大容积 |
|---|---|---|
| 无管网（预制）系统 | ≤**500㎡** | ≤**1600m³** |
| 管网系统 | ≤**800㎡** | ≤**3600m³** |

**预制系统**。柜式和悬挂式，适用较小防护区；自动控制+手动控制两种方式（无机械应急）

## 泄压口

- 泄压口高度应大于防护区净高**2/3**，宜设在外墙
- 允许压强≥1200Pa

## 围护结构耐火

- 围护结构及门窗耐火极限≥**0.5h**
- 吊顶≥**0.25h**

## 口诀补充（3号书讲义）

| 口诀 | 对应内容 |
|---|---|
| **表姨生气** | CO2固体深位火灾喷放≤7min，前2min浓度达30% |
| **三生三C明星泪，终极驱使文雅三说明** | 灭火器铭牌标识内容（11项） |

## 考试出题角度

- 三类气体灭火系统的灭火浓度对比
- 防护区面积/容积限值（预制 vs 管网）
- 泄压口、围护结构耐火要求
- 七氟丙烷喷头位置（净高2/3）
