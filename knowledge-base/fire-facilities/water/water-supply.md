# 消防给水与消防水泵

## 给水系统类型（易混点）

| 类型 | 特点 |
|---|---|
| 高压系统 | 管网始终满足工作压力和流量，火灾时无须水泵加压 |
| 临时高压系统 | 平时不满足，火灾时自动启动水泵；**绝大多数建筑采用** |
| 低压系统 | 满足移动消防泵取水；管网压力≥0.10MPa（从地面算起） |
| 湿式消火栓 | 平时管网充满有压水 |
| 干式消火栓 | 平时不充水，火灾时由水泵充水 |

## 阀门（记忆口诀：闸驴鸭柔、肉鸭子施法）

- **明杆闸阀**。阀杆升降直接判断开闭状态
- **暗杆闸阀**。无法直接判断，应设开启刻度和标志
- **蝶阀**。手柄垂直管道=关闭，平行=打开；应带自锁装置
- 吸水管上应设明杆闸阀或带自锁蝶阀

### 阀门设置位置（竖向P77）

| 部位 | 阀门类型 |
|---|---|
| 消防水泵吸水管 | 明杆、暗杆（启闭刻度）、自锁蝶阀 |
| 消防水泵出水管 | 明杆、自锁蝶阀 |
| 埋地管道 | 暗杆、耐腐蚀明杆（阀门井内） |
| 稳压泵吸出水管 | 明杆 |
| 室内架空 | 明杆、暗杆、蝶阀 |
| 室外架空 | 暗杆（启闭刻度）、耐腐蚀明杆 |
| 水流指示器前方 | 信号阀 |
| 报警阀组上下 | 信号阀或锁具 |
| 气体灭火剂管道 | 选择阀 |
| 气体灭火驱动管道 | 低泄高封阀（分配时单向阀） |
| 电磁阀 | 气体驱动气瓶、雨淋第三腔 |
| 电动阀 | 快速排气阀前、>300mm 管道 |
| 报警阀上三个阀门 | 主排水阀（常闭）、试警铃阀（常闭）、报警管路控制阀（常开） |
| 细水雾 | 分区控制阀 |
| 手动快开阀 | 雨淋、预作用第三腔 |

## 消防水泵关键参数

### 基本要求
- 多用离心泵；工作泵不宜超过3台
- **串联增加扬程/压力，并联增加流量**
- 外壳宜球墨铸铁，叶轮宜青铜或不锈钢
- 不应采用双电动机/双动力驱动水泵（双叶轮可以）

### 备用泵设置（口诀：宅男250）
可不设备用泵，满足任一即可
- H<54m 住宅
- 室外流量≤25L/s
- 室内流量≤10L/s

### 性能参数
- 零流量时压力≤设计工作压力140%，且宜>120%
- 150%设计流量时，出口压力≥设计工作压力65%
- 单台最小额定流量≥10L/s；最大≤320L/s

## 水泵启停控制（案例高频）

### 连锁启动（三兄弟）——不经联动控制器直接启泵
1. 高位水箱出水管上的**流量开关**
2. 出水干管上的**低压压力开关**
3. 干式/湿式报警阀组的**压力开关**

以上三者发出信号→连锁启动消防水泵。**水泵控制柜须处于自动状态**

### 联动启动
消火栓按钮 + 2个探测器，或 消火栓按钮 + 1探测器 + 1手动报警按钮 → 消防联动控制器 → 启动水泵

### 手动启动（与控制柜手自动状态无关）
- 就地手动。水泵控制柜上的手动按钮
- 远程手动。消防控制室多线控制盘直接启动
- 机械应急启动。与控制柜状态无关，直接闭合交流接触器；报警后确保水泵5.0min内正常工作

### 停泵规则
**消防水泵绝对不能自动停泵**，只能就地手动或远程手动停泵

### 时间要求
- 接到启泵信号后，水泵≤2min内正常运转
- 双路电源自动切换≤2s；电源+内燃机切换≤15s

## 消防水泵管路

### 吸水管
- 应采取**自灌式吸水**；吸水口无吸水井时应设旋流防止器
- 吸水管数量≥2条，1条检修时其余通过全部设计流量
- 喇叭口淹没深度≥600mm；旋流防止器≥200mm
- 喇叭口距池底≥0.8D且≥0.10m；两吸水口间距≥2D
- 过滤器过水面积>管道过水面积4倍；孔径≥3mm

### 出水管
- 组件顺序。柔性接头→压力表→止回阀→DN65试水阀→闸阀
- 出水管压力表最大量程≥设计工作压力2倍，且≥1.60MPa
- 每组水泵≥2条输水干管与环状管网连接

### 管径流速
| 位置 | DN<250 | DN≥250 |
|---|---|---|
| 吸水管 | 1.0-1.2m/s | 1.2-1.6m/s |
| 出水管 | 1.5-2.0m/s | 2.0-2.5m/s |

## 消防管网

- 两路供水应布置成环状管网
- 室外管网。一路供水时，除H>54m住宅外，室外流量≤20L/s可采用枝状；管径≥DN100
- 室内管网。可枝状条件。室外流量≤20L/s 且 室内消火栓≤10个；竖管管径≥DN100
- 应设环状的4条件。向两栋及以上建筑供水；向两种及以上系统供水；设有高位水箱的临时高压系统；向两个及以上报警阀控制的自喷系统供水
- 常规流速≤2.5m/s；任何消防管道内流速≤7m/s

## 自动巡检（口诀：721变）

- 巡检周期≤7d
- 低频交流电逐台驱动，低速转动≥2min
- 变频运行方式巡检；定期人工巡检应工频满负荷运行并出流
- 收到启泵信号应立即退出巡检，转为正常启动
- 发现故障应有声光报警+记录储存

## 消防给水检测内容（口诀：童工采柱莽）

水源供水能力测试、水泵接合器通水加压测试、储水设备结构材料检查、水泵流量性能测试、系统联动测试（5号书讲义）

## 消防水箱（5号书讲义）

- 钢筋混凝土水箱。内部贴白瓷砖或喷涂瓷釉涂料
- 采用其他材料时。宜设置支墩，支墩高度不宜小于**600mm**（便于管道附件安装检修）
- 常见材料。碳素钢板、钢筋混凝土、搪瓷钢板、玻璃钢、不锈钢
- 玻璃钢水箱受紫外线照射强度变化、橡胶垫片易老化，**不推荐使用**
- 钢筋混凝土水箱进水管/出水管加设防水套管；钢板等用**法兰连接**，振动管道加柔性接头
- 水箱外壁与墙面净距。无管道侧面≥0.7m，有管道侧面≥1.0m；设人孔的池顶板面与板底净空≥0.8m
- 注意。笔记"混凝土支架500mm"教材未明确（教材仅说其他材料支墩600mm），该数值存疑但可信性较高（用户2026-08-05确认），答题时优先采用600mm口径

## 消防水池（3号书讲义 P53-63）

### 应设消防水池条件（3条）

1. 市政管网不能满足消防流量
2. 一路供水且室外栓流量>20L/s 或建筑高度>50m
3. 市政消防流量<建筑室内外消防流量

> 讲义 P53。依据：GB 50974-2014 第4.3.1条。

### 补水时间与进水管

- 补水时间≤48h；有效总容积>2000m³时≤96h
- 进水管径≥DN100

> 讲义 P53、P59。

### 有效容积下限

- 两路供水连续补水满足时≥100m³
- 仅设消火栓系统时≥50m³

> 讲义 P54。

### 火灾延续时间表（3号书 P55，72题考点）

| 对象 | 火灾延续时间 |
|---|---|
| 甲、乙、丙类厂房/仓库 | 3.0h |
| 丁、戊类厂房/仓库 | 2.0h |
| **一类高层民用建筑**、体积>100000m³公共建筑 | **3.0h** |
| 其他公共建筑 | 2.0h |
| 一类高层住宅 | 2.0h |
| 其他住宅 | 1.0h |
| 人防工程（建筑面积>3000㎡ / ≤3000㎡） | 2.0h / 1.0h |

- **图书馆建筑高度>50m → 一类高层公共建筑 → 火灾延续时间3.0h**
- 用水量 V=设计流量Q(L/s)×延续时间T(h)×3.6（如40L/s×3h×3.6=432m³）

### 两格/两座

- 有效容积>500m³ 宜设两格；>1000m³ 应设两座
- 每格（座）独立出水管+连通管

> 讲义 P61。

### 取水口距离

- 取水口吸水高度≤6.0m
- 距建筑（泵房除外）≥15m
- 距甲乙丙液体储罐≥40m
- 距液化石油气储罐≥60m（防辐射可40m）

> 讲义 P61。依据：GB 50974-2014 第4.3.5条。

### 其他要求

- 就地+远程水位显示、最高最低报警水位
- 溢流水管、间接排水
- 通气管防虫鼠

> 讲义 P62-63。

## 高位消防水箱（3号书讲义 P68-72）

### 必须设高位消防水箱

**口诀：高12设高位水箱**
- 高=高层民用
- 1=总建面>10000㎡
- 2=层数>2层
→ 三者满足任一即必须设高位消防水箱

- 高层民用、总建面>10000㎡且层数>2层公共建筑、其他重要建筑必须设
- 确有困难可不设但应设稳压泵
- 市政直接供水可替代

> 讲义 P68。依据：GB 50974-2014 第6.1.9条。

### 进出水管要求

| 项目 | 要求 |
|---|---|
| 进水管 | 8h充满，≥DN32，宜设液位阀/浮球阀 |
| 进水管接入 | 在溢流水位以上接入，高出溢流边缘高度=管径但100~150mm |
| 虹吸破坏孔 | ≥管径1/5且≥25mm |
| 溢流管 | ≥进水管径2倍且≥DN100 |
| 溢流管喇叭口 | =溢流管1.5~2.5倍 |
| 出水管 | ≥DN100；设止回阀 |
| 阀门 | 进出水管设带指示启闭装置的阀门 |

> 讲义 P69-71。

### 吸水口淹没深度（高位消防水箱）

| 部件 | 淹没深度 |
|---|---|
| 喇叭口 | ≥600mm |
| 旋流防止器 | ≥150mm |

> **与消防水池的区别**：喇叭口两者均为≥600mm，一致；旋流防止器水池≥200mm、高位水箱≥150mm，注意区分。
> 依据：GB 50974-2014 第5.2.6条。讲义 P69-71。

### 高位消防水池

- 供水管≥2条
- 储存室内用水量确有困难且补水可靠时≥室内用水量50%
- 总容积>200m³ 宜设两格（>100m高设两座）
- 在建筑物内用2.00h隔墙+1.50h楼板隔开+甲级防火门

> 讲义 P72。

## 稳压泵（3号书讲义 P73-76）

- 宜单吸单级或多级离心泵；外壳叶轮不锈钢
- 流量≥管网正常泄漏量且<系统自动启动流量；无泄漏数据时按消防流量1%~3%且≥1L/s
- 设计压力比自动启泵压力高0.07~0.10MPa；最不利点静压>0.15MPa
- 气压水罐启泵次数≤15次/h，有效储水容积≥150L
- 吸水管设明杆闸阀，出水管设消声止回阀+明杆闸阀
- 应设备用泵

> 讲义 P73-76。

## 消防水泵房（3号书讲义 P75-76）

- 严寒地区采暖≥10℃（无人值守≥5℃）
- 通风按6次/h
- 独立建造耐火≥二级
- 附设建筑内用2.0h隔墙+1.50h楼板隔开；门直通安全出口，开向疏散走道的门用甲级防火门

> 讲义 P75-76。

## 分区供水（口诀：口头报喜）

| 条件 | 分区要求 |
|---|---|
| 栓口静压>1.0MPa | 应分区 |
| 喷头工作压力>1.2MPa | 应分区 |
| 报警阀工作压力>1.6MPa | 应分区 |
| 系统工作压力>2.4MPa | 应分区；>2.4MPa时用泵串联或减压水箱 |

> 口诀"口头报喜"对应 1.0/1.2/1.6/2.4MPa。讲义 P77、P80。

### 水泵串联转输水箱

- 转输水箱≥60m³，可作高位水箱；溢流管宜接消防水池
- 直接串联时低区到高区依次顺序启动
- 出水管设减压型倒流防止器

> 讲义 P78。

### 减压阀减压分区

- 校核150%流量时出口动压≥设计值65%
- 每区≥2组减压阀组，每组宜设备用
- 比例式减压阀>1.2MPa时用先导式
- 阀前阀后压力比≤3:1
- 串联减压≤两级，第二级宜先导式，前后压差≤0.40MPa
- 减压阀后设安全阀

> 讲义 P78-80。

### 减压水箱减压

- 有效容积≥18m³且宜分两格；两条进出水管
- 水位控制阀；进水管设紧急关闭阀，溢流水回消防水池

> 讲义 P79-80。
