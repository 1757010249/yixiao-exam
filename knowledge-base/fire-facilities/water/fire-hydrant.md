# 消火栓系统

## 室外消火栓

### 市政消火栓设置条件
- 除≤500人且≤2层的居住区外，应设市政消火栓（口诀：500两层住）

### 布置参数
| 项目 | 要求 |
|---|---|
| 保护半径 | ≤150m |
| 间距 | ≤120m |
| 道路>60m | 两侧交叉错落设置 |
| 距路边 | ≥0.5m 且 ≤2.0m |
| 距建筑外墙 | ≥5.0m |
| 平时压力 | 工作压力≥0.14MPa |
| 火灾时 | **最不利栓出流量≥15L/s**；供水压力≥0.10MPa |

> 依据：GB 50974-2014 第7.2.8条（市政消火栓火灾时最不利栓出流量≥15L/s）。注意与**建筑室外消火栓**每个出流量10~15L/s（第7.3.5条）相区分。

### 动压静压要求（室外/市政）

| 类型 | 动压 | 静压 |
|---|---|---|
| 室外消火栓 | ≥**0.10MPa**（从地面算起） | ≥**0.14MPa**（平时工作压力） |
| 市政消火栓 | 供水压力≥**0.10MPa**（从地面算起） | 平时运行≥**0.14MPa** |

> 依据：GB 50974-2014 第7.2.8条（市政消火栓平时运行工作压力≥0.14MPa，火灾时最不利出流≥15L/s，供水压力从地面算起≥0.10MPa；3号书P83）。注意建筑室外消火栓本身无专属压力值，只给出流量10~15L/s（第7.3.5条）；"动压0.1/静压0.14"这套数值出自市政消火栓条文。2021实务真题16题（A动压0.10MPa正确；B"0.13MPa"错误应为0.14MPa；C最不利出流10L/s错误应为15L/s；D间距130m错误应为120m）。口诀。室外市政"动压0.1、静压0.14"。

### 栓口配置
- 地上式。1个150mm 或 100mm+2个65mm栓口
- 地下式。100mm+65mm栓口各1个

### 室外消火栓布置要点
- 沿建筑周围均匀布置；建筑扑救面一侧≥2个
- 距人防出入口≥5m且≤40m（口诀：我是人骑车加15→5m、40m）
- 距停车场最近排汽车≥7m
- 距加油站≥15m
- **距罐壁15m范围内的消火栓不计入该罐可使用数量**
- **建筑室外消火栓**每个出流量10~15L/s（依据：GB 50974-2014 第7.3.5条；区别于市政消火栓最不利栓出流量≥15L/s）

### 不设室外栓（口诀：二级3000戊）
地铁地上区间 + 一二级耐火且体积≤3000m³的戊类厂房

## 室内消火栓

### 配置
- 消火栓 DN65；水带 65mm内衬 长度≤25m；水枪喷嘴16mm或19mm
- 流量2.5L/s时水枪喷嘴可用11mm或13mm
- 软管卷盘。内径≥19mm，长度30m
- 轻便水龙。直径25mm，长度30m
- 软管/轻便用水量可不计入消防用水总量

### 设置场所（口诀：超高人密200点）
- **人员密集公共建筑、H>100m建筑、>200㎡商业网点**内应设软管卷盘或轻便水龙（奇门总结 P85、竖向P90）
- **步行街**。应设软管卷盘或轻便消防水龙
- **高层住宅**户内宜配置轻便水龙
- **老年人照料设施、避难层、隧道、地铁**。应设软管卷盘
- 商场商铺外每隔30m设DN65消火栓+软管卷盘/消防水龙

### 充实水柱与栓口压力（核心记忆，口诀：高工8）

| 场所 | 栓口动压 | 充实水柱 |
|---|---|---|
| 高层建筑/厂房/仓库/净高>8m | ≥0.35MPa | ≥13m |
| 其他场所 | ≥0.25MPa | ≥10m |
| 隧道 | ≥0.30MPa；>0.70MPa设减压 | - |

- 栓口动压上限≤0.50MPa；>0.70MPa时必须设减压装置
- 栓口距地面高度宜为1.1m
- 出水方向宜与墙面成90°角或向下

### 布置
- 任意2个消火栓间距≤30m（2股充实水柱同时到达）
- 可用1支的场所。≤24m且≤5000m³多层仓库；≤54m住宅且设一部疏散楼梯，跃层住宅，商业网点（间距≤50m）
- 消防电梯前室应设消防栓并计入消防用水总量

### 湿式/干式消火栓
- 湿式。室内环境温度4~70℃
- 干式。温度<4℃或>70℃；干式充水时间不应大于5min；电动阀开启≤30s

### 消火栓箱安装（三档偏差，口诀：20畜生周五想小三）

| 口诀段 | 对应知识点 | 数值 |
|---|---|---|
| 20 | 栓口中心距地面 1.1m（每栋应一致）允许偏差 | **±20mm** |
| 周5（谐音"轴5"） | 阀门中心定位（距箱侧面140mm、距箱后内表面100mm）允许偏差 | **±5mm** |
| 小三 | 消火栓箱体安装垂直度允许偏差 | **±3mm** |

- 口诀顺序即检查顺序。栓口 → 阀门 → 箱体
- 箱门玻璃 ≥4mm、金属 ≥1.2mm；箱门开启角 ≥120°
- 注意。±3mm 是**箱体垂直度**偏差，不是栓口误差（栓口误差是±20mm）

> 依据：GB 50974-2014 第12.3.10条。讲义出处：5号书综合能力内页 L1694-1696。

### 消火栓标志/铭牌（区别于水泵接合器"压稀饭"）

- **室内消火栓**。应设明显的**永久性固定标志**（未规定具体内容）
- **地下式室外/市政消火栓**。应有明显的永久性标志；冬季<-20℃地区井口保温
- **消火栓箱**。张贴使用方法标识；箱门不被装饰物遮掩，颜色明显区别或发光标志
- **对比考点**。水泵接合器永久性标志**铭牌**须标明供水系统、供水范围、额定压力（口诀"压稀饭"）；消火栓仅"永久性固定标志"，**无**供水系统/范围/压力等内容规定——考试问消火栓铭牌内容应判"规范未规定"

> 讲义出处：5号书 L1691、L1648；3号书 L2249。

## 消防排水（口诀：库里蹦迪）

| 部位 | 排水管径 |
|---|---|
| 末端试水装置 | ≥DN75 |
| 报警阀处 | 宜DN100 |
| 减压阀压力试验 | ≥DN100 |

试验排水可回收部分宜排入专用消防水池循环再利用

## 消防水鹤

**口诀：消防水鹤123**（1=间距1000m、2=管径DN200、3=出流量30L/s，压力0.10MPa；讲义 3号书 P83）

- 间距1000m；管径≥DN200（依据：GB 50974-2014 第7.2.9条）
- 出流量≥30L/s；供水压力≥0.10MPa（依据：GB 50974-2014 第7.2.10条）
- 设置条件。严寒地区宜增设消防水鹤（依据：GB 50974-2014 第7.2.1条）

## 水泵接合器相关

- 应设场所。高层建筑、地下商场、设有自喷的厂房等
- 距建筑外缘5~40m的市政栓可为水泵接合器供水并计入
- 可不设水泵接合器的建筑。建筑高度16m多层住宅等

### 应设水泵接合器口诀（3号书讲义：高水柱四工五民10人睡2层10000㎡地下室）

| 口诀段 | 对应场所 |
|---|---|
| 高 | 高层民用建筑、高层工业建筑 |
| 水住 | 设有消防给水的住宅 |
| 四工五民 | 四层及以上的厂房、五层及以上的民用建筑 |
| 10人睡2层 | 超过2层或建筑高度超过10m的地下、半地下建筑 |
| 10000㎡地下室 | 总建筑面积超过10000㎡的地下、半地下建筑 |

## 与建筑物间距汇总（5m最多）

### 5m 档（最高频）
| 设施 | 间距 |
|---|---|
| 市政消火栓距建筑外墙 | ≥5m |
| 消防车登高操作场地距外墙 | ≥5m 且≤10m |
| 消防车道靠外墙一侧边缘 | 不宜小于5m |
| 室外消火栓距人防出入口 | ≥5m 且≤40m |

### 15m 档
| 设施 | 间距 |
|---|---|
| 消防水池取水口距建筑物 | ≥15m（泵房除外） |
| 水泵接合器距消火栓/水池 | ≥15m 且≤40m |
| 室外消火栓距加油站 | ≥15m |

### 40m 档（上限）与特殊
| 设施 | 间距 |
|---|---|
| 消防水池取水口距甲乙丙液体储罐 | ≥40m |
| 消防水池取水口距液化石油气储罐 | ≥60m（防辐射热保护时40m） |
| 室外消火栓距停车场最近排汽车 | ≥7m |

### 市政栓计入规则（3号书设施篇 第104页）
- **距建筑外缘5~150m**的市政栓可计入室外消火栓
- 为水泵接合器供水时，**5~40m**可计入
- 枝状管网时计入的市政栓出流量不宜超过一个市政栓的出流量；环状管网全部代替
- 另见 3号书设施篇 第87页（汇总表）、第109页（重复条文）

**记忆**。5m贴建筑、15m危险源、40m操作上限

## 应设室内消火栓的场所（口诀：一老秃驴5000块乘车马超逛商展览，8点12特价，买了15M或10000M³办公教学）

- 占地面积>300㎡ 甲乙丙类厂房/仓库
- 高层公共建筑、>21m 住宅
- 特等/甲等剧场、>800座乙等剧场、>800座电影院、>1200座礼堂/体育馆
- 体积>5000m³的车站、码头、机场候车（机）厅、展览、商店、旅馆、医疗、老年人照料设施、档案馆、图书馆
- 高度>15m 或体积>10000m³的办公、教学建筑
- >300㎡汽车库、修车库
- >300㎡平时使用的人防工程
- 地铁地下区间、控制中心、车站及>30m人行通道
- 通行机动车的一、二、三类隧道

> 依据：GB 50974-2014 第7.4.1条。讲义 P89、P96。

## 干式消防竖管

- 高度≤27m 住宅可设干式竖管
- 宜设在楼梯间休息平台，仅配栓口
- 设消防车供水接口（首层）
- 竖管顶端设自动排气阀

> 讲义 P94、P107。

## 隧道消火栓

- 供水压力≥0.30MPa；>0.70MPa 设减压
- 间距≤50m；双向3车道以上双面间隔设置
- >3000m 且允许危险化学品通行时配水雾/泡沫枪

> 讲义 P94-95。

## 应设水泵接合器场所（3号书讲义）

- 高层民用建筑
- 设消防给水的住宅、>5层其他多层民用建筑
- >2层或面积>10000㎡地下半地下建筑、室内栓流量>10L/s的人防工程
- 高层工业建筑 + >4层多层工业建筑
- 城市交通隧道、地铁、>4层汽车库、地下半地下汽车库

> 讲义 P48-49、P51。

### 墙壁水泵接合器安装

- 距地面0.70m；与门窗孔洞净距≥2.0m
- 不装在玻璃幕墙下方
- 地下式进水口与井盖底面距离≤0.40m且≥井盖半径

> 讲义 P49、P52。

## 干式消火栓系统

- 充水时间≤5min
- 干式报警阀/雨淋阀/电磁阀/电动阀快速启闭；电动阀开启≤30s
- 消火栓箱处设手动按钮
- 最高处设快速排气阀

> 讲义 P98、P108。

## 埋地管道最小覆土

- ≥0.70m；机动车道下≥0.90m；冰冻线以下0.30m

> 讲义 P99。

## 钢丝网骨架塑料复合管

- PE 等级≥PE80；内环向应力≥8.0MPa
- 人行道下≥0.80m、轻型车行道下≥1.0m
- 与热力管道最小净距1.50m（表面温度≤40℃）

> 讲义 P100。

## 消防排水措施（口诀：库里蹦迪）

- 消防水泵房、设消防给水的地下室、消防电梯井底、仓库应排水

> 讲义 P100、P108。

## 规范依据

## 考试出题角度

- 栓口压力/充实水柱与场所对应（高工8）
- 室外消火栓数量计算（保护半径、间距）
- 不设室外栓/水泵接合器的条件判断
- 消火栓组件配置（水带长度、水枪喷嘴）
- 消防排水管径
