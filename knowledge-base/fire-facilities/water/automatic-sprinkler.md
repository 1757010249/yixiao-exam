# 自动喷水灭火系统

## 系统分类与温度条件

| 系统 | 类型 | 适用温度 | 特点 |
|---|---|---|---|
| 湿式系统 | 闭式 | 4℃≤T≤70℃ | 管网常充水，启动最快 |
| 干式系统 | 闭式 | T<4℃ 或 T>70℃ | 管网充有压气体 |
| 预作用系统 | 闭式 | - | 感烟先动作，先充水再等喷头爆裂 |
| 雨淋系统 | 开式 | - | 开式喷头，快速大面积喷水 |
| 水幕系统 | 开式 | - | 防火分隔/防护冷却 |

## 湿式系统（重点）

### 组成
- 洒水喷头、报警阀组、水流指示器/压力开关、管道、供水设施
- **末端试水装置**。试水阀+压力表+试水接头；排水立管≥75mm；距地面1.5m
- 报警阀组组件。阀瓣、报警管路控制阀(常开)、**延迟器**(防渗漏误报)、节流孔、水力警铃、压力开关、试警铃阀(常闭)、主排水阀(常闭)、补偿器

### 启动流程（案例高频）
火灾喷头破碎 → 管网静水转流动 → **水流指示器动作** → 系统侧供水侧平衡打破 → 阀瓣打开 → 初期高位水箱供水 → **压力开关动作→连锁启动消防水泵** → 喷头持续喷水

### 水泵启动方式
- **自动**。出水干管压力开关、高位水箱流量开关、报警阀组压力开关
- **手动**。消防控制室远程、水泵控制柜就地
- **机械应急**。水泵房现场应急操作

## 干式系统

- **没有延迟器、补偿器**
- 独有组件。充气管路压力表、注水漏斗、快速排气阀、空气压缩机、自动滴水阀(低泄高封阀)
- 系统侧充气、供水侧充水
- 启动流程。喷头爆破→管网排气→水流指示器→阀瓣打开→压力开关动作启动快速排气阀前电动阀→连锁启动水泵

## 雨淋系统（开式）

- 开式洒水喷头 + 雨淋报警阀组；**无水流指示器、无末端试水装置**
- 适用场所。①火灾水平蔓延速度快 ②净空高度超规范须迅速扑救 ③严重危险级Ⅱ级
- 启动阀组方式
  - 自动。两只感温探测器，或一只感温+一只手报
  - 手动。控制室手动盘、现场手动快开阀
  - 传动管。传动管破裂泄水（寒冷地区用气动）
- 恢复流程。阀瓣卡在防复位装置→关供水阀→打开主排水阀排水→手动恢复防复位装置

## 预作用系统（单联锁 vs 双联锁对比，核心考点）

| 对比项 | 单联锁 | 双联锁 |
|---|---|---|
| 系统侧 | 可充气可不充气 | 必须充气（防冰冻） |
| 启动阀组 | 两只感烟 或 一只感烟+手报 | 一只感烟 + 充气管路压力开关 |
| 是否需喷头爆裂 | 不需要 | 需要（管路压力下降） |
| 适用场所 | 严禁误喷 | 严禁充水（寒冷地区）、替代干式 |
| 启动水泵 | 压力开关/流量开关等，两者相同 | 同左 |

- 单联锁检漏。配水管道气压 0.03~0.05MPa
- 快速排气阀入口前电动阀应在启动水泵的同时开启

## 系统联动方式汇总（记忆表）

| 系统 | 启动阀组信号 | 自动启动水泵 |
|---|---|---|
| 湿式 | 喷头爆破→阀组平衡破坏自动打开 | 压力开关/流量开关/低压压力开关 |
| 干式 | 喷头爆破→阀组平衡破坏自动打开 | 同左 |
| 单联锁预作用 | 两只感烟 或 感烟+手报 | 火灾报警系统(两感烟/感烟+手报) |
| 双联锁预作用 | 感烟+充气管路压力开关 | 火灾报警系统(感烟+充气管路压力开关) |
| 雨淋 | 两感温/感温+手报/传动管 | 火灾报警系统(两感温/感温+手报) |
| 通用手动 | 控制室远程、就地启动、机械应急 | - |

## 火灾危险等级与喷水强度

### 危险等级划分
- **轻危险级**。住宅等
- **中危险级Ⅰ级**。办公楼、旅馆客房等
- **中危险级Ⅱ级**。商场、超市(净高≤8m)、地下车库等
- **严重危险级Ⅰ级**。净高>8m超市、易燃品仓库等
- **严重危险级Ⅱ级**。摄影棚、溶剂清洗车间等

### 关键判断示例
- 净高7.5m超市、物品堆高4.0m → 严重危险级Ⅰ级
- 溶剂清洗车间 → 严重危险级Ⅱ级
- 净空11m制衣厂 → 设计喷水强度15L/(min·㎡)
- 净空15m航站楼 → 15L/(min·㎡)

## 喷头选型要点

| 场所 | 喷头类型 |
|---|---|
| 地下汽车库 | 直立型 |
| 非通透性吊顶商场 | 下垂型 |
| 多层旅馆客房(坡度2%) | 边墙型 |
| 员工集体宿舍 | 家用喷头 |
| 格栅吊顶(镂空比≥85%) | 直立型(配水支管在梁下) |

- 喷头溅水盘与顶板距离。无障碍物75~150mm；有障碍物≤550mm(直立型)
- 备用喷头数量。不应少于总数1%且每种型号不少于10只

### 喷头布置口诀（3号书讲义）

| 口诀 | 对应内容 |
|---|---|
| **4640**（正方形布置） | 标准覆盖面积喷头正方形布置最大长边（46m×40m 对应不同危险级） |
| **5066**（矩形/平行四边形布置） | 矩形布置最大长边50m/66m |
| **清华水平100分** | 无吊顶轻危险场所，洒水软管喷头溅水盘与顶板距离≤100mm |
| **甲乙有粉丝** | 甲乙类厂房仓库不能设在地下（粉尘、棉麻毛丝等） |
