# 自动喷水灭火系统

## 系统分类与温度条件

| 系统 | 类型 | 适用温度 | 特点 |
|---|---|---|---|
| 湿式系统 | 闭式 | 4℃≤T≤70℃ | 管网常充水，启动最快 |
| 干式系统 | 闭式 | T<4℃ 或 T>70℃ | 管网充有压气体 |
| 预作用系统 | 闭式 | - | 感烟先动作，先充水再等喷头爆裂 |
| 雨淋系统 | 开式 | - | 开式喷头，快速大面积喷水 |
| 水幕系统 | 开式 | - | 防火分隔/防护冷却 |

## 湿式系统（重点）

### 组成
- 洒水喷头、报警阀组、水流指示器/压力开关、管道、供水设施
- **末端试水装置**。试水阀+压力表+试水接头；排水立管≥75mm；距地面1.5m
- 报警阀组组件。阀瓣、报警管路控制阀(常开)、**延迟器**(防渗漏误报)、节流孔、水力警铃、压力开关、试警铃阀(常闭)、主排水阀(常闭)、补偿器

### 启动流程（案例高频）
火灾喷头破碎 → 管网静水转流动 → **水流指示器动作** → 系统侧供水侧平衡打破 → 阀瓣打开 → 初期高位水箱供水 → **压力开关动作→连锁启动消防水泵** → 喷头持续喷水

### 水泵启动方式
- **自动**。出水干管压力开关、高位水箱流量开关、报警阀组压力开关
- **手动**。消防控制室远程、水泵控制柜就地
- **机械应急**。水泵房现场应急操作

## 干式系统

- **没有延迟器、补偿器**
- 独有组件。充气管路压力表、注水漏斗、快速排气阀、空气压缩机、自动滴水阀(低泄高封阀)
- 系统侧充气、供水侧充水
- 启动流程。喷头爆破→管网排气→水流指示器→阀瓣打开→压力开关动作启动快速排气阀前电动阀→连锁启动水泵

## 雨淋系统（开式）

- 开式洒水喷头 + 雨淋报警阀组；**无水流指示器、无末端试水装置**
- 适用场所。①火灾水平蔓延速度快 ②净空高度超规范须迅速扑救 ③严重危险级Ⅱ级
- 启动阀组方式
  - 自动。两只感温探测器，或一只感温+一只手报
  - 手动。控制室手动盘、现场手动快开阀
  - 传动管。传动管破裂泄水（寒冷地区用气动）
- 恢复流程。阀瓣卡在防复位装置→关供水阀→打开主排水阀排水→手动恢复防复位装置

## 预作用系统（单联锁 vs 双联锁对比，核心考点）

| 对比项 | 单联锁 | 双联锁 |
|---|---|---|
| 系统侧 | 可充气可不充气 | 必须充气（防冰冻） |
| 启动阀组 | 两只感烟 或 一只感烟+手报 | 一只感烟 + 充气管路压力开关 |
| 是否需喷头爆裂 | 不需要 | 需要（管路压力下降） |
| 适用场所 | 严禁误喷 | 严禁充水（寒冷地区）、替代干式 |
| 启动水泵 | 压力开关/流量开关等，两者相同 | 同左 |

- 单联锁检漏。配水管道气压 0.03~0.05MPa
- 快速排气阀入口前电动阀应在启动水泵的同时开启

## 系统联动方式汇总（记忆表）

| 系统 | 启动阀组信号 | 自动启动水泵 |
|---|---|---|
| 湿式 | 喷头爆破→阀组平衡破坏自动打开 | 压力开关/流量开关/低压压力开关 |
| 干式 | 喷头爆破→阀组平衡破坏自动打开 | 同左 |
| 单联锁预作用 | 两只感烟 或 感烟+手报 | 火灾报警系统(两感烟/感烟+手报) |
| 双联锁预作用 | 感烟+充气管路压力开关 | 火灾报警系统(感烟+充气管路压力开关) |
| 雨淋 | 两感温/感温+手报/传动管 | 火灾报警系统(两感温/感温+手报) |
| 通用手动 | 控制室远程、就地启动、机械应急 | - |

## 火灾危险等级与喷水强度

### 危险等级划分
- **轻危险级**。住宅等
- **中危险级Ⅰ级**。办公楼、旅馆客房等
- **中危险级Ⅱ级**。商场、超市(净高≤8m)、地下车库等
- **严重危险级Ⅰ级**。净高>8m超市、易燃品仓库等
- **严重危险级Ⅱ级**。摄影棚、溶剂清洗车间等

### 关键判断示例
- 净高7.5m超市、物品堆高4.0m → 严重危险级Ⅰ级
- 溶剂清洗车间 → 严重危险级Ⅱ级
- 净空11m制衣厂 → 设计喷水强度15L/(min·㎡)
- 净空15m航站楼 → 15L/(min·㎡)

### 易错场所归类（81题考点，4号书题眼）

| 场所 | 危险等级 |
|---|---|
| 高层医院 | 中危险级Ⅰ级 |
| 网吧（单层建面≤1000㎡） | 中危险级Ⅰ级 |
| 木器厂房 | 中危险级Ⅱ级 |
| 总建面<5000㎡商场 | 中危险级Ⅰ级（≥5000㎡为中Ⅱ，口诀"一千五千大商场"） |
| 国家文物保护单位 | 中危险级Ⅰ级 |
| 高层办公楼、高层旅馆 | 中危险级Ⅰ级 |

## 喷头选型要点

| 场所 | 喷头类型 |
|---|---|
| 地下汽车库 | 直立型 |
| 非通透性吊顶商场 | 下垂型 |
| 多层旅馆客房(坡度2%) | 边墙型 |
| 员工集体宿舍 | 家用喷头 |
| 格栅吊顶(通透面积>70%) | 直立型(配水支管在梁下) |

- 喷头溅水盘与顶板距离。无障碍物75~150mm；有障碍物≤550mm(直立型)
- 备用喷头数量。不应少于总数1%且每种型号不少于10只

### 喷头布置口诀（3号书讲义）

| 口诀 | 对应内容 |
|---|---|
| **4640**（正方形布置） | 标准覆盖面积喷头正方形布置最大长边（46m×40m 对应不同危险级） |
| **5066**（矩形/平行四边形布置） | 矩形布置最大长边50m/66m |
| **清华水平100分** | 无吊顶轻危险场所，洒水软管喷头溅水盘与顶板距离≤100mm |
| **甲乙有粉丝** | 甲乙类厂房仓库不能设在地下（粉尘、棉麻毛丝等） |

### 消防洒水软管（GB 50084-2017 第5.1.6条）

洒水喷头与配水管道之间采用消防洒水软管连接时：

| # | 要求 |
|---|---|
| 1 | 仅适用于**轻危险级或中危险级Ⅰ级**场所，且系统应为**湿式**系统 |
| 2 | 应设置在**吊顶内** |
| 3 | 应用于**公称直径≤DN80** 的配水管及配水支管，且**不应穿越防火分区** |
| 4 | 长度**不应超过1.8m**（真题陷阱。≤2m 是错的） |

**有吊顶/无吊顶附加条件**
- 有吊顶。吊顶内应**无其他可燃物**，吊顶材料为**不燃或难燃**装修材料
- 无吊顶。场所应为**轻危险级**，顶板水平、光滑，喷头溅水盘与顶板距离≤**100mm**（口诀"清华水平100分"）

> 出处。4号书 P3350-3358、2021年实务真题36题、口诀见上文喷头布置口诀表。知识库此前仅收录无吊顶的"清华水平100分"，主条文为补录。

## 火灾危险等级完整分类（3号书讲义 P145、P150）

### 中危险级
- **中1级**（口诀：屋里藏十佳古文物）。钢屋架、玻璃制品、冷藏库、食品、家用电器等
- **中2级**（口诀：舞台书库停车场、一千五千大商场，3.5M超市）。舞台、书库、停车场、1000~5000㎡商场、净高≤3.5m超市等

### 严重危险级
- **严重1级**（口诀：液晶印钞）。印刷、酒精、可燃液体、净高≤8m物品>3.5m超市
- **严重2级**。摄影棚、舞台葡萄架等

> 依据：GB 50084-2017 第4.2.1条。讲义 P145、P150。

## 网格栅板通透性吊顶（P149、P177）

- 喷水强度×1.3
- 通透面积**>70%**时喷头设吊顶上方（≤70%设在吊顶下方）
- 通透性吊顶开口部位**净宽度不应小于10mm**（不是10m），开口部位厚度不应大于开口最小宽度

## 水幕系统参数（P151）

| 水幕类型 | 高度 | 喷水强度 | 工作压力 |
|---|---|---|---|
| 防火分隔水幕 | h≤12m | 2.0L/(s·m) | 0.1MPa |
| 防护冷却水幕 | h≤4m | 0.5L/(s·m) | 0.1MPa |

- 每增1m加0.1L/(s·m)，超9m取1.0L/(s·m)
- 持续喷水时间≥耐火极限

### 水幕喷头布置规则（P177，33/96题易混点）

- **防火分隔水幕。喷头布置应保证水幕宽度不小于6m**；采用**水幕喷头时不少于3排**，采用**开式洒水喷头时不少于2排**（口诀：冷开123——水幕喷头3排、开式喷头2排、防护冷却单排）
- **防护冷却水幕。喷头宜布置成单排**，应直接将水喷向被保护对象
- **防火分隔水幕不宜用于尺寸超过15m（宽）×8m（高）的开口**（舞台口除外）
- **水幕系统应设独立报警阀组或感温雨淋报警阀**

### 防护冷却系统喷头布置（P177）

- 防火卷帘、防火玻璃墙等需防护冷却系统保护时，喷头应根据可燃物情况**一侧或两侧布置**；外墙可只在需要保护的一侧布置（33题D"布置在外墙两侧"错误）

## 防护冷却系统（P151-152）

- 独立设置；喷头高度≤8m（4~8m用快速响应）
- ≤4m时喷水强度≥0.5L/(s·m)，超4m每增1m加0.1
- 喷头间距1.8~2.4m
- 溅水盘与防火分隔设施水平距离≤0.3m

## 湿式喷头选型（P160-161）

- 不做吊顶梁下用直立型
- 吊顶下用下垂型或吊顶型
- 顶板水平轻/中1的住宅、宿舍、旅馆客房、医疗病房、办公室可用边墙型
- 易受碰撞带保护罩
- 无梁障碍物可用扩大覆盖
- 住宅宿舍公寓宜用家用喷头
- 隐蔽式仅轻/中1

## 快速响应喷头场所（口诀：老幼病残地下商场中庭玩接合器）（P161-162）

- 公共娱乐场所、中庭环廊
- 医院、疗养院病房、治疗区；老、幼、残集体活动场所
- 超出水泵接合器供水高度的楼层
- 地下商业场所
- >100m 公共建筑高层主体

## 备用喷头（P162）

- ≥总数1%且每种型号≥10只

## 水流指示器设置（P162）

- 除报警阀控制喷头只保护不超过防火分区面积同层场所外，每个防火分区、每楼层均应设
- 仓库内顶板下与货架内置喷头分别设

## 末端试水装置（P163-164）

- 每个报警阀组最不利点设
- 其他分区/楼层设 DN25 试水阀
- 由试水阀+压力表+试水接头组成
- 孔口出流排入排水管道，排水立管≥75mm
- 距地1.5m

## 报警阀组喷头数（P165-166）

- 湿式/预作用≤800只；干式≤500只
- 吊顶上下只计较多一侧
- 串联接入湿式管道的其他自喷系统喷头计入湿式阀组

## 报警阀组（P166-168）

- 每个报警阀组供水最高最低喷头高程差≤50m
- 报警阀距地1.2m
- 进出口控制阀用信号阀
- 水力警铃工作压力≥0.05MPa、连接管径20mm、总长≤20m

## 溅水盘与顶板距离（P171-175）

## 喷头障碍物增设（P174）

- 梁、风管、管道、桥架宽度>1.2m下方增设喷头
- ESFR 和特殊应用 >0.6m 增设

## 每根配水支管喷头数（P179-181）

- 轻/中1≤8只；严重/仓库≤6只
- 短立管及末端试水连接管≥DN25

## 配水管道充水时间（P179、P181）

- 干式/双联锁预作用≤1min
- 雨淋/单联锁预作用≤2min

## 局部应用系统（P183）

- 净高≤8m民用、总建面≤1000㎡；轻/中1；快速响应
- 持续喷水≥0.5h
- 标准覆盖喷头≤20只或扩大覆盖≤12只可不设报警阀组

## 气压供水设备（P183-184）

- 按最不利处4只喷头最低工作压力5min用水量确定

## 干式预作用供气管道（P184）

- 钢管≥DN15；铜管≥DN10

## 管道坡度（P184）

- 充水管道坡度≥2‰；准工作状态不充水管道≥4‰
- 口诀：气死水2

## 配水管道工作压力（P176）

- 配水管道工作压力≤1.20MPa

## 仓库自喷（P186）

- 货架储存用钢制通透层板，通透部分≥层板总面积50%
- 储物高度>7.5m 应设货架内置喷头
- 顶板下喷水强度：仓库1级18、仓库2级20、仓库3级22 L/(min·㎡)；作用面积≥200㎡、持续≥2h

## 喷头流量公式（P188）

- q=K√10P
- K=80、P=0.1MPa 时 q=80L/min
