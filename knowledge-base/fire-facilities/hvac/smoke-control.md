# 防排烟系统

## 系统选择（口诀：551）

| 建筑 | 防烟楼梯间/前室 | 系统 |
|---|---|---|
| >50m 公建/工业、>100m 住宅 | 机械加压送风 | 机械 |
| ≤50m 公建/工业、≤100m 住宅 | 自然通风（不能时机械加压送风） | 自然/机械 |
| 敞开阳台/凹廊楼梯间 | 可不设防烟系统 | 不设 |
| 独立前室两个不同朝向且各≥2㎡外窗 | 楼梯间可不设防烟系统 | 不设 |

### 送风系统设置
- 独立前室一个门。仅在楼梯间设机械加压送风（≤551且≤100）
- 独立前室多个门。楼梯间、前室分别独立设置
- 合用前室、剪刀楼梯。分别独立设置
- 地上地下。分别独立设置（地下为汽车库/设备用房时可共用，风量相加）

## 机械加压送风

### 分段与风口
- >100m 建筑竖向分段独立，每段≤100m
- 楼梯间每隔2~3层设常开百叶送风口
- 前室每层设常闭加压送风口+手动开启装置
- 风口风速不宜大于7m/s
- 送风机进风口与排烟风机出风口距离。竖向（进风口在下方）≥6m；水平≥20m（竖版 P128，即用户笔记"送风机和排烟风机水平20m竖直6m"）

### 压力参数（核心记忆）
| 部位 | 压差 |
|---|---|
| 前室/避难层/封闭楼梯间与走道 | 25~30Pa |
| 防烟楼梯间与走道 | 40~50Pa |
| 超压泄压 | 超过最大允许压力差应采取泄压措施 |

### 联动控制
- 触发信号。加压送风口所在防火分区内两只独立探测器 或 一只探测器+一只手报
- **15s内开启该防火分区楼梯间全部送风机**；开启着火层及相邻上下层前室常闭送风口
- 启动方式。现场手动/自动/消防控制室手动/常闭风口开启时联动

## 自然排烟

### 防烟分区
- 挡烟垂壁/结构梁/隔墙划分；**不应跨越防火分区**
- 走道宽≤2.5m长边≤60m；工业自然排烟长边≤净高×8
- 净高>9m可不设挡烟设施
- 吊顶开孔≤25%时，吊顶内高度不得计入储烟仓厚度

### 防烟分区最大面积表（依据：GB 51251-2017 第4.2.4条，讲义 P387-388）

| 空间净高 | 最大允许面积 | 长边最大长度 |
|---|---|---|
| 净高≤3m | 500㎡ | 24m |
| 3m<净高≤6m | 1000㎡ | 36m |
| 净高>6m | 2000㎡ | 60m（自然对流条件≤75m） |

> **45题应用示例**。净高7m商场（H>6m），房间70m×20m=1400㎡，面积虽满足1个分区（≤2000㎡），但**长边70m>60m超限**，需沿长度方向划2段（每段35m、面积700㎡）→ 至少2个防烟分区。

- 工业建筑自然排烟长边≤空间净高的8倍
- 走道宽≤2.5m 时 长边≤60m
- 净高>9m 时防烟分区之间可不设挡烟设施

### 排烟窗
- 任一点到最近排烟窗≤30m；工业≤净高×2.8；公建≥6m有对流≤37.5m
- 位置在储烟仓以内；走道/净高≤3m可设在净高1/2以上
- 防火墙两侧自然排烟窗最近边缘水平距离≥2.0m

### 储烟仓厚度
| 类型 | 厚度 |
|---|---|
| 自然排烟 | ≥净高20%且≥500mm |
| 机械排烟 | ≥净高10%且≥500mm（口诀：机10） |

最小清晰高度 Hq=1.6+0.1×H'（H'为排烟空间净高）

## 机械排烟

### 排烟风机
- 耐温280℃连续工作30min
- 与入口排烟防火阀连锁，关闭时风机停止
- 设在最高处，出口朝上

### 排烟管道耐火（易错点）
| 部位 | 耐火要求 |
|---|---|
| 竖向管道井内 | ≥0.5h |
| 水平吊顶内 | ≥0.5h |
| 确实困难直接设室内 | ≥1.0h |
| 走道/穿越防火分区 | ≥1.0h（设备用房/汽车库≥0.5h） |

### 送风管道耐火（3号书讲义 P396-399）

| 部位 | 耐火要求 |
|---|---|
| 竖向独立管道井内 | 可不作特殊要求 |
| 竖向未设在管道井内或合用管道井 | ≥1.00h |
| 水平吊顶内 | ≥0.50h |
| 水平未设吊顶内 | ≥1.00h |
| 送风管道井隔墙 | ≥1.00h，检修门乙级防火门 |
| 排烟管道井隔墙 | ≥1.00h + 检修门乙级防火门 |

> 送风管道与排烟管道井隔墙均≥1.00h + 乙级防火门。讲义 P396-399。

### 排烟防火阀设置位置
垂直与水平交接处；负担多个防烟分区支管上；风机入口处；穿越防火分区处

### 排烟口
- 距安全出口边缘≥1.5m；任一点与最近排烟口≤30m
- 面积<50㎡房间可通过走道排烟

### 联动控制（时间参数）
- **15s内开启全部排烟阀/排烟口/排烟风机和补风设施**
- **30s内关闭与排烟无关的通风/空调系统**
- **60s内挡烟垂壁开启到位**
- 多防烟分区仅打开着火防烟分区的排烟阀/口

## 补风系统

- 除走道或<500㎡房间外，设排烟场所应设补风
- 补风量≥排烟量50%；防火门窗不得作补风设施
- 机械补风口≤10m/s（人员密集≤5m/s）；自然补风口≤3m/s
- 同一防烟分区补风口设在储烟仓下沿以下，与排烟口水平距离≥5m
- 补风系统与排烟系统联动开启/关闭

## 排烟量计算（核心）

| 情况 | 排烟量 |
|---|---|
| 净高≤6m场所 | ≥60m³/(h·㎡)且≥15000m³/h；或自然排烟窗≥建筑面积2% |
| 仅走道/回廊 | ≥13000m³/h |
| 设计风量 | 计算排烟量×1.2 |
| 多防烟分区(净高≤6m) | 同防火分区任意两个相邻防烟分区排烟量之和最大值 |
| 多防烟分区(净高>6m) | 按最大一个防烟分区计算 |
| 中庭(周围有排烟) | 最大防烟分区排烟量×2，且≥107000m³/h |
| 中庭(仅回廊排烟) | 回廊≥13000m³/h，中庭≥40000m³/h |

## 自然排烟窗距离（3号书讲义 P388）

- 任一点距排烟窗≤30m
- 工业建筑≤净高2.8倍
- 公共建筑净高≥6m 有自然对流≤37.5m

## 排烟风机（3号书讲义 P389、P392）

- 专用机房内，两侧≥600mm空间
- 280℃连续30min
- 与入口排烟防火阀连锁
- 排烟管道金属风速≤20m/s、非金属≤15m/s、排烟口≤10m/s

### 消防控制室手动控制设备（94题考点，3号书 P395）

- **可在消防控制室手动控制的设备。送风口、电动挡烟垂壁、排烟口、排烟窗、排烟阀，以及防烟/排烟风机**（通过消防联动控制器手动控制盘/专线直接手动控制防排烟风机启停）
- **排烟防火阀不在手动控制清单内**（靠280℃温度熔断器自动关闭，无需控制室手动控制功能）
- 消防水泵、防烟和排烟风机的控制设备，应采用联动控制和在消防控制室设置手动控制
- 送风口、排烟口、排烟窗或排烟阀开启/关闭动作信号、风机启停信号、电动防火阀关闭动作信号，均应反馈至消防联动控制器

## 排烟防火阀设置部位（P390、P392）

- 垂直与水平交接处水平管段上
- 负担多个防烟分区支管上
- 风机入口处
- 穿越防火分区处

## 储烟仓厚度（P390-391、P393）

| 类型 | 厚度 |
|---|---|
| 自然排烟 | ≥净高20%且≥500mm |
| 机械排烟 | ≥净高10%且≥500mm（口诀：机10） |

- 吊顶开孔≤25%时吊顶内高度不计入储烟仓厚度

## 最小清晰高度（P390、P392）

- 走道净高≤3m 时 ≥净高1/2
- 其他 Hq=1.6+0.1×H'（H'为排烟空间净高）

## 机械排烟竖向分段（P389）

- 水平布置每防火分区独立
- >50m 公共、>100m 住宅竖向分段，公共≤50m、住宅≤100m

## 排烟系统联动（P394-395、P397-398）

- 同一防烟分区两只独立探测器 → 开启排烟口并停止该分区空调
- 排烟口开启动作信号 → 启动排烟风机
- 电动挡烟垂壁由同分区附近两只独立感烟联动
- 15s内开启排烟阀/口/风机/补风；30s内关闭无关通风空调；60s挡烟垂壁开启到位

## 补风系统（P395、P398）

- 除走道或<500㎡房间外应设补风
- 补风量≥排烟量50%；防火门窗不得作补风设施
- 机械补风口≤10m/s（人员密集≤5m/s）、自然补风口≤3m/s
- 同防烟分区补风口设储烟仓下沿以下，与排烟口水平距离≥5m

## 中庭排烟（P409）

- 中庭周围有排烟时 中庭排烟量=最大防烟分区排烟量×2 且≥107000m³/h
- 仅回廊排烟时 回廊≥13000m³/h、中庭≥40000m³/h

## 中庭回廊设置（P395-396）

- 周围房间均设排烟时回廊可不设（商店建筑回廊应设）
- 任一房间未设回廊应设
- 未用防火隔墙等分隔时中庭与周围场所间设挡烟垂壁

## 应急排烟排热设施（P396-397）

无可开启外窗地上建筑，满足任一应设：
- 任一层>2500㎡丙类厂房/仓库
- >2500㎡商展、会议厅、多功能厅、宴会厅及>60m走道
- >1000㎡歌舞娱乐房间和走道
- 靠外墙或贯通屋顶中庭

## 可熔性采光带（窗）（P397、P400）

- 机械排烟>2000㎡、自然排烟>2500㎡制鞋、衣、玩具、塑料、木器两类工业建筑可用
- 未设自喷或钢结构/预应力屋面板时≥10%、其他≥5%（口诀：水缸鱼）

## 固定窗（P400、P404）

- 顶层区域总面积≥楼地面2%
- 靠外墙非顶层单个≥1㎡、间距≤20m、下沿≥层高1/2
- 中庭区域≥中庭楼地面5%
- 消防员进入窗不计入

## 排烟合用系统阀门（P401）

- 排烟口打开时联动关闭的通风空调控制阀≤10个

## 吊顶内排烟（P401）

- 封闭式吊顶烟气流入口颈部烟速≤1.5m/s
- 非封闭式开孔率≥25%且均匀

## 排烟口设置（P402、P404）

- 宜设顶棚或靠近顶棚墙面
- 储烟仓内（走道净高≤3m可设在净高1/2以上）
- <50㎡房间可通过走道排烟
- 距安全出口相邻边缘≥1.5m
- 每个排烟口≤最大允许排烟量

## 自然排烟窗（P402-403、P405）

- 外墙时在储烟仓内（≤3m可在1/2以上）
- 房间≤200㎡开启方向不限
- 每组长度≤3.0m
- 防火墙两侧最近边缘水平距离≥2.0m
- 厂房仓库沿两条对边均匀设置

### 屋面斜度与排烟窗（P403）

- 屋面斜度≤12°每200㎡设相应排烟窗
- >12°每400㎡设

### 自然排烟窗有效面积（P403、P405）

| 窗型 | 有效面积计算 |
|---|---|
| 悬窗开窗角>70° | 按窗面积 |
| 悬窗开窗角≤70° | 按水平投影 |
| 平开窗≤70° | 按竖向投影 |
| 推拉窗 | 按最大开口面积 |
| 百叶窗 | 按有效开口面积 |
| 顶部平推窗 | 按1/2周长×平推距离 |
| 外墙平推窗 | 按1/4周长×平推距离 |

## 汽车库修车库排烟量（P410）

| 净高(m) | 排烟量(m³/h) |
|---|---|
| ≤3.0 | 30000 |
| 4.0 | 31500 |
| 5.0 | 33000 |
| 6.0 | 34500 |
| 7.0 | 36000 |
| 8.0 | 37500 |
| 9.0 | 39000 |
| >9.0 | 40500 |

## 避难层/避难走道送风量（P382-383、P386）

- 封闭避难层（间）、避难走道按净面积每㎡≥30m³/h
- 避难走道前室按门洞断面积×1.0m/s

## 直灌式加压送风（P383、P386）

- ≤50m 建筑楼梯间可直灌式
- >32m 高层用两点部位送风，送风口间距离≥建筑高度1/2
- 送风量增加20%

## 规范依据

- GB 51251-2017 第3.1节。防烟系统选择
- GB 51251-2017 第4.6节。排烟量计算
- GB 51251-2017 第5.1节。联动控制

## 考试出题角度

- 防烟系统选择（551口诀）
- 机械加压送风压力参数（25-30/40-50Pa）
- 联动时间（15s/30s/60s）
- 排烟量计算（60/15000、相邻分区和）
- 排烟管道耐火等级
