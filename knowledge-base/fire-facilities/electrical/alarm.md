# 火灾自动报警系统

## 系统分类（4大金刚）

系统组成。火灾探测报警系统 + 消防联动控制系统 + 可燃气体探测报警系统 + 电气火灾监控系统

| 系统 | 特点 |
|---|---|
| 区域报警系统 | 仅报警不需联动；探测器+手动按钮+声光警报器+报警控制器 |
| 集中报警系统 | 有联动要求；+消防广播+专用电话+图形显示装置+联动控制器 |
| 控制中心报警系统 | 建筑群/体量大；2个及以上集中报警系统；确定一个主控制室 |

## 探测器选型

### 感烟探测器
- **光电感烟不宜**。相对湿度>95%；气流>5m/s；大量粉尘/水雾；腐蚀性气体；正常情况下有烟；产生醇/醚/酮等有机物
- 离子感烟。适用于高海拔、烟不易对流场所

### 感温探测器（口诀考点）
- 宜选。相对湿度>95%；无烟火灾；大量粉尘；厨房/锅炉房/发电机房/烘干车间
- 不宜。可能产生阴燃火；温度<0℃不宜定温；温度变化大不宜差温

### 火焰探测器
- 不宜。火焰前有浓烟；镜头易污染；油/烟/水/雾遮挡；金属和无机物火灾；阳光/白炽灯照射

### 安装高度
| 探测器 | 最大安装高度 |
|---|---|
| 点型感烟 | ≤12m |
| 线型光束感烟 | ≤20m |
| A1类感温 | ≤8m |
| A2类感温 | ≤7m |
| B类感温 | ≤6m |
| CDEFG类感温 | ≤4m |
| 火焰探测器 | 20m |

### 线型光束感烟探测器间距（口诀：1357142）

**拆解**：1=0.3-1、3=0.5-7、5=14、7=20（对应规范数值）

| 数字 | 对应规范内容 |
|---|---|
| **0.3-1**（1→0.3/1） | 光束轴线至顶棚垂直距离 0.3~1.0m |
| **0.5-7**（3→0.5/7） | 探测器至侧墙水平距离 0.5~7m |
| **14**（5→14） | 相邻两组探测器水平距离 ≤14m |
| **20**（7→20） | 探测器距地高度 ≤20m |
| （100） | 发射器和接收器间距 ≤100m |

### 吸气式感烟探测器适用场所（口诀：早起进入的士高隐蔽跳舞）

| 口诀段 | 对应场所 |
|---|---|
| 早起 | 需早期探测的场所 |
| 进入 | 人员不宜进入的场所 |
| 的士高 | 高速气流场所、大空间/舞台上方/高度>12m |
| 隐蔽 | 需隐蔽探测的场所 |
| 跳舞 | 低温场所 |

## 探测器布置（易错点）

### 格栅吊顶
- 镂空面积/总面积 ≤15% → 吊顶**下方**
- >30% → 吊顶**上方**
- 15~30% → 试验确定

### 梁突出顶棚
- 高度<200mm 不计影响
- 200~600mm 按附录确定
- >600mm 每个梁间区域至少1只

### 内走道
- 宽度<3m 居中布置；感温间距≤10m；感烟间距≤15m
- 至墙壁/梁边水平距离≥0.5m；周围0.5m内无遮挡
- 至空调送风口边≥1.5m；宜接近回风口

## 控制器与手动按钮

- 报警控制器。总地址≤3200点；每一总线回路≤200点且留10%余量
- 联动控制器。地址总数/模块总数≤1600点；每一联动总线回路≤100点且留10%余量
- 短路隔离器。保护消防设备总数≤32点；穿越防火分区时穿越处设
- 手动按钮。任何位置到最近按钮步行距离≤30m；底边距地1.3~1.5m

## 联动控制（案例核心）

### 双信号原则
需联动控制的消防设备，联动触发信号应采用**2个独立报警触发装置信号的'与'逻辑**

### 消火栓泵联动
- 低压压力开关/高位水箱流量开关/报警阀压力开关 → **直接控制启动消火栓泵**（不受自动/手动状态影响）
- 消火栓按钮。动作信号作为报警信号及联动触发信号，由联动控制器控制启动

### 喷淋泵联动
- 湿式/干式。报警阀压力开关/流量开关直接控制启动喷淋泵
- 预作用。同一区域2只感烟 或 1感烟+1手报 → 开启预作用阀组
- 雨淋。同一区域2只感温 或 1感温+1手报 → 开启雨淋阀组

### 防火卷帘（高频）
**非疏散通道卷帘**
- 任2只独立探测器报警 → 卷帘直接下降至楼板面

**疏散通道卷帘（二步降）**
- 一步降。分区内任2只独立感烟 或 1只专用感烟 → 下降至距楼板面1.8m
- 二步降。任1只专用感温 → 下降到楼板面
- 感温探测器。卷帘任一侧距卷帘纵深0.5~5m内设≥2只专用感温探测器

### 声光警报器
- 声压级高于背景噪声15dB且≥60dB；底边距地>2.2m
- 单次发出警报8~20s；与消防应急广播交替循环播放

### 切断非消防电源（口诀：悟空洞房乐）
- **可立即切断**。普通动力负荷、自动扶梯、排污泵、空调用电、康乐设施、厨房设施
- **不应立即切断**。正常照明、生活给水泵、安全防范系统、地下室排水泵、客梯、Ⅰ~Ⅲ类汽车库车辆疏散口提升机
- 需切断照明时，宜在自喷/消火栓系统动作前切断

## 可燃气体探测器

- 应独立组成，**不应接入火灾报警控制器探测器回路**
- 密度小于空气（天然气）→顶部；大于空气（LPG）→下部；相当（人工煤气）→中间或顶部
- 厨房。天然气→甲烷探测器→顶部；液化气→丙烷探测器→下部；煤制气→CO探测器

## 电气火灾监控系统

- 组成。电气火灾监控器+探测器+声警报器；**不宜自动切断供电电源**
- 探测器类型。剩余电流保护式；故障电弧式；测温式
- 探测器报警值宜300~500mA；故障电弧探测器保护线路长度≤100m
- 不宜设在IT系统配电线路和消防配电线路中；适用TN-S，不适用TN-C

## 广播扬声器

- 额定功率≥3W；从分区内任何部位到最近扬声器直线距离≤25m；走道末端≤12.5m
- 客房专用扬声器功率≥1W；壁挂底边距地面>2.2m
- 确认火灾后同时向全楼广播；与声警报器分时交替（1次声警报+1次或2次广播）
