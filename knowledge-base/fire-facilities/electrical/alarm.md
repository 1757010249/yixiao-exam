# 火灾自动报警系统

## 系统分类（4大金刚）

系统组成。火灾探测报警系统 + 消防联动控制系统 + 可燃气体探测报警系统 + 电气火灾监控系统

| 系统 | 特点 |
|---|---|
| 区域报警系统 | 仅报警不需联动；探测器+手动按钮+声光警报器+报警控制器 |
| 集中报警系统 | 有联动要求；+消防广播+专用电话+图形显示装置+联动控制器 |
| 控制中心报警系统 | 建筑群/体量大；2个及以上集中报警系统；确定一个主控制室 |

## 探测器选型

### 感烟探测器
- **光电感烟不宜**。相对湿度>95%；气流>5m/s；大量粉尘/水雾；腐蚀性气体；正常情况下有烟；产生醇/醚/酮等有机物
- 离子感烟。适用于高海拔、烟不易对流场所

### 感温探测器（口诀考点）
- 宜选。相对湿度>95%；无烟火灾；大量粉尘；厨房/锅炉房/发电机房/烘干车间
- 不宜。可能产生阴燃火；温度<0℃不宜定温；温度变化大不宜差温

### 火焰探测器
- 不宜。火焰前有浓烟；镜头易污染；油/烟/水/雾遮挡；金属和无机物火灾；阳光/白炽灯照射

### 安装高度
| 探测器 | 最大安装高度 |
|---|---|
| 点型感烟 | ≤12m |
| 线型光束感烟 | ≤20m |
| A1类感温 | ≤8m |
| A2类感温 | ≤8m |
| B类感温 | ≤6m |
| CDEFG类感温 | ≤4m |
| 火焰探测器 | 20m |

### 线型光束感烟探测器间距（口诀：1357142）

**拆解**：1=0.3-1、3=0.5-7、5=14、7=20（对应规范数值）

| 数字 | 对应规范内容 |
|---|---|
| **0.3-1**（1→0.3/1） | 光束轴线至顶棚垂直距离 0.3~1.0m |
| **0.5-7**（3→0.5/7） | 探测器至侧墙水平距离 0.5~7m |
| **14**（5→14） | 相邻两组探测器水平距离 ≤14m |
| **20**（7→20） | 探测器距地高度 ≤20m |
| （100） | 发射器和接收器间距 ≤100m |

**设置与探测区域补充（3号书讲义 P266、P253）**

- 应设置在**固定结构**上；接收端应避开日光和人工光源直接照射
- 选择反射式探测器时，反射板与探测器间任何部位模拟试验均应正确响应
- 探测区域长度。红外光束/缆式线型感温 ≤100m；空气管差温 20~100m

**调试检测数据（GB 50166，6号综合习题）**

| 减光率 | 探测器反应 |
|---|---|
| 0.9dB | 不应报警 |
| 1.0~10.0dB | 火警确认灯点亮并保持 |
| 11.5dB | 点亮火警或故障确认灯（只点火警灯不符合规定） |

> 依据。GB 50116-2013 第6.2.15条；GB 50166 线型光束感烟探测器调试要求

### 线型光束感烟探测器适用/不宜场所（3号书讲义 P261）

- **宜选**。无遮挡的大空间、有特殊要求的房间
- **不宜选**。大量粉尘/水雾滞留；可能产生蒸气和油雾；正常情况有烟滞留；固定探测器的建筑结构因振动等产生较大位移

### 吸气式感烟探测器适用场所（口诀：早起进入的士高隐蔽跳舞）

| 口诀段 | 对应场所 |
|---|---|
| 早起 | 需早期探测的场所 |
| 进入 | 人员不宜进入的场所 |
| 的士高 | 高速气流场所、大空间/舞台上方/高度>12m |
| 隐蔽 | 需隐蔽探测的场所 |
| 跳舞 | 低温场所 |

## 探测器布置（易错点）

### 格栅吊顶
- 镂空面积/总面积 ≤15% → 吊顶**下方**
- >30% → 吊顶**上方**
- 15~30% → 试验确定

### 梁突出顶棚
- 高度<200mm 不计影响
- 200~600mm 按附录确定
- >600mm 每个梁间区域至少1只

### 内走道
- 宽度<3m 居中布置；感温间距≤10m；感烟间距≤15m
- 至墙壁/梁边水平距离≥0.5m；周围0.5m内无遮挡
- 至空调送风口边≥1.5m；宜接近回风口

## 控制器与手动按钮

- 报警控制器。总地址≤3200点；每一总线回路≤200点且留10%余量
- 联动控制器。地址总数/模块总数≤1600点；每一联动总线回路≤100点且留10%余量
- 短路隔离器。保护消防设备总数≤32点；穿越防火分区时穿越处设
- 手动按钮。任何位置到最近按钮步行距离≤30m；底边距地1.3~1.5m

## 联动控制（案例核心）

### 双信号原则
需联动控制的消防设备，联动触发信号应采用**2个独立报警触发装置信号的'与'逻辑**

### 消火栓泵联动
- 低压压力开关/高位水箱流量开关/报警阀压力开关 → **直接控制启动消火栓泵**（不受自动/手动状态影响）
- 消火栓按钮。动作信号作为报警信号及联动触发信号，由联动控制器控制启动

### 喷淋泵联动
- 湿式/干式。报警阀压力开关/流量开关直接控制启动喷淋泵
- 预作用。同一区域2只感烟 或 1感烟+1手报 → 开启预作用阀组
- 雨淋。同一区域2只感温 或 1感温+1手报 → 开启雨淋阀组

### 雨淋系统控制（3号书 P287，GB 50116-2013 第4.2.6条）
- 联动触发信号。同一报警区域内2只及以上独立感温探测器，或1只感温探测器+1只手动报警按钮 → 作为雨淋阀组开启的联动触发信号
- **控制主体。雨淋阀组由消防联动控制器控制开启；水泵控制柜只控制消防水泵启停，不能控制雨淋阀组**
- 手动控制方式。雨淋消防泵控制箱（柜）启动/停止按钮、雨淋阀组启动/停止按钮，用**专用线路直接连接至消防控制室消防联动控制器手动控制盘**
- 动作信号反馈。压力开关、雨淋阀组、雨淋消防泵的启动和停止动作信号应反馈至消防联动控制器

### 防火卷帘（高频）
**非疏散通道卷帘**
- 任2只独立探测器报警 → 卷帘直接下降至楼板面

**疏散通道卷帘（二步降）**
- 一步降。分区内任2只独立感烟 或 1只专用感烟 → 下降至距楼板面1.8m
- 二步降。任1只专用感温 → 下降到楼板面
- 感温探测器。卷帘任一侧距卷帘纵深0.5~5m内设≥2只专用感温探测器

### 声光警报器
- 声压级高于背景噪声15dB且≥60dB；底边距地>2.2m
- 单次发出警报8~20s；与消防应急广播交替循环播放

### 切断非消防电源（口诀：悟空洞房乐）
- **可立即切断**。普通动力负荷、自动扶梯、排污泵、空调用电、康乐设施、厨房设施
- **不应立即切断**。正常照明、生活给水泵、安全防范系统、地下室排水泵、客梯、Ⅰ~Ⅲ类汽车库车辆疏散口提升机
- 需切断照明时，宜在自喷/消火栓系统动作前切断

## 可燃气体探测器

- 应独立组成，**不应接入火灾报警控制器探测器回路**
- 密度小于空气（天然气）→顶部；大于空气（LPG）→下部；相当（人工煤气）→中间或顶部
- 厨房。天然气→甲烷探测器→顶部；液化气→丙烷探测器→下部；煤制气→CO探测器

## 电气火灾监控系统

- 组成。电气火灾监控器+探测器+声警报器；**不宜自动切断供电电源**
- 探测器类型。剩余电流保护式；故障电弧式；测温式
- 探测器报警值宜300~500mA；故障电弧探测器保护线路长度≤100m
- 不宜设在IT系统配电线路和消防配电线路中；适用TN-S，不适用TN-C

## 广播扬声器

- 额定功率≥3W；从分区内任何部位到最近扬声器直线距离≤25m；走道末端≤12.5m
- 客房专用扬声器功率≥1W；壁挂底边距地面>2.2m
- 确认火灾后同时向全楼广播；与声警报器分时交替（1次声警报+1次或2次广播）

## 探测器分类（5种+4维，3号书讲义 P247-248）

- 5种。感温/感烟/感光/气体/复合
- 4维。按监视范围（点型/线型）；按复位（可/不可）；按可拆卸性

## 探测区域划分（P253、P255）

- 按独立房间，≤500㎡
- 从入口能看清且≤1000㎡可划一个
- 红外光束和缆式线型感温≤100m；空气管差温20-100m

### 应单独划分探测区域（P256-257）

- 敞开/封闭/防烟楼梯间
- 防烟楼梯间前室、消防电梯前室、合用前室、走道、坡道
- 电气管道井、通信管道井、电缆隧道
- 建筑物闷顶、夹层

## 探测器选择原则（P257）

- 阴燃产烟选感烟
- 发展迅速选感温/感烟/火焰或其组合
- 强烈火焰辐射选火焰
- 需要早期探测增设一氧化碳
- 可燃气体选可燃气体探测器

## 不宜点型离子感烟（P258）

- 相对湿度>95%；气流>5m/s；大量粉尘水雾；腐蚀性气体；正常有烟；产醇醚酮

## 不宜点型光电感烟（P258）

- 大量粉尘水雾；蒸气油雾；高海拔地区；正常有烟
- 口诀：海淀

## 宜点型感温（口诀：发哥吸烟干厨师）（P258-259、P267）

- 相对湿度>95%；无烟火灾；大量粉尘；吸烟室
- 厨房/锅炉房/发电机房/烘干车间
- 需联动熄灭安全出口标志灯的安全出口内侧

## 不宜点型火焰/图像（P259-260）

- 火焰前浓烟；镜头易污染
- 视线被油雾烟雾水雾冰雪遮挡；金属无机物
- 阳光白炽灯照射；高温不选单波段红外
- 明火作业/射线/弧光/闪电不选紫外

## 探测器高度选择表（口诀：ABC864，P263）

| 探测器 | 高度要求 |
|---|---|
| 点型感烟 | 12<h≤20不适合 |
| A1/A2感温 | 8<h≤12不适合 |
| B感温 | 6<h≤8不适合 |
| CDEFG感温 | 4<h≤6不适合 |
| 火焰 | 4<h≤20适合 |

## 点型探测器布置（P263-264）

- 内走道<3m居中；感温间距≤10m、感烟≤15m
- 至端墙≤间距1/2；至墙壁梁边≥0.5m；周围0.5m无遮挡
- 至空调送风口边≥1.5m；至多孔送风顶棚孔口≥0.5m

## 探测器保护面积表（P272-273）

- 感烟（地面≤80㎡，h≤12：80㎡/6.7m等）
- 感温（S≤30，h≤8：30㎡/4.4m等）

## 探测器数量修正系数（P273）

- 容纳人数>10000人取0.7-0.8
- 2000-10000人取0.8-0.9
- 500-2000人取0.9-1.0
- 其他取1.0

## 控制器安装（P273）

- 主显示屏高度1.5-1.8m
- 靠近门轴侧面距墙≥0.5m；正面操作距离≥1.2m

## 火灾光警报器（P275、P280）

- 设在每楼层楼梯口、消防电梯前室、建筑内部拐角
- 不宜与安全出口指示标志灯同一面墙

## 消防专用电话（P276）

- 独立的消防通信系统；消防控制室设总机
- 多线制分机单独连接
- 避难层每隔20m设分机或插孔；插孔底边距地1.3-1.5m

## 模块（P277）

- 集中设在金属模块箱
- 严禁设在配电柜（箱）内；不控制其他报警区域设备
- 附近标识≥100mm×100mm

## 总线短路隔离器（P283、P288）

- 保护设备总数≤32点
- 穿越防火分区时在穿越处设

## 超过100m建筑（P283）

- 除消防控制室内控制器外，每台控制器直接控制设备不应跨越避难层

## 消防联动控制器（P284、P288-289）

- 电压输出直流24V
- 启动电流大的设备宜分时启动
- 双信号"与"逻辑

## 防火卷帘系统功能（P293-295）

- 温控释放装置70℃动作、自重下降
- 双帘面高度差≤50mm
- 垂直卷帘电动启闭速度2-7.5m/min、自重下降≤9.5m/min
- 平均噪声≤85dB；操作臂力≤70N
- 备用电源工作1h

## 防火卷帘控制器/手动按钮（P293）

- 内外两侧墙壁，底边距地1.3-1.5m

## 火灾声警报器（P299）

- 单次8-20s；与应急广播交替循环播放

## 消防应急广播（P300）

- 单次语音播放10-30s
- 1次声警报+1或2次广播交替
- 确认火灾后同时向全楼广播
- 与普通广播合用应强制切入

## 切断非消防电源（口诀：悟空洞房乐，P300）

- **可立即切断**。普通动力/自动扶梯/排污泵/空调用电/康乐设施/厨房设施
- **不应立即切断**。正常照明/生活给水泵/安防/地下室排水泵/客梯/Ⅰ~Ⅲ类汽车库车辆疏散口提升机
- 切照明宜在自喷消火栓动作前

## 可燃气体探测报警系统（P301-302）

- 独立组成，探测器不应接入火灾报警控制器探测器回路
- 由可燃气体报警控制器接入
- 线型探测器保护区域长度≤60m
- **石化行业特殊规定**。过程控制的可燃气体探测器可接入 DCS 等生产控制系统，但**报警信号应接入消防控制室**（横向P125）
- **控制器位置**。有消防控制室→控制器可设在保护区域附近；无消防控制室→控制器应设在有人值班场所（横向P125）

## 线型光束感烟探测器分层组网（横向P125）

- 线性光束。≤16m 时，宜在 6-7m 增设一层探测器；>16m 但 ≤26m 时，宜在 6-7m 和 11-12m 各增设一层；对流层为 7-13m 时，可设在流层下1m处；分层设置的探测器保护面积按常规计算，宜与下层探测器**交错布置**
- 吸气式。采样管宜水平+垂直结合布管，至少 2 个采样孔在 16m 以下，且宜有 2 个采样孔设在开窗/通风空调对流层下1m处
- 光栅光纤感温。保护外浮顶油罐时，相邻光栅间距 ≤3m；隧道内消防设备防护等级 ≥IP65

## 可燃气体探测器安装位置（P302、P304）

- 密度<空气（天然气）→顶部
- >空气（液化石油气）→下部
- 相当（人工煤气）→中间或顶部

### 厨房可燃气体探测器（P311、P317-318）

- 天然气→甲烷探测器→顶部
- 液化气→丙烷探测器→下部
- 煤制气→CO探测器
- 不宜设灶具正上方

## 电气火灾监控系统（P305-307、P315）

- 监控器+探测器+火灾声警报器
- 独立式探测器≤8只无控制室可用
- 非独立式不接入火灾报警控制器回路
- 报警值300-500mA
- 故障电弧保护线路≤100m
- 测温式1000V以下接触式布置
- 不宜用于IT系统、消防配电线路、TN-C

## 报警系统电源（P307、P316）

- 交流电源+蓄电池备用电源
- 备用电源用消防设备应急电源时报警控制器和联动控制器单独供电回路
- 主电源不应设剩余电流保护和过负荷保护
- 应急电源输出功率>全负荷120%
- 蓄电池连续工作3h以上

## 报警系统线路（P308-310）

- 传输线路和50V以下控制线路≥300V/500V铜芯
- 220V/380V线路≥450V/750V
- 线芯最小截面（穿管1.0㎡/线槽0.75㎡/多芯电缆0.5㎡）
- 明敷用金属管/可挠电气导管/金属封闭线槽
- 暗敷保护层≥30mm
- 矿物绝缘电缆可直接明敷

## 报警系统接地（P311）

- 共用接地≤1Ω；专用接地≤4Ω（口诀：一共四块砖）
- 专用接地线≥4mm²；接地板与建筑接地体≥25mm²

## 消防控制室设置（P313-314、P318）

- 单独建造耐火≥二级
- 附设首层靠外墙或地下一层，2.0h隔墙+1.50h楼板+直通室外安全出口
- 设备面盘前单列≥1.5m、双列≥2m
- 工作一面至墙≥3m；面盘后维修距离≥1m
- 排列长度>4m两端设≥1m通道
- 24h值班每班≥2人

## 考试出题角度

- 探测器选型（哪些场所不宜哪种探测器）
- 探测器安装高度表
- 格栅吊顶/梁的影响判断
- 防火卷帘一步降/二步降触发信号
- 声光警报器声压级、切换逻辑
- 切断非消防电源范围（悟空洞房乐）
- 线型光束感烟。间距口诀 1357142、分层组网、减光率调试（0.9/1.0-10.0/11.5dB）
