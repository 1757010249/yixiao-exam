## 三、重点薄弱点剖析

### 1. 消防给水与水泵（39 题，第一薄弱）

**具体问题**
- 高位消防水箱容积与静压（住宅/工业/公共分档）易混
- 水泵参数（启泵时间、泵轴密封、淹没深度、备用泵）
- 阀门类（减压阀安装方向、止回阀、排气阀）
- 分区供水方式、消防水池设置

**建议**。水箱容积表格化记忆，水泵参数配合口诀。

### 2. 安全疏散（36 题）

**具体问题**
- 疏散楼梯间形式判断、疏散人数计算（人员密度）、疏散距离（设自喷×1.25）

### 3. 装修与保温（36 题，本期新增 +29 最多）

**具体问题**
- 保温材料等级选择、防护层厚度、防火隔离带、装修降级规则

### 4. 自动喷水灭火（30 题，含历史修复 +8）

**具体问题**
- 系统调试/维护检查周期、报警阀排水口、末端试水装置

### 5. 火灾自动报警（27 题，含历史修复 +6）

**具体问题**
- 探测器选型与安装（线型光束、吸气式、可燃气体探测器）

## 四、对策建议

1. **优先补消防给水 + 装修保温 + 安全疏散**。这三大块合计 111 题，是当前最突出的薄弱面。
2. **注意设施类历史欠账**。本次修复的 28 道被合并错题集中在火灾报警、自动喷水、消火栓，说明设施类此前被低估，需重点补。
3. **安全管理已明显上升**（2→16 题），需系统补法规条文（公安部令 61 号等）。
4. **防排烟相对稳定**（26 题，本期仅 +1），此前专项补强有效，可维持。
