## 一、防排烟系统（25 题，最高频）

### 1.1 防烟分区与排烟口

| 易错点 | 正确（规范要求） | 常见错误（易错答案） |
|---|---|---|
| 排烟口开启触发 ⚠5次 | 同一防烟分区内**2只独立探测器**报警 → 开启排烟口 | 1只探测器+1只手报；或联动相邻分区排烟口 |
| 排烟风机启动触发 ⚠4次 | 排烟口/排烟阀**开启动作信号**联动启动排烟风机 | 用手动报警按钮直接控制排烟口开启 |
| 联动时间轴 ⚠5次 | 15s开启全部排烟口/风机，30s关空调，60s挡烟垂壁到位 | 把30s与15s、60s混淆 |
| 补风口位置 ⚠2次 | 同一防烟分区内设在储烟仓下沿以下，距排烟口≥5m | 补风口与排烟口水平距离3m |
| 排烟量（净高≤6m） ⚠3次 | ≥60m³/(h·㎡) 且 ≥15000m³/h | 只记60或只记15000 |
| 多防烟分区排烟量 ⚠3次 | 净高≤6m按**任意两个相邻防烟分区之和的最大值** | 按最大一个分区算（那是净高>6m的规则） |
| 防烟分区面积/长边 ⚠5次 | 净高5m商场面积≤1000㎡、长边≤36m | 把净高5m错配1500㎡面积 |
| 走道排烟窗距离 ⚠2次 | 任一点到最近排烟窗≤30m；工业≤净高×2.8 | 一律按30m，忽略工业系数 |
| 排烟防火阀位置 ⚠2次 | 风机入口、穿越防火分区处、垂直水平交接处 | 只记一处漏记其他 |

### 1.2 机械加压送风

| 易错点 | 正确 | 常见错误 |
|---|---|---|
| 前室与走道压差 ⚠4次 | 25~30Pa | 记成40~50Pa |
| 防烟楼梯间与走道压差 ⚠4次 | 40~50Pa | 记成25~30Pa |
| 送风机联动时间 ⚠3次 | **15s**内开启全部送风机 | 记成30s |
| 加压送风口 ⚠4次 | 楼梯间每隔2~3层设常开百叶；前室每层设常闭风口 | 前后颠倒 |
| 分段设置 ⚠2次 | >100m建筑每段≤100m | 记成50m |
| 送风机进/排烟口距离 ⚠2次 | 竖向≥6m（进风口在下）；水平≥20m | 记成15m |
| 自然通风外窗面积 ⚠2次 | 独立前室各≥2㎡（总面积≥4㎡）；合用前室各≥3㎡ | 独立前室按3㎡ |

### 1.3 排烟管道

| 易错点 | 正确 | 常见错误 |
|---|---|---|
| 排烟管道耐火（水平吊顶内） ⚠1次 | 0.5h | 记成1.0h |
| 排烟管道耐火（走道/穿越防火分区） ⚠1次 | 1.0h | 记成0.5h |
| 排烟管隔热层 ⚠1次 | 不燃绝热材料≥**40mm** | 记成30mm或50mm |
| 补风量 ⚠2次 | ≥排烟量**50%** | 记成30% |

## 三、火灾自动报警（21 题）

| 易错点 | 正确 | 常见错误 |
|---|---|---|

| 线型光束感烟最大高度 ⚠7次 | ≤**20m** | 记成12m |
| A1类感温最大高度 ⚠7次 | ≤**8m** | 记成10m |
| 火焰探测器最大高度 ⚠7次 | ≤**20m** | 记成12m |
| 格栅吊顶镂空≤15% ⚠3次 | 探测器在吊顶**下方** | 放上方 |
| 格栅吊顶镂空>30% ⚠3次 | 探测器在吊顶**上方** | 放下方 |
| 梁间净距<1m ⚠2次 | 可忽略梁的影响 | 记成2m |

### 3.2 联动控制

| 易错点 | 正确 | 常见错误 |
|---|---|---|
| 疏散通道防火卷帘一步降 ⚠5次 | 任2只独立感烟 或 1只专用感烟 → 降至**1.8m** | 直接一步到楼板面 |
| 疏散通道防火卷帘二步降 ⚠5次 | 1只专用**感温** → 降至楼板面 | 用感烟信号做二步降 |

| 双信号原则 ⚠3次 | 联动触发用2个独立报警信号"与"逻辑 | 单信号即动作 |
| 不可立即切电源 ⚠1次 | 客梯、生活给水泵、正常照明、安防系统 | 把客梯归入可切断 |

## 八、易错点之间的关联分析

### 8.1 核心关联逻辑

你的易错点不是孤立的，它们围绕**两条主线**相互关联。

**主线一。系统启动逻辑链（联动控制）**

> 探测器 → 报警控制器 → 联动控制器 → 启动风机/水泵/卷帘

这条链上的易错点高度关联，错一个环节往往连错一串

- 防排烟的"排烟口开启触发"（2只独立探测器）
- 报警的"双信号原则"、"卷帘一步降/二步降"
- 自喷的"单/双联锁触发信号"
- 给水的"连锁启动三兄弟"

**共同规律**。凡是"触发→联动"逻辑，规范普遍要求 **2 个独立信号"与"逻辑**。你只要记住这个大原则，很多具体触发条件就不用死记。单联锁/双联锁、卷帘一步降二步降，本质都是"2个信号"的变体。

**主线二。数值记忆群（数字陷阱）**

| 数字家族 | 涉及易错点 | 关联点 |
|---|---|---|
| **压差25~30Pa vs 40~50Pa** | 加压送风 | 前室/封闭楼梯间 vs 防烟楼梯间 |
| **耐火极限0.5h vs 1.0h** | 排烟管道、隔墙 | 吊顶内 vs 走道/穿越防火分区 |
| **疏散宽度1.2/1.3/1.4m** | 疏散走道 | 外门/单面/双面布房 |
| **百人指标0.65/0.75/1.00** | 疏散宽度 | 1-2层/3层/≥4层 |
| **面积650㎡ vs 500㎡** | 住宅安全出口 | 户门距离10m vs 15m联动 |
| **时间15s/30s/60s** | 排烟联动 | 依次对应开阀/关空调/挡烟垂壁 |

**规律**。这些数字都是"分层递进"结构——随建筑高度、楼层、场所等级递增/递减。建议画一条"数字轴"记忆，而不是孤立记每个数。

### 8.2 跨知识点强关联（案例分析高频）

| 关联组 | 关联点 | 案例题怎么考 |
|---|---|---|
| 耐火等级 ↔ 疏散距离 | 疏散距离按耐火等级取值（二级25m、三级35m） | 给建筑→判耐火等级→算疏散距离 |
| 火灾危险性 ↔ 耐火等级 | 甲/乙类厂房耐火等级要求更高 | 给厂房名→判类别→判耐火等级是否达标 |
| 火灾危险性 ↔ 平面布置 | 甲/乙类仓库中间仓库、防火间距要求严 | 给厂房→判类别→判办公室能否设 |
| 自动喷水 ↔ 防火分区 | 设自喷防火分区面积可加倍 | 给面积→判是否超限 |
| 自动喷水 ↔ 疏散距离 | 设自喷疏散距离×1.25 | 计算题核心 |
| 探测报警 ↔ 防排烟 | 探测器信号触发排烟口/风机联动 | 联动流程题 |
| 探测报警 ↔ 自喷 | 感烟/感温信号触发预作用/雨淋阀组 | 联动流程题 |

### 8.3 一个根本性薄弱模式

从错题看，你最主要的薄弱模式是**"数字记忆混淆"**（约占 60%），其次是**"系统启动逻辑"**（约占 30%）。

- 数字混淆多发生在**相似数值**之间（0.5/1.0h、25/30/40Pa、1.2/1.3/1.4m、0.65/0.75/1.00）
- 系统逻辑混淆多发生在**相邻系统**之间（预作用单/双联锁、卷帘一步/二步降、连锁/联动启动）

**针对性建议**
1. 对数字类易错点，用**表格对比**（本文档就是基础），并自编口诀串联相似数
2. 对系统逻辑类易错点，画**启动流程图**（探测器→联动→执行），把各系统的触发信号标在图上对比
3. 案例题训练时，养成"定性→防火→设施→联动"的分步习惯，每步只调取一个知识模块，避免串联错误
