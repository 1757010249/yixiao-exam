# 建议主题

气体灭火系统储存装置铭牌内容口诀"鸡鸭明日变凉皮"

## 建议内容

储存装置上应设耐久的固定铭牌，标明每个容器的 **7 项**内容（讲义P217原文）：编号、容积、皮重、灭火剂名称、**充装量**、充装日期、充压压力。

口诀及拆解（26卡牌大师 P74）：

| 口诀 | 内容 |
|---|---|
| 鸡 | 容积 |
| 鸭 | 充压压力 |
| 明 | 灭火剂名称 |
| 日 | 充装日期 |
| 变 | 编号 |
| 凉 | 充装量 |
| 皮 | 皮重 |

易错点：考试选项可能把"充装量"写成"重装量"、把"充压压力"写成"工作压力"，需按规范原文用词排除。
