# 独立建造的变电站（室外变、配电站）与甲类厂房的防火间距

## 建议内容

知识库 site-layout.md 仅收录"甲类厂房与明火或散发火花地点≥30m（不应小于）"（[site-layout.md](knowledge-base/building-fire-protection/site-layout.md#L57)），未收录**室外变、配电站与甲、乙类厂房**的专门间距规定。

用户问"为什么不是30m"：即考生常把变电站误归入"明火或散发火花地点"（30m），但 GB 50016-2014 表3.4.1 对**室外变、配电站（按变压器总油量分级）**单独设列，属特别规定，应优先适用。建议补录：

- 独立建造的变电站（室外变、配电站）与**甲、乙类厂房**的防火间距（待核实：疑为25m，与表3.4.1 中室外变配电站列对应；请 Claude Code 核实表3.4.1 原文数值与注）
- 室外变、配电站与丙、丁、戊类厂房的间距按**变压器总油量**（≤5t / 5-10t / 10-50t / >50t）分级取值
- 与"甲类厂房与明火或散发火花地点≥30m"的辨析逻辑（专门规定优先于一般规定）
